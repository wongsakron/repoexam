# บทที่ 2 โครงสร้างพื้นฐานและมาตรฐาน Data Center
> เล่ม 3 แนวสอบกระทรวงการคลัง · หมวด 2 (สัดส่วนประมาณ 10–12%) · ออก: Tier I–IV (Uptime %, Concurrently Maintainable, Fault Tolerant), ลำดับ UPS/ATS/Generator, สารดับเพลิงสะอาด, พื้นที่ TIA-942, PUE

## 1. มาตรฐาน Uptime Institute Tier I–IV ⭐⭐
| Tier | ความซ้ำซ้อน | Availability | Downtime/ปี | จุดเด่น |
|---|---|---|---|---|
| I | N (ไม่มีสำรอง) | 99.671% | ~28.8 ชม. | เส้นทางเดียว ซ่อมต้องปิดระบบ |
| II | N+1 เส้นทางเดียว | 99.741% | ~22 ชม. | สำรองอุปกรณ์ แต่ซ่อมเส้นทางหลักยังต้องปิด |
| III | N+1 + 2 เส้นทาง (Active 1 / Passive 1) | 99.982% | ~1.6 ชม. | **Concurrently Maintainable** ซ่อมได้ไม่ต้องปิดระบบ · นิยมในภาครัฐ |
| IV | 2N หรือ 2N+1 (Active ทั้ง 2 เส้น) | 99.995% | ~26.3 นาที | **Fault Tolerant** พังกะทันหันก็ไม่สะดุด |

- ⚠️ "ซ่อมบำรุงได้โดยไม่ต้องปิดระบบ" = **Tier III** · "ทนเหตุขัดข้องฉับพลัน" = **Tier IV**
- Tier I–IV เทียบได้กับ **Rated-1 ถึง Rated-4** ของ ANSI/TIA-942 · มาตรฐานที่เกี่ยวข้อง: ANSI/BICSI 002, ISO/IEC 27001
- คำนวณ Downtime = 8,760 ชม. × (1 − Availability)

## 2. ระบบไฟฟ้าและพลังงานสำรอง ⭐⭐
- เส้นทางไฟ: การไฟฟ้า → หม้อแปลง → **ATS** (เลือกไฟหลัก/Generator) → **UPS** → **PDU** → **Dual PSU** ของ Server
- **UPS** จ่ายไฟทันที **0 วินาที** · ชนิด Online Double Conversion ไม่มี Transfer Time
- **ATS** สั่งสตาร์ทและสลับไป **Generator** ใช้เวลาประมาณ **10–30 วินาที**
- ลำดับเมื่อไฟดับ: ไฟดับ → UPS จ่ายไฟ → ATS สั่ง Generator → ATS สลับโหลดไป Generator
- **PDU** กระจายไฟและวัดการใช้ไฟในตู้แร็ค · **Dual PSU** เสียบ Path A + Path B แยกกัน
- **N** = พอดีโหลด · **N+1** = เพิ่มสำรอง 1 ชุด (ใช้ 2 ติดตั้ง 3) · **2N** = 2 ระบบเต็มแยกอิสระ (ใช้ 4 ติดตั้ง 8)

## 3. ระบบปรับอากาศ ⭐
- **CRAC** มีน้ำยาแอร์ + คอมเพรสเซอร์ในตัว (ห้องเล็ก–กลาง) · **CRAH** ใช้ Chilled Water จาก Chiller (DC ใหญ่ ประหยัดกว่า)
- **ASHRAE**: อุณหภูมิ **18–27°C** · ความชื้น **40–60% RH**
- ความชื้น **< 40% → ไฟฟ้าสถิต (ESD)** · **> 60% → หยดน้ำ/สนิม** · ร้อนเกิน → Thermal Throttling
- **Hot/Cold Aisle**: หน้าตู้หันชนกัน = Cold Aisle · หลังตู้หันชนกัน = Hot Aisle · **Containment** กันลมผสม
- พื้นยกสูงประมาณ 30–60 ซม. ใช้ช่องใต้พื้น (**Plenum**) ส่งลมเย็น · เดินสายบน Overhead Cable Tray แยกจากสายไฟแรงสูง (กัน EMI)

## 4. ดับเพลิงและความปลอดภัยทางกายภาพ ⭐⭐
- **ห้ามใช้ Sprinkler น้ำ** เป็นระบบหลัก · ใช้ **Clean Agent**: สารเคมี **FM-200 (HFC-227ea)**, **Novec 1230 (FK-5-1-12)** หรือก๊าซเฉื่อย **Inergen (IG-541)**
- **VESDA** ดูดอากาศผ่านท่อมาวิเคราะห์ควันด้วยเลเซอร์ แจ้งเตือนก่อนเกิดเปลวไฟ
- **Mantrap** ประตู 2 ชั้นกัน Tailgating · Biometrics + บัตร · CCTV 24 ชม. · Water Leak Detection ใต้พื้นยก · Grounding ทุกตู้แร็ค

## 5. พื้นที่ตาม ANSI/TIA-942 ⭐⭐
| พื้นที่ | หน้าที่ |
|---|---|
| **ER** Entrance Room | รับสายจาก ISP/Carrier เข้าอาคาร |
| **MDA** Main Distribution Area | ศูนย์กลาง: Core Router/Switch, Main Cross-Connect |
| **IDA** Intermediate | กระจายสายระดับกลาง (DC ใหญ่) ระหว่าง MDA–HDA |
| **HDA** Horizontal | กระจายสายประจำแถว: Access Switch, SAN Switch |
| **ZDA** Zone | จุดพักสาย **Passive ห้ามมีอุปกรณ์ Active** |
| **EDA** Equipment | ตู้แร็ค Server/Storage |

- **Backbone Cabling** ER → MDA → HDA · **Horizontal Cabling** HDA → EDA · โครงสร้าง Hierarchical Star

## 6. PUE / DCiE / DCIM
- **PUE = พลังงานทั้งหมด ÷ พลังงานอุปกรณ์ไอที** · ดีที่สุด 1.0 · DC สมัยใหม่ 1.2–1.5
- **DCiE = (1 ÷ PUE) × 100%** เช่น PUE 2.0 → 50%
- ⚠️ ลดไฟฝั่งระบบสนับสนุน (เช่นทำ Containment) → PUE ลด · ลดไฟฝั่งไอทีอย่างเดียว → PUE กลับสูงขึ้น
- **DCIM** ซอฟต์แวร์ติดตามพลังงาน อุณหภูมิ ความชื้น พื้นที่ตู้แร็คแบบเรียลไทม์
