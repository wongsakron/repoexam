# บทที่ 7 OSI Model, Protocol และ Port
> เล่ม 1 หน้า 213–232 · ตรงหลักสูตรกรมที่ดิน (ความปลอดภัยเครือข่าย) ⭐ ออกบ่อยมาก: เลเยอร์ไหนทำอะไร, PDU, อุปกรณ์ประจำชั้น, TCP vs UDP, ARP/ICMP, MAC vs IP, เลข Port

## 1. องค์ประกอบการสื่อสารข้อมูล 5 อย่าง (น.213)
- **ผู้ส่ง (Sender) · สื่อกลาง (Medium) · ข้อมูลข่าวสาร (Message) · ผู้รับ (Receiver) · โพรโตคอล (Protocol)**
- สื่อกลางมีสาย (Ethernet, ใยแก้วนำแสง) / ไร้สาย (ไมโครเวฟ, ดาวเทียม, Wi-Fi) · Protocol = กฎ/ข้อตกลงให้คุยกันรู้เรื่อง (TCP/IP, UDP/IP)

## 2. ทิศทางการส่งข้อมูล (Transmission Mode) (น.214–215) ⭐
| แบบ | ลักษณะ | ตัวอย่าง |
|---|---|---|
| **Simplex** | ทางเดียว ผู้รับตอบกลับไม่ได้ | ทีวี, วิทยุ, Live Stream, เสียงประกาศ, คอม→ปริ้นเตอร์ |
| **Half-Duplex** | สองทาง **สลับกัน** ต้องรอให้อีกฝั่งส่งจบ | วิทยุสื่อสาร (Walkie-talkie), **Hub** |
| **Full-Duplex** | สองทาง **พร้อมกัน** | โทรศัพท์, วิดีโอคอล, แชต, Switch |

## 3. ชนิดสัญญาณ (น.215)
- **Analog** ต่อเนื่อง (Continuous) รูปคลื่นไซน์ **ถูกรบกวนง่าย** เช่น เสียงในสายโทรศัพท์ วิทยุ ไมโครโฟน
- **Digital** ไม่ต่อเนื่อง (Discrete) กราฟสี่เหลี่ยม 0/1 **แม่นยำกว่า** · **Modem** = แปลง Digital ↔ Analog (Modulate/Demodulate)
- (เสริม) **Bandwidth** = ความกว้างของช่องทางสื่อสาร ยิ่งกว้างยิ่งส่งข้อมูลได้มาก (bps)

## 4. OSI Model 7 ชั้น (น.216–224) ⭐⭐
- พัฒนาโดย **ISO** · จำจากล่างขึ้นบน: **"Please Do Not Throw Sausage Pizza Away"** (Physical, Data Link, Network, Transport, Session, Presentation, Application)

| ชั้น | หน้าที่ (คำสำคัญ) | หน่วยข้อมูล (PDU) | อุปกรณ์/โพรโตคอล |
|---|---|---|---|
| 7 Application | ประตูให้ผู้ใช้/โปรแกรมเข้าสู่เครือข่าย | Data | HTTP, FTP, SMTP, DNS, Telnet |
| 6 Presentation | **แปลงรูปแบบ · เข้ารหัส · บีบอัด** | Data | JPEG, MPEG, ASCII, SSL/TLS (การเข้ารหัส) |
| 5 Session | สร้าง/จัดการ/ยุติ Session · **Sync (Checkpoint)** | Data | NetBIOS, RPC |
| 4 Transport | ส่งระหว่างโปรเซสต้นทาง–ปลายทาง · **Port** · ควบคุมความถูกต้อง | **Segment** | **TCP, UDP** |
| 3 Network | หาเส้นทาง (Routing) ข้ามเครือข่าย · **IP Address** · Best Effort Delivery | **Packet** | **Router, L3 Switch**, IP, ICMP |
| 2 Data Link | ส่งในเครือข่ายเดียวกัน · **MAC Address** · ตรวจจับข้อผิดพลาด | **Frame** | **Switch, Bridge**, NIC, Ethernet, Token Ring, Frame Relay, ATM |
| 1 Physical | ส่งสัญญาณบิต 0/1 ผ่านสื่อกลาง | **Bit** | **Hub, Repeater**, สาย, คลื่น |

- ชั้น **1–3 = Network-dependent (ขึ้นกับเครือข่าย)** · ชั้น **4–7 = Application-oriented**
- จำ PDU: **Data → Segment → Packet → Frame → Bit** (ห่อหุ้ม Encapsulation ตอนส่งจากบนลงล่าง)
- ตัวอย่าง Login Facebook: ชั้น 7 กรอก User/Pass → ชั้น 6 Encode → ชั้น 5 สร้าง Session รอ Sync → ชั้น 4 แบ่ง Segment ใส่ Port → ชั้น 3 ใส่ IP หาเส้นทาง → ชั้น 2 ใส่ MAC → ชั้น 1 ส่งเป็นสัญญาณ

## 5. TCP/IP Model 4 ชั้น (น.224–230) ⭐
| TCP/IP | เทียบ OSI | โพรโตคอล |
|---|---|---|
| **Application** | 5–7 | HTTP, HTTPS (TLS), SMTP, POP3, IMAP, FTP, Telnet, SSH, DNS, DHCP |
| **Transport** | 4 | **TCP, UDP** |
| **Internet** | 3 | **IP, ICMP, IGMP, ARP, RARP** |
| **Link / Network Access** | 1–2 | Ethernet, Wi-Fi, PPP/PPPoE, Token Ring (เลิกใช้) |

- อีเมล: **SMTP = ส่ง** · **POP3 = ดึงลงเครื่องแล้ว (มัก) ลบจากเซิร์ฟเวอร์** · **IMAP = อ่านบนเซิร์ฟเวอร์ อีเมลยังอยู่ ซิงก์หลายเครื่อง**

### TCP vs UDP (น.226–228) ⭐⭐
| TCP | UDP |
|---|---|
| **Connection-oriented** (สร้างการเชื่อมต่อก่อน · 3-way handshake) | **Connectionless** (Datagram ส่งเลย) |
| **Reliable** มีลำดับข้อมูล ส่งซ้ำถ้าหาย (เหมือนไปรษณีย์ลงทะเบียน) | ไม่รับประกัน ไม่เรียงลำดับ ไม่ส่งซ้ำ |
| ช้ากว่า · Header **20 bytes** | **เร็วกว่า** ง่ายกว่า · Header **8 bytes** · Broadcast/Multicast ได้ |
| HTTP, HTTPS, FTP, SMTP, Telnet | **DNS, DHCP, TFTP, SNMP, RIP, VoIP**, สตรีมมิง, เกมออนไลน์ |

### ชั้น Internet (น.228–229)
- **IP** = ที่อยู่ต้นทาง/ปลายทาง (เหมือนใบปะหน้าพัสดุ · Packet = กล่อง · Router = บริษัทขนส่งหาเส้นทาง)
- **ARP** = หา **MAC Address จาก IP** (Broadcast ถามทุกเครื่องในวง เครื่องที่ตรงตอบกลับ) · **RARP** = กลับกัน หา IP จาก MAC
- **ICMP** = **รายงานข้อผิดพลาด** ความคับคั่ง หมดเวลาเชื่อมต่อ (คำสั่ง **ping, tracert** ใช้ ICMP) · แบบ Connectionless

### MAC Address vs IP Address (น.230) ⭐
- **MAC (Physical Address)** ฝังมากับการ์ดเครือข่ายโดยผู้ผลิต **6 ไบต์ (48 บิต)** · **3 ไบต์แรก IEEE จัดสรรให้ผู้ผลิต (OUI)** 3 ไบต์หลังผู้ผลิตกำหนด · ทำงานชั้น **2** · เหมือน**เลขบัตรประชาชน** เปลี่ยนไม่ได้
- **IP (Logical Address)** กำหนดโดย Network Layer · ชั้น **3** · เหมือน**รหัสนักศึกษา** ย้ายเครือข่ายเปลี่ยนได้

### ขั้นตอนส่งข้อมูลใน TCP/IP (น.230)
Application (HTTP/SMTP) → Transport (กำหนด **Port**, แบ่ง **Segment**) → Internet (ใส่ **IP** ห่อเป็น **Packet** ใน Packet Header) → Link (เป็น **Frame** ส่งผ่าน Node)

## 6. Port (น.231–232) ⭐⭐
- เลขพอร์ต **0–65535** (16 บิต) · TCP และ UDP ใช้เลขเดียวกันได้เพราะคนละโพรโตคอล (รวมได้ 131,070)
- เปรียบเทียบ: บุรุษไปรษณีย์ = Network Layer · คนรับจดหมายประจำบ้าน = OS ปลายทาง · **ชื่อบนซอง = Port** · ผู้รับจริง = Application
- (เสริม) Well-known 0–1023 · Registered 1024–49151 · Dynamic/Private 49152–65535

| Port | Protocol | ใช้ทำอะไร |
|---|---|---|
| **20 / 21** | FTP | 20 = Data Transfer · 21 = Command/Control |
| **22** | SSH | ล็อกอินระยะไกลแบบเข้ารหัส |
| **23** | Telnet | ล็อกอินระยะไกล **ไม่เข้ารหัส** |
| **25** | SMTP | ส่งอีเมลระหว่างเมลเซิร์ฟเวอร์ |
| **53** | DNS | แปลงชื่อโดเมน → IP |
| **67 / 68** | DHCP | แจก IP อัตโนมัติ (Server 67, Client 68) |
| **80** | HTTP | เว็บไม่เข้ารหัส |
| **110** | POP3 | ดาวน์โหลดอีเมล (มักลบจากเซิร์ฟเวอร์) |
| **123** | NTP | ซิงก์เวลา |
| **143** | IMAP | จัดการอีเมลบนเซิร์ฟเวอร์ |
| **161 / 162** | SNMP | เฝ้าระวังอุปกรณ์ (Manager 161, Trap 162) |
| **443** | HTTPS | เว็บเข้ารหัส TLS/SSL |
| **3389** | RDP | Remote Desktop ของ Windows |
