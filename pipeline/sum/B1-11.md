# บทที่ 11 ระบบสารสนเทศ (Information System)
> เล่ม 1 หน้า 400–418 · ตรงหลักสูตรกรมที่ดินโดยตรง ⭐⭐ (ระบบสารสนเทศ, GIS ใช้กับงานที่ดิน, ความปลอดภัยข้อมูล/ไซเบอร์) · ออก: TPS/MIS/DSS/EIS/ES, GIS, Batch vs Interactive, CIA Triad, Threat/Vulnerability/Risk, การจัดการความเสี่ยง, MFA, Least Privilege, CHMOD, NTFS, IDS/IPS, VPN, ชั้นความลับ, Backup 3-2-1

## 1. ความหมาย (น.400)
- **ระบบสารสนเทศ** = ระบบจัดเก็บและประมวลผลข้อมูลโดยอาศัย**คน + เทคโนโลยีสารสนเทศ** ให้ได้สารสนเทศที่เหมาะกับงาน
- กิจกรรม 3 อย่าง: **Input → Processing → Output** (บางระบบมี **Feedback** เป็นข้อที่ 4)

## 2. ประเภทตามระดับในองค์กร (น.400–401) ⭐
| ระดับ | ผู้ใช้ | ระบบ |
|---|---|---|
| **Operational-level** | ผู้ปฏิบัติงาน งานประจำวัน | **TPS** |
| **Knowledge-level** | ผู้ชำนาญการ/พนักงานความรู้ | **OAS, KWS** |
| **Management-level** | ผู้บริหารระดับกลาง | **MIS, DSS** |
| **Strategic-level** | ผู้บริหารระดับสูง วางแผนระยะยาว (5 ปี) | **EIS/ESS** |

## 3. ลักษณะของระบบสารสนเทศแต่ละแบบ (น.401–405) ⭐⭐
| ระบบ | ลักษณะ | ตัวอย่าง / ผลลัพธ์ |
|---|---|---|
| **TPS** (Transaction Processing) | บันทึก**รายการประจำวัน**แทนมือ เชื่อมกับลูกค้า | จองตั๋วเครื่องบิน, ATM ฝาก-ถอน · รายงานรายละเอียด |
| **OAS** (Office Automation) | งานธุรการ เอกสาร การสื่อสาร | เอกสาร กำหนดการ สิ่งพิมพ์ |
| **KWS** (Knowledge Work) | สร้างความรู้/ผลิตภัณฑ์ใหม่ ใช้แบบจำลอง | สิ่งประดิษฐ์ ตัวแบบ |
| **MIS** (Management Information) | ระดับกลาง วางแผน/ควบคุม รวมข้อมูลจาก TPS | ระบบบริหารบุคลากร · **รายงานสรุป / รายงานสิ่งผิดปกติ** |
| **DSS** (Decision Support) | ช่วยตัดสินใจปัญหา**กึ่งโครงสร้าง** ใช้ข้อมูลภายใน+ภายนอก ผู้ใช้โต้ตอบเปลี่ยนเงื่อนไข (What-if) | GPS route planning, Crop planning (Kaset Go) · รายงานวิเคราะห์ พยากรณ์ |
| **EIS/ESS** (Executive) | สารสนเทศ**เชิงกลยุทธ์**ผู้บริหารสูงสุด ใช้ง่าย (เมาส์/จอสัมผัส) ใช้ข้อมูล**ภายนอก**มาก | คาดการณ์แนวโน้มธุรกิจ · เป็น MIS ชนิดพิเศษ |
| **ES** (Expert System / AI) | เก็บความรู้ผู้เชี่ยวชาญ: **ฐานความรู้ (Knowledge Base) + กลไกอนุมาน (Inference)** ตัดสินใจแทนผู้เชี่ยวชาญ ไม่มีผลกระทบทางอารมณ์ | วิเคราะห์การตลาด ลดต้นทุน |

### GIS ระบบสารสนเทศภูมิศาสตร์ (น.404–405) ⭐ (เกี่ยวกับงานที่ดินโดยตรง)
- ระบบคอมพิวเตอร์รวบรวม จัดเก็บ วิเคราะห์ แสดงผล **ข้อมูลเชิงพื้นที่ (Spatial Data)** + **ข้อมูลเชิงบรรยาย (Attribute Data)** เชื่อมกันด้วย**พิกัดภูมิศาสตร์**
- องค์ประกอบ: **ข้อมูล** (ขอบเขต ที่ตั้ง ถนน / ประชากร มูลค่าทรัพย์สิน) · **ฮาร์ดแวร์ & ซอฟต์แวร์** · **บุคลากร** · **กระบวนการ** (วิเคราะห์ระยะทาง, **Overlay Analysis** ซ้อนทับชั้นข้อมูล)
- ใช้: วิเคราะห์**ความเหมาะสมทำเล (Site Suitability)** เช่น ที่ตั้งโรงพยาบาลใหม่ · บริหารสาธารณูปโภค (ท่อประปา สายไฟ เส้นทางเก็บขยะ)
- GIS เติมมิติ **"ที่ไหน (Where)"** ให้ MIS/DSS/EIS

## 4. การประมวลผลข้อมูล (น.406) ⭐
- **ด้วยมือ (Manual)** กระดาษ ลูกคิด เครื่องคิดเลข เหมาะข้อมูลน้อย ไม่เร่งด่วน
- **ด้วยคอมพิวเตอร์ (EDP)**:
  - **Batch Processing** รวบรวมข้อมูลไว้ช่วงหนึ่งแล้วประมวลผลพร้อมกันตามรอบ **ประหยัดค่าใช้จ่าย** เช่น **ดอกเบี้ยทุก 3 เดือน, ค่าน้ำ-ค่าไฟสิ้นเดือน**, เงินเดือน
  - **Interactive Processing** ประมวลผลทันทีเมื่อรับข้อมูล: **Online** และ **Real-time** (ATM, จองตั๋ว)

## 5. ความมั่นคงปลอดภัยสารสนเทศ (น.407–409) ⭐⭐
- **CIA Triad**:
  - **Confidentiality** (ความลับ) → เข้ารหัส, Access Control, จัดชั้นความลับ
  - **Integrity** (ถูกต้องครบถ้วน ไม่ถูกแก้ไขโดยไม่ได้รับอนุญาต) → **Digital Signature**, Hash, Backup, ควบคุมการแก้ไข
  - **Availability** (พร้อมใช้งาน) → ระบบสำรอง, **BCP**, ป้องกัน **DDoS**
- **Information Security** (กรอบใหญ่ ครอบคลุมทั้งกระดาษ/ดิจิทัล/คำพูด) ⊃ **IT Security** (มาตรการทางเทคนิค: Firewall, Antivirus, Encryption) → **Cybersecurity** (ขยายสู่ Cyberspace: อินเทอร์เน็ต Cloud IoT)

### ภัยคุกคาม ช่องโหว่ ความเสี่ยง ⭐
- **Threat (ภัยคุกคาม)** = เหตุการณ์/การกระทำที่อาจก่อความเสียหาย: **Malware** · **Phishing** (หลอกด้วยเว็บ/อีเมลปลอม) · **DoS/DDoS** (ทำให้ระบบให้บริการไม่ได้) · **Zero-day** (โจมตีช่องโหว่ที่ยังไม่มีแพตช์) · **Insider Threat** (คนใน)
- **Vulnerability (ช่องโหว่)** = จุดอ่อน: ไม่อัปเดตแพตช์ · ตั้งค่าผิด (Misconfiguration) · รหัสผ่านอ่อน · Access Control บกพร่อง · Human Error
- **Risk (ความเสี่ยง)** = **โอกาส**ที่ Threat จะใช้ Vulnerability โจมตี Asset จนเกิด Impact (ยังไม่เกิดขึ้น)
  - **Risk = Threat × Vulnerability × Asset Value** (ปิดช่องโหว่ได้ → ความเสี่ยงลด)
- **การจัดการความเสี่ยง 4 แบบ**: **Avoidance** (หลีกเลี่ยง/ยกเลิกกิจกรรม) · **Mitigation** (ลด: Firewall อบรม แพตช์) · **Transfer** (โอน: **ประกันภัยไซเบอร์**, Outsource) · **Acceptance** (ยอมรับเมื่อเสี่ยงต่ำ)

## 6. มาตรการควบคุม 3 กลุ่ม (น.410–416) ⭐⭐
### 6.1 Administrative Controls (นโยบาย/กระบวนการ)
- Security Policy · อบรม · **Authentication** (ยืนยันตัวตน = ด่านแรก) → **Authorization** (กำหนดสิทธิ์ = ด่านที่ 2)
- Authentication: **Password** (นโยบาย ≥ 8–12 ตัว ผสมอักษรพิเศษ) · **MFA** ใช้ > 1 ปัจจัยจาก **Something you know** (รหัสผ่าน) / **have** (มือถือ, Token) / **are** (ลายนิ้วมือ ใบหน้า) · **Biometric** (นิ้วมือ ใบหน้า ม่านตา ปลอมยาก)
- Authorization: **Principle of Least Privilege** (ให้สิทธิ์เท่าที่จำเป็น) · **RBAC** (ตามบทบาท) · **ACL** (รายการสิทธิ์อ่าน/เขียน/ลบ รายคน)
- **CHMOD (Linux)** เลขฐานแปด 3 หลัก = **Owner · Group · Others** · **r = 4, w = 2, x = 1** (รวมกัน)
  - 7 = rwx · 6 = rw- · 5 = r-x · 4 = r-- · 0 = ---
  - **644** เจ้าของอ่าน-เขียน คนอื่นอ่านอย่างเดียว · **755** เจ้าของทำได้หมด คนอื่นอ่าน+รัน · **777** ทุกคนทำได้ทุกอย่าง (อันตราย)
- **NTFS Permission (Windows)** เรียงจากสูงไปต่ำ: **Full Control** (ทุกอย่าง + **เปลี่ยนสิทธิ์**) > **Modify** (อ่าน เขียน รัน **ลบ** แต่เปลี่ยนสิทธิ์ไม่ได้) > **Read & Execute** > **Read** · **Write** (สร้าง/เขียนไฟล์) · สิทธิ์ระดับสูงครอบคลุมระดับต่ำ · **Effective Permission** = สิทธิ์รวมจากทุกกลุ่ม · ตั้งที่ Properties → Security

### 6.2 Technical Controls (เทคโนโลยี)
- Firewall · Antivirus · **Encryption** (Plaintext → Ciphertext รักษา Confidentiality ทั้งตอนเก็บและส่ง: AES, RSA, ECC)

### 6.3 Physical Controls (กายภาพ)
- Access Control เข้าห้องเซิร์ฟเวอร์ (บัตร **RFID**, รหัส, สแกนนิ้ว) · **CCTV** 24 ชม. · Environmental (ดับเพลิง แอร์ **UPS**) · Visitor Management

## 7. Network Security (น.416–417) ⭐
- **Firewall** กรองข้อมูลระหว่างเครือข่ายภายใน–ภายนอกตามกฎ (Hardware / Software / **NGFW**)
- **IDS** (Intrusion **Detection**) **ตรวจจับและแจ้งเตือน** · **IPS** (Intrusion **Prevention**) **บล็อกการโจมตีได้ทันที** แบบ Real-time · ใช้คู่ Firewall = **Defense in Depth** (ป้องกันหลายชั้น)
- **VPN** สร้าง **Secure Tunnel** เข้ารหัสบนเครือข่ายสาธารณะ ป้องกันการดักฟัง (Eavesdropping) · ใช้ทำงานทางไกล/เชื่อมสาขา

## 8. การบริหารจัดการข้อมูล (น.417–418) ⭐
| ชั้นความลับ (Data Classification) | ตัวอย่าง | มาตรการ |
|---|---|---|
| **Top Secret** (ลับที่สุด) | แผนกลยุทธ์ผู้บริหาร, ข้อมูลทหาร/ความมั่นคง | เข้ารหัส จำกัดสิทธิ์สูงสุด ระบบแยก |
| **Confidential** (ลับเฉพาะ) | ข้อมูลลูกค้า, บัญชีเงินเดือน | เข้ารหัส + **MFA** |
| **Internal Use** (ภายใน) | คู่มือปฏิบัติงาน, รายงานภายใน | จำกัดการแชร์ในระบบภายใน |
| **Public** (สาธารณะ) | ข่าวประชาสัมพันธ์, เว็บไซต์องค์กร | ไม่จำกัด แต่ตรวจความถูกต้อง |

- **Backup 3-2-1**: **3** ชุด (ต้นฉบับ 1 + สำรอง 2) · **2** ประเภทสื่อ (เช่น HDD + Cloud) · **1** ชุดเก็บ**นอกสถานที่ (Off-site)**
- **Data Recovery** · **DRP (Disaster Recovery Plan)** → ทำให้ธุรกิจดำเนินต่อได้ (**Business Continuity / BCP**)
