# บทที่ 4 โครงสร้างข้อมูล (Data Structure)
> เล่ม 2 หน้า 159–187 · ออกบ่อย: Stack/Queue, LIFO/FIFO, การท่องทรี Pre/In/Post, Infix→Prefix/Postfix, BFS/DFS

## 1. ประเภทโครงสร้างข้อมูล (น.159)
- **Primitive** (ดั้งเดิม): Integer, Real, Character, Boolean
- **Non-Primitive** (สมัยใหม่)
  - **เชิงเส้น (Linear)**: Array, Stack, Queue, Linked List
  - **ไม่เชิงเส้น (Non-Linear)**: Tree, Graph

## 2. ลำดับเข้า–ออก (น.160)
- **FIFO = LILO** → Queue (เข้าก่อนออกก่อน)
- **LIFO = FILO** → Stack (เข้าทีหลังออกก่อน)

## 3. Array (น.160–161)
- เก็บเรียงต่อเนื่อง ข้อมูลชนิดเดียวกัน อ้างด้วย **Index เริ่มที่ 0** (ขนาด 10 → index 0–9)
- เข้าถึงแบบ **Random Access** (เร็ว) · Static Array ขนาดคงที่ / Dynamic Array เปลี่ยนขนาดได้
- ใช้: เรียงข้อมูล, Pixel ภาพ, Matrix, CPU Scheduling · อาร์เรย์ 2 มิติ = ตาราง (ลังขวดน้ำ)
- ข้อเสีย: แทรกกลางต้องขยับทุกตัว, ขนาดตายตัว

## 4. Stack (น.161–164) ⭐
- **LIFO** เหมือนจานซ้อน · เข้า–ออกทางเดียวที่ **Top**
- **Push** = ใส่ (ต้องเช็คเต็ม → ถ้าเกิน = **Stack Overflow**) · **Pop** = เอาบนสุดออก+ลบ · **Stack Top/Peek** = ดูบนสุดไม่ลบ
- ใช้: **Undo/Redo**, Back/Forward ของเบราว์เซอร์, ประวัติการโทร, การใส่เสื้อผ้า, **แปลงนิพจน์ infix/prefix/postfix**, DFS
- สร้างด้วย Array (Static ต้องจองขนาด) หรือ Linked List (Dynamic ไม่เต็มจนกว่าหน่วยความจำหมด)
- เข้าถึงแบบเรียงลำดับ (Sequential) ไม่ใช่ Random

## 5. Queue (น.164–167) ⭐
- **FIFO** เหมือนเข้าแถว · เข้าที่ **Tail/Rear** ออกที่ **Head/Front**
- **Enqueue** = เข้า · **Dequeue** = ออก · front(), rear(), size(), isEmpty()
- ใช้: **คิวงานพิมพ์ (Print Spooling)**, CPU Scheduling, บัฟเฟอร์คีย์บอร์ด, Router/Switch, คิวเพลง, Call Center, **BFS**
- **Priority Queue** = ออกก่อนตามความสำคัญ (ห้องฉุกเฉิน, OS ให้ I/O ก่อน, ถ่ายเอกสาร 2 แผ่นแซง 100 แผ่น)

## 6. Linked List (น.167–170)
- โหนด = **Data + Next (Pointer)** · แทรก/ลบแค่ย้ายตัวชี้ ไม่ต้องขยับข้อมูล
- ข้อดี: Dynamic ไม่เปลืองพื้นที่ จองเท่าที่ใช้ · ข้อเสีย: ใช้หน่วยความจำต่อโหนดมากกว่า Array (มี Pointer), เข้าถึงแบบลำดับ (ช้า)
- **Single** (ทางเดียว) · **Double** (ไป–กลับ) · **Circular Double** (วนกลับจุดเริ่ม เช่น เพลย์ลิสต์วน)
- ใช้: เพลย์ลิสต์, Timeline ตัดต่อวิดีโอ, ปัดซ้าย/ขวา, News Feed, ทำ Stack/Queue แบบ Dynamic

## 7. Tree (น.171–179) ⭐
- ต้นไม้กลับหัว: **Root** บนสุด, **Leaf** ล่างสุด (ไม่มีลูก), ความสัมพันธ์แบบลำดับชั้น
- **Binary Tree** = แต่ละโหนดมีลูกไม่เกิน 2 (Left/Right) · **Binary Search Tree**: **L < N ≤ R** (Inorder ได้ค่าเรียงจากน้อยไปมาก)
- การท่องทรี (จำตำแหน่ง N, L มาก่อน R เสมอ):
  - **Preorder = N L R** → ได้ **Prefix**
  - **Inorder = L N R** → ได้ **Infix**
  - **Postorder = L R N** → ได้ **Postfix**
- ใช้: File Explorer/โฟลเดอร์, ผังองค์กร, หมวดหมู่สินค้า/หนังสือ, สายบังคับบัญชา
- **Expression Tree**: ใบ = ตัวถูกดำเนินการ, โหนดแม่ = เครื่องหมาย
  - 3+((5+9)*2) → Prefix `+3*+592` · Postfix `359+2*+`
  - (a+b)*(c*(d+e)) → Prefix `*+ab*c+de` · Postfix `ab+cde+**`
  - ((a+b)*c)+7 → Prefix `+*+abc7` · Postfix `ab+c*7+`
- Prefix/Postfix ไม่ต้องใช้วงเล็บ คอมพิวเตอร์ประมวลผลเร็วกว่า Infix

## 8. Graph (น.180–187)
- **Vertex** (จุด) + **Edge** (เส้น) · โครงสร้างแบบตาข่าย ไม่เชิงเส้น
- **Directed (Digraph)** มีลูกศร (เส้นเรียก Arc) · **Undirected** เดินได้สองทาง · **Weighted** เส้นมีค่า (ระยะทาง/เวลา/ค่าใช้จ่าย)
- **Degree** = จำนวนเส้นที่ต่อกับจุด · Indegree (เข้า) / Outdegree (ออก)
- การท่องกราฟ: **BFS** (แนวกว้าง ใช้ **Queue**) · **DFS** (แนวลึก ใช้ **Stack**)
- Shortest Path: **Dijkstra**, Bellman-Ford → Google Maps, เส้นทางบิน, โลจิสติกส์, เดินสายเครือข่าย
- Tree เป็นกราฟชนิดหนึ่งที่ไม่มีวงวน (Cycle)
