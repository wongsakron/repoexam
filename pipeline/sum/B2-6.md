# บทที่ 6 วิทยาการข้อมูล (Data Science)
> เล่ม 2 หน้า 235–245 · ออก: BI, 4V ของ Big Data, Database vs Data Warehouse vs Data Lake, Data Mining, Data Visualization

## 1. Data Science & BI (น.235)
- **Data Science** = นำข้อมูลมาใช้ประโยชน์: เก็บ (Collect) → จัดการ (Manage) → วิเคราะห์ (Analyze) → ตัดสินใจ (Decision)
- **Business Intelligence (BI)** = แปลงข้อมูลเป็นข้อมูลเชิงลึก (Insight) ช่วยตัดสินใจ: Data Preparation · Data Querying · **Data Visualization** · Performance Metrics Reporting · Data Mining

## 2. Big Data – 4V (น.235–236) ⭐
- **Volume** ปริมาณมาก (วัดเป็น GB/TB) · **Variety** หลากหลาย (ตาราง เอกสาร ภาพ เสียง โซเชียล) · **Velocity** เพิ่มเร็ว (โอนเงิน 10 ล้านครั้ง/ชม.) · **Veracity** คุณภาพ/ความน่าเชื่อถือ → ต้องทำ **Data Cleansing**
- (บางตำราเพิ่ม **Value** = 5V) · ⚠️ "Variable" ไม่ใช่ V ของ Big Data
- จำ: Velo เร็วทันตา · Vera คุณภาพดี · Variety หลายกลุ่ม · Volume มากมาย

## 3. ที่เก็บข้อมูล (น.237–238)
- **Database**: ข้อมูลมีโครงสร้าง (Structured) จากแหล่งเดียว ใช้ SQL · ข้อมูลปัจจุบัน (Real-time) · งานธุรกรรมประจำวัน
- **Data Warehouse**: ข้อมูลมีโครงสร้างจาก **หลายแหล่ง** รวมกัน · ข้อมูล**ย้อนหลัง (Historical)** · ใช้ทำรายงาน BI/DSS ของผู้บริหาร
  - คุณสมบัติ (Inmon): Subject-Oriented · Integrated · Time-Variant · Non-Volatile
- **Data Lake**: เก็บ**ข้อมูลดิบทุกรูปแบบ** ไม่ต้องแปลงก่อน (Structured + Semi-structured + Unstructured) · ต้นทุนถูก ยืดหยุ่น · ใช้โดย Data Scientist
- ชนิดข้อมูล: **Structured** (ตาราง/Excel) · **Semi-Structured** (**JSON, XML, HTML**) · **Unstructured** (ข้อความ รูปภาพ เสียง)

## 4. Data Mining (น.239–240) ⭐
- = เทคนิคค้นหา **รูปแบบ/ความสัมพันธ์ที่ซ่อนอยู่** ในข้อมูลขนาดใหญ่ แปลงข้อมูลดิบเป็นความรู้ (สาขาหนึ่งของ Data Science)
- ตัวอย่างคลาสสิก: ซูเปอร์มาร์เก็ตพบว่า **ลูกค้าซื้อเบียร์มักซื้อผ้าอ้อม** → จัดชั้นวาง/โปรโมชัน (Association Rule / Market Basket)
- วัตถุประสงค์: KDD (Knowledge Discovery in Databases) · Knowledge Extraction · Data Archeology · Data Exploration · Data Pattern Processing · Data Dredging
- การใช้: ทำนายยอดขาย/ลูกค้าเป้าหมาย · ธนาคารประเมินความเสี่ยงสินเชื่อ/บัตรเครดิต · วางผังรายการทีวี · ทำนายอายุ Disk
- เทคนิคที่ใช้บ่อย: Classification (Decision Tree) · Clustering · Association Rule · Neural Network
- แหล่งข้อมูล: Database · Data Warehouse · WWW

## 5. Data Visualization (น.241–245)
- = ทำข้อมูลเป็นภาพ "A picture is worth a thousand words" ให้เห็น **Insight**/แนวโน้มทันที
- ประโยชน์: เข้าใจง่าย · เห็น Insight · ประหยัดเวลาตัดสินใจ · เห็นจุดน่าสนใจ · น่าสนใจขึ้น
- รูปแบบ: **Charts** (Pie = สัดส่วน, Gauge = ความเข้มข้น) · **Graphs** (ความสัมพันธ์ 2 ตัวแปร แกน X/Y เห็นเทรนด์) · **Tables** · **Maps** (ข้อมูลเชิงพื้นที่) · **Dashboards** (สรุปหลายกราฟ นิยมแบบ Real-time)
- **Infographic** = Info + Graphic ใช้ **Storytelling** ผสมภาพ/Data Viz/เสียง/วิดีโอ เล่าเรื่อง
- เครื่องมือ: **Microsoft Power BI** · **Tableau** · **Looker Studio** (ชื่อเดิม Google Data Studio) · **Excel** (Pivot Table, UNIQUE, COUNTIF, IF/IFS, VLOOKUP/HLOOKUP/XLOOKUP)
- Excel: **1,048,576 แถว × 16,384 คอลัมน์** · 1 เซลล์ใส่ได้ **32,767 ตัวอักษร**
