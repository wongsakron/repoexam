# บทที่ 1 ระบบเครือข่ายและความมั่นคงปลอดภัยไซเบอร์
> ชุดแนวสอบกระทรวงการคลัง · หมวด 1 (สัดส่วนประมาณ 20–25%) · ออก: จับคู่ OSI Layer กับโปรโตคอล/อุปกรณ์, คำนวณ Subnet, เปรียบเทียบ IDS/IPS/WAF/SIEM, การเข้ารหัส PKI/TLS

## 1. โครงสร้างข้อสอบกระทรวงการคลัง
- ปรนัย **100 ข้อ 200 คะแนน** แบ่ง 7 หมวด ชุด 3 นี้แยกบทตามหมวด และมีโหมด **จำลองสอบกระทรวงการคลัง** ที่สุ่มตามสัดส่วน
- ข้อสอบเน้น 3 แบบ: **เปรียบเทียบเทคโนโลยีที่คล้ายกัน** · **วิเคราะห์สถานการณ์** (Troubleshooting, Security Incident) · **ตัวเลขและระยะเวลาตามกฎหมาย**
- ด่าน 1 = ง่าย (นิยาม/ตัวเลข) · ด่าน 2 = กลาง (เปรียบเทียบ/คำนวณ) · ด่าน 3 = ยาก (สถานการณ์/กับดัก)

## 2. OSI 7 Layers และ TCP/IP ⭐⭐
| OSI | TCP/IP | PDU | โปรโตคอล / อุปกรณ์ |
|---|---|---|---|
| 7 Application | Application | Data | HTTP, HTTPS, FTP, SMTP, DNS, DHCP |
| 6 Presentation | Application | Data | SSL/TLS, JPEG, MPEG — เข้ารหัส บีบอัด แปลงรหัส |
| 5 Session | Application | Data | NetBIOS, RPC — เปิด/ปิดและควบคุมการเชื่อมต่อ |
| 4 Transport | Transport | **Segment** (TCP) / Datagram (UDP) | TCP (Three-way Handshake), UDP, Port |
| 3 Network | Internet | **Packet** | IPv4, IPv6, ICMP, IPSec, OSPF, BGP — **Router** |
| 2 Data Link | Network Access | **Frame** | Ethernet 802.3, Wi-Fi 802.11, **ARP**, VLAN 802.1Q — **Switch L2** |
| 1 Physical | Network Access | **Bit** | UTP, Fiber, Hub, Repeater, NIC |

- **Switch L2** แยก Collision Domain แต่ยังอยู่ Broadcast Domain เดียวกัน · **Router** แยก Broadcast Domain · **Switch L3** ทำ Inter-VLAN Routing
- **Load Balancer** L4 ดู IP/Port · L7 ดู URL/Header/Cookie · วิธีกระจาย: Round Robin, **Least Connections**

## 3. Subnet ⭐⭐
- Host ใช้ได้ = **2^h − 2** (h = 32 − prefix) · จำนวนซับเน็ต = **2^n** (n = บิตที่ยืม)
- /26 → 62 เครื่อง · /27 → Mask 255.255.255.224, 30 เครื่อง · /23 → 510 เครื่อง
- หา Network/Broadcast: ขนาดบล็อก = 256 − เลข Mask แล้วดูว่า IP ตกอยู่ช่วงไหน (ดูวิธีละเอียดในเล่ม 2 บท 11)
- IPv6 = **128 บิต** ฐานสิบหก 8 กลุ่ม · มี Unicast / Multicast / Anycast · **ไม่มี Broadcast**

## 4. โปรโตคอลที่ต้องจำ
- **DNS** พอร์ต 53 · **DHCP** UDP 67/68 ขั้นตอน **DORA** (Discover → Offer → Request → Acknowledge) · HTTP 80 / **HTTPS 443**
- **VLAN** 802.1Q จำกัด Broadcast Domain · **VPN** IPSec (Layer 3) vs SSL/TLS VPN (Application)
- **OSPF** = IGP แบบ Link-State (Dijkstra) · **BGP** = EGP เชื่อมระหว่าง Autonomous System
- Cloud: **IaaS** ผู้ใช้ดูแล OS เอง · **PaaS** ดูแลแค่โค้ดและข้อมูล · **SaaS** ใช้ซอฟต์แวร์สำเร็จรูป

## 5. ความมั่นคงปลอดภัยไซเบอร์ ⭐⭐
- **CIA**: Confidentiality (เข้ารหัส, Access Control) · Integrity (Hash, Digital Signature) · Availability (Redundancy, Backup)
- ภัยคุกคาม: Ransomware (กระทบ C และ A) · Phishing · **DDoS** (กระทบ A) · **MITM** เช่น ARP Spoofing · **Zero-day**

| อุปกรณ์ | หน้าที่ |
|---|---|
| **NGFW** | กรองทราฟฟิก + Deep Packet Inspection + รู้จักผู้ใช้/แอป |
| **IDS** | ตรวจจับและ **แจ้งเตือน** (Passive) |
| **IPS** | ตรวจจับและ **บล็อกทันที** (Inline) |
| **WAF** | ป้องกันเว็บแอป Layer 7 เช่น SQL Injection, XSS |
| **SIEM** | รวม Log ทั้งองค์กร วิเคราะห์ Correlation แจ้งเตือน |
| **EDR** | เฝ้าระวังพฤติกรรมบนเครื่องปลายทาง |

## 6. การเข้ารหัสและ PKI ⭐⭐
- **Symmetric** (AES) กุญแจเดียว เร็ว แต่ส่งกุญแจยาก · n คนต้องใช้ n(n−1)/2 ดอก
- **Asymmetric** (RSA, ECC) คู่กุญแจ Public/Private · **CA** ออกใบรับรองดิจิทัล
- **TLS**: Asymmetric ตอน Handshake แลก Session Key → ส่งข้อมูลจริงด้วย Symmetric
- ⚠️ **ต้องการความลับ** → เข้ารหัสด้วย **Public Key ของผู้รับ** · **Digital Signature** → ผู้ส่งเข้ารหัส **Hash ด้วย Private Key ของผู้ส่ง** ผู้รับตรวจด้วย Public Key ผู้ส่ง
- **ISO/IEC 27001** = ISMS (วงจร PDCA) · **Zero Trust** = Never Trust, Always Verify + Least Privilege + Micro-segmentation
