# บทที่ 3 คอมพิวเตอร์กราฟิก
> เล่ม 1 หน้า 73–80 · ออก: RGB vs CMYK, องค์ประกอบงานออกแบบ ความหมายของสี/เส้น, ระบบสี HSB/LAB, 2D vs 3D

## 1. หลักการ (น.73)
- ภาพบนจอเกิดจากแสง **RGB** ผสมเป็นจุด **Pixel** (Picture + Element)
- ภาพมี 2 แบบ: **Raster** (จุดพิกเซล ขยายแตก) · **Vector** (สมการคณิตศาสตร์ ขยายไม่แตก)

## 2. องค์ประกอบงานกราฟิก (Element of Design) (น.73–77)
1. **เส้น (Line)**: แนวนอน = สงบ ราบเรียบ · แนวตั้ง = มั่นคง แข็งแรง · **ทแยง = ไม่มั่นคง เคลื่อนไหว** · ตัดกัน = ประสาน แข็งแกร่ง · **โค้ง = อ่อนช้อย** · ประ = โปร่ง ไม่สมบูรณ์/ส่วนที่ซ่อน · ก้นหอย = เคลื่อนไหวไม่สิ้นสุด · คลื่น = เคลื่อนไหวนุ่มนวล · **ซิกแซ็ก = น่ากลัว อันตราย**
2. **รูปร่าง (Shape)** 2 มิติ · **รูปทรง (Form)** 3 มิติ: เรขาคณิต · ธรรมชาติ · อิสระ · **น้ำหนัก (Value)** = ความเบา–หนักจากสีและแสงเงา
3. **พื้นผิว (Texture)** เช่น กระดาษ Glossy = หรู · ลายสนิม = เก่า
4. **สี (Color)** หัวใจของงาน: โทนร้อน = ตื่นเต้น · โทนเย็น = สุภาพ สบาย
   - แดง = เร้าใจ มีอำนาจ · **ส้ม = พลัง สนุกสนาน** · เหลือง = สดใส ร่าเริง · เขียวอ่อน = สดชื่น · เขียวเข้ม = หดหู่ · **น้ำเงิน = เชื่อมั่น สงบ หนักแน่น** · ฟ้า = สงบ นุ่มนวล · ชมพู = แจ่มใส สมหวัง · **ม่วง = ลี้ลับ โศกเศร้า** · ดำ = มืดมน ลี้ลับ · ขาว = บริสุทธิ์ · เทา = เข้าได้ทุกสี · น้ำตาล = เก่าแก่ · ทอง/เงิน = มั่นคง
5. **ตัวอักษร (Typography)** · 6. **ที่ว่าง (Space)** ช่วยเน้นจุดเด่น · 7. **ทิศทาง (Direction)** นำสายตาสู่จุดสนใจ

## 3. ระบบสี (น.77–80) ⭐
- **RGB** (แสง) แม่สี แดง เขียว น้ำเงิน · **ผสมแบบบวก (Additive)** รวมกันได้**สีขาว** · 16.7 ล้านสี · ใช้กับ**จอภาพ** งานนำเสนอ เว็บ
  - Visible Light: ม่วงความถี่สูงสุด แดงความถี่ต่ำสุด
- **CMYK** (หมึกพิมพ์) Cyan, Magenta, Yellow, **K = Key/Black** · **ผสมแบบลบ (Subtractive)** · ใช้กับ**งานพิมพ์** (ถ้าใช้ RGB พิมพ์สีจะเพี้ยน)
  - เขียว+น้ำเงิน = Cyan · แดง+น้ำเงิน = Magenta · แดง+เขียว = Yellow · ขาว = CMYK 0% ทุกค่า · ดำ = K 100%
  - งานพิมพ์ใช้ **CMYK 300 dpi** · งานจอ/เว็บใช้ **RGB 72 ppi**
- **HSB** (ตามการมองเห็นของมนุษย์): **Hue** สี (วงล้อสี) · **Saturation** ความสด 0–100 · **Brightness** ความสว่าง 0–100
- **LAB** (**ไม่ขึ้นกับอุปกรณ์ Device Independent**, กำหนดโดย **CIE**) ครอบคลุมทุกสีของ RGB และ CMYK · L = ความสว่าง · A = เขียว↔แดง · B = น้ำเงิน↔เหลือง · ใช้กำหนดสีธงชาติ

## 4. 2 มิติ vs 3 มิติ (น.80)
- **2D** แกน X (กว้าง) + Y (ยาว): ภาพถ่าย รูปวาด กราฟ การ์ตูน · โปรแกรม Photoshop, Illustrator, CorelDRAW, GIMP, Visio
- **3D** เพิ่มแกน **Z** (ความลึก/ความหนา) · โปรแกรม **3ds Max, Maya** (Blender)
