# บทที่ 9 การท่องอินเทอร์เน็ตและใช้โปรแกรมประยุกต์
> เล่ม 1 หน้า 309–346 · เกี่ยวกับหลักสูตรกรมที่ดินด้านเทคโนโลยีใหม่ ⭐ ออก: Cookie, Incognito, Web 1.0/2.0/3.0, Blockchain, CMS, E-Commerce (B2C…G2C), Prompt, สูตร Excel และค่า Error, จดหมายเวียน, PowerPoint

## 1. เว็บบราวเซอร์ & เว็บไซต์ (น.309–311)
- ส่วนประกอบ Chrome: Title bar (แท็บ) · Menu bar · **Address Bar** (พิมพ์ URL หรือค้นหาได้) · Bookmark bar · Apps (Chrome Web Store)
- **เว็บไซต์** = รวมหลาย **เว็บเพจ** เชื่อมกันด้วย **Hyperlink** · สร้างด้วย **HTML** เป็นหลัก (+CSS, JavaScript, PHP, SQL)
- **Home Page** = หน้าแรกของเว็บ (เหมือนปกหนังสือ) · **Web Page** = หน้าย่อยแต่ละหน้า

## 2. Cookie & Incognito (น.312–313) ⭐
- **Cookie** = ไฟล์เล็กที่เว็บสร้างเก็บในเครื่องผู้ใช้ จำการล็อกอิน ตะกร้าสินค้า ค่าที่ตั้งไว้ (มีมาตั้งแต่ปี **1994**)
  - **First-party Cookie** เว็บที่เราเข้าสร้างเอง · **Third-party Cookie** เว็บอื่นสร้าง (โฆษณา) ปิดได้
  - Cookie Law: EU ใช้ **GDPR** (25 พ.ค. 2018) · ไทยใช้ **PDPA** บังคับ **1 มิ.ย. 2565** → เว็บต้องขอความยินยอมก่อนเก็บคุกกี้
- **Incognito / Private / InPrivate** ไม่เก็บประวัติ คุกกี้ และข้อมูลฟอร์ม (แต่ Bookmark/ไฟล์ดาวน์โหลดยังอยู่) · **ไม่ได้ซ่อนตัวตน**: ISP และเว็บยังเห็น IP เดิม · ไม่กันมัลแวร์/Keylogger

## 3. วิวัฒนาการเว็บ (น.313–315) ⭐
| ยุค | ลักษณะ | ตัวอย่าง |
|---|---|---|
| **Web 1.0** | **Static** อ่านอย่างเดียว สื่อสาร**ทางเดียว** | เว็บข่าว เหมือนหนังสือพิมพ์ออนไลน์ |
| **Web 2.0** | **Dynamic** สื่อสาร**สองทาง** ผู้ใช้สร้างเนื้อหา · จุดอ่อน: **Privacy** (ข้อมูลเป็นของเจ้าของเว็บ) | Social Network |
| **Web 3.0** | **กระจายอำนาจ (Decentralized)** ไม่มีตัวกลาง ผู้ใช้คุมข้อมูลเอง ใช้ Blockchain + AI | Private Key, Crypto, (Metaverse บางส่วน) |

- **Tim Berners-Lee** (CERN) ผู้คิดค้น **WWW** (HTML, URL, HTTP) ผู้ก่อตั้ง **W3C** · **Dr. Gavin Wood** ร่วมก่อตั้ง **Ethereum**, สร้าง Polkadot, คนตั้งชื่อ Web3

## 4. Blockchain & Web 3.0 (น.315–318) ⭐
- **Blockchain** = บัญชีแยกประเภท**กระจายศูนย์** ทุกคนถือสำเนาเดียวกัน เชื่อมเป็นโซ่ ตรวจสอบด้วย **Consensus** · แก้ไข/ปลอมแปลงยาก · ทำธุรกรรมแบบ **P2P** ไม่ผ่านตัวกลาง (ธนาคาร)
- **Satoshi Nakamoto** สร้าง **Bitcoin** ปี **2008** (สกุลเงินดิจิทัลแรก)
- **Private Key** ใช้ยืนยันตัวตน เข้า Digital Wallet, Play to Earn, **DeFi** (การเงินกระจายศูนย์), **NFT** (Non-Fungible Token)
- **Cryptocurrency** = สินทรัพย์ดิจิทัลเข้ารหัสบน Blockchain (ต่างจาก **Fiat Currency** เงินตราทั่วไป)
- **Metaverse** โลกเสมือน แต่ยังถูกบริษัทเอกชนควบคุม จึง**ยังไม่ใช่** Web 3.0 แท้
- **Wolfram Alpha** = Computational Knowledge Engine (ผู้ผลิต Mathematica) **คำนวณ**คำตอบเชิงข้อเท็จจริง ไม่ใช่แค่ค้นหาลิงก์

## 5. ขั้นตอนพัฒนาเว็บไซต์ (น.319–321)
1. **วางแผน** (เวลา · ทีม 3 ฝ่าย: โปรแกรม/ออกแบบ/เนื้อหา · งบ · อุปกรณ์ · ปัญหา)
2. **รวบรวมและวิเคราะห์โครงสร้าง** (เนื้อหา ภาพ เสียง)
3. **ออกแบบและสร้าง** (จุดประสงค์ แพลตฟอร์ม **แผนผังเว็บไซต์** หน้าตา)
4. **ทดสอบและปรับปรุง** (ทดสอบออฟไลน์หลายเบราว์เซอร์/อุปกรณ์)
5. **เผยแพร่** (จด **Domain Name** + เช่า **Web Hosting** แล้ว Upload · มี Counter นับผู้ชม)
6. **พัฒนา/อัปเดต** สม่ำเสมอ (ช่วย **SEO**)

## 6. CMS & เครื่องมือสร้างเว็บ (น.322–324) ⭐
- **CMS (Content Management System)** ลดคน/เวลา/เงินในการทำเว็บ มี **Admin Panel** จัดการผ่านเว็บ ใช้ภาษาสคริปต์ (PHP, Python) + Web Server (Apache) + DB (MySQL)
  - **WordPress** นิยมที่สุด (~36% ของเว็บโลก) ใช้ง่ายสุด Plugin/Theme เยอะ SEO ดี
  - **Joomla!** เว็บราชการ/โรงเรียนไทยนิยม ฟรี
  - **Drupal** **ปลอดภัยที่สุด** ยืดหยุ่นสูง เหมาะมืออาชีพ ไม่เหมาะมือใหม่
- โปรแกรมแก้ไขโค้ด: **Dreamweaver** (มุมมอง **WYSIWYG** = What You See Is What You Get) · **VS Code** (นิยมสุด Extensions เยอะ) · **Notepad++** (เบา ~8 MB ไฮไลต์โค้ด)
- No-Code: **Wix** (Drag & Drop, E-commerce) · **Google Sites** (ฟรี ใช้ร่วม Workspace) · Artisteer (สร้าง Template ให้ CMS) · Google Web Designer (แบนเนอร์ HTML5)

## 7. E-Commerce (น.324–328) ⭐
- B = Business · C = Consumer · G = Government
  - **B2C** ร้านขายผู้บริโภค · **B2B** ธุรกิจขายธุรกิจ (วัตถุดิบ) · **C2B** ผู้บริโภคขายให้ธุรกิจ · **C2C** ผู้บริโภคขายกันเอง ผ่าน Marketplace
  - **B2G** ธุรกิจขายให้รัฐ (**จัดซื้อจัดจ้างภาครัฐ**/e-GP) · C2G · **G2B** · **G2C** (รัฐให้บริการประชาชน)
  - **มีตัว G = e-Government** (รัฐบาลอิเล็กทรอนิกส์)
- รูปแบบ: **M-Commerce** (ผ่านมือถือ) · Enterprise E-commerce · Social Media E-commerce
- ข้อดี: เข้าถึงตลาดทั่วโลก · สั่งง่าย · **ต้นทุนดำเนินการต่ำ** เปิด 24 ชม. · ติดต่อลูกค้าตรง | ข้อท้าทาย: เจรจาตัวต่อตัวไม่ได้ · ปัญหาเทคนิค · **ความปลอดภัยข้อมูล** (ต้องมีนโยบายความเป็นส่วนตัว)

## 8. Prompt สำหรับ Generative AI (น.328–329)

### สูตร Excel ⭐
| สูตร | ใช้ทำ |
|---|---|
| **SUM / SUMIF(range, criteria, [sum_range])** | ผลรวม / ผลรวมตามเงื่อนไข |
| **AVERAGE · MAX · MIN** | ค่าเฉลี่ย สูงสุด ต่ำสุด |
| **SMALL(array,k) · LARGE(array,k)** | ค่าน้อยสุด/มากสุด **อันดับที่ k** |
| **COUNT** | นับเซลล์ที่เป็น**ตัวเลข** (COUNTA นับเซลล์ไม่ว่าง) |
| **TODAY()** | วันที่ปัจจุบัน |
| **BAHTTEXT** | ตัวเลข → คำอ่านเงินบาท |
| **UPPER / LOWER** | ตัวพิมพ์ใหญ่ / เล็ก |

| **CONCATENATE** | เชื่อมข้อความ |
| **LEN** | นับจำนวนตัวอักษร |
| **RANDBETWEEN(a,b)** | สุ่มจำนวนเต็ม |
| **ROUND / ROUNDUP / ROUNDDOWN** | ปัดทศนิยม / ปัดขึ้น / ปัดลง |

### ค่า Error ใน Excel (ขึ้นต้นด้วย #) ⭐
| Error | ความหมาย |
|---|---|
| **#VALUE!** | ชนิดข้อมูลในเซลล์อ้างอิงไม่ถูกต้อง |
| **#DIV/0!** | **หารด้วยศูนย์**หรือเซลล์ว่าง |
| **#N/A** | ไม่มีค่า/หาค่าไม่พบ |
| **#NAME?** | ชื่อฟังก์ชันผิด/Excel ไม่รู้จักชื่อ |
| **#NULL!** | อ้างช่วงเซลล์ผิด (ไม่ใส่ :) |
| **#NUM!** | ค่าตัวเลขในสูตรไม่ถูกต้อง |
| **#REF!** | **อ้างอิงเซลล์ที่ใช้ไม่ได้** (ถูกลบ) |
| **####** | คอลัมน์แคบเกินแสดงค่า |

### Word ⭐
- **จดหมายเวียน (Mail Merge)** = เอกสารเนื้อความเดียวกัน ต่างกันแค่ชื่อ/ที่อยู่ (หนังสือเชิญ เกียรติบัตร)
  - ใช้ 2 ไฟล์: **เอกสารหลัก (Main Document)** + **แหล่งข้อมูล (Data Source)** (ตาราง Word/Excel)
  - ขั้นตอน: Mailings → **Select Recipients** (Use Existing List) → **Insert Merge Field** → Preview Results → **Finish & Merge** (Edit Individual Documents / Print Documents)
- **สารบัญอัตโนมัติ** = กำหนด Style **Heading 1/2** → References → Table of Contents (อัปเดตเลขหน้าได้)
- **บรรณานุกรมอัตโนมัติ** = References → Insert Citation → Add New Source → Bibliography (รูปแบบ **APA**, ISO, IEEE)
- **OneDrive** เก็บเวอร์ชันย้อนหลังได้ **25 เวอร์ชัน** (Version History)
