# บทที่ 1 ภาษาที่ใช้ในการเขียนโปรแกรม
> เล่ม 2 หน้า 11–37 · ตรงหลักสูตรกรมที่ดิน "เขียนชุดคำสั่งภาษาคอมพิวเตอร์" ⭐ ออก: ระดับภาษา 5 ยุค, ตัวแปลภาษา, OOP 4 ประการ, ภาษาแต่ละตัว, Framework, IDE

## 1. Technology Stack (น.11–12)
- ชุดเทคโนโลยีที่ใช้สร้างเว็บ/แอป = ภาษา + Framework + Library + Server + UI/UX + เครื่องมือ
- **Front-end (Client Side)**: HTML5 (โครงสร้าง) · CSS (ตกแต่ง) · JavaScript (โต้ตอบ)
- **Back-end (Server Side)**: Python, Java, Ruby, PHP, .NET, JavaScript (Node.js) + Database (MySQL, Oracle)
- เปรียบการสร้างบ้าน: **Library** = เขียนเองทั้งหมดมีแค่เครื่องมือ · **Framework** = มีโครงสำเร็จรูป+คู่มือ · **CMS** = ซื้อบ้านจัดสรรแล้วตกแต่ง

## 2. ประเภทภาษา 5 ประเภท (น.13–16)
1. **Programming Language** แปลด้วย Compiler (C, C++, Java)
2. **Scripting Language** แปลด้วย **Interpreter** ช้ากว่า · Client Side (JavaScript, VBScript) / Server Side (Python, PHP) · ภาษาสคริปต์ทุกตัวเป็นภาษาโปรแกรม แต่ภาษาโปรแกรมไม่ใช่สคริปต์ทุกตัว
3. **Markup Language** แสดงโครงสร้าง/รูปแบบข้อมูล: **HTML, XML**
4. **Style Sheet Language** กำหนดการแสดงผล: **CSS**, XSL, DSSSL
5. **Query Language** ถาม/จัดการข้อมูลใน DBMS: **SQL** (มาตรฐาน **ANSI**), SPARQL, MDX

## 3. ระดับของภาษา 5 ระดับ/ยุค (น.16–19) ⭐
| ยุค | ระดับ | ลักษณะ | ตัวอย่าง |
|---|---|---|---|
| 1 | ภาษาเครื่อง | เลข 0/1 เครื่องเข้าใจทันที ขึ้นกับเครื่อง | Machine Code |
| 2 | ภาษาระดับต่ำ (อิงเครื่อง) | ตัวย่อ **Mnemonic** (LOAD, ADD, SUB, MOV) | **Assembly** (แปลด้วย Assembler) |
| 3 | ภาษาระดับสูง | คำภาษาอังกฤษ ต้องมี Translator | C, Java, COBOL, Fortran |
| 4 | ระดับสูงมาก (**4GL**) | ไร้กระบวนคำสั่ง บอกแค่ "ทำอะไร" ไม่ต้องบอก "ทำอย่างไร" | **SQL**, Visual Basic, PHP, Python |
| 5 | **ภาษาธรรมชาติ** | ไม่สนไวยากรณ์ ใช้ AI/Knowledge Base แปล | **Prolog**, Mercury, OPS5 · Siri, Alexa, Autocomplete |

## 4. ตัวแปลภาษา (Translator) (น.19–20) ⭐
- **Assembler** แปล Assembly → ภาษาเครื่อง
- **Compiler** แปล**ทั้งโปรแกรม** (Source → Object Program) เก็บไว้ใช้ซ้ำไม่ต้องแปลใหม่ · C, C++, C#, Java, Go, Swift, Kotlin, COBOL, Pascal, Fortran
- **Interpreter** แปลและทำงาน**ทีละคำสั่ง** ต้องแปลใหม่ทุกครั้ง · Python, JavaScript, PHP, Perl, Ruby
- บางภาษามีทั้งสองแบบ: BASIC, Java

## 5. OOP – การเขียนโปรแกรมเชิงวัตถุ (น.20–23) ⭐
- **Class** = พิมพ์เขียว · **Object** = สิ่งที่สร้างจากคลาส · **Properties/Attributes** = ข้อมูล (สี ยี่ห้อ) · **Methods** = การกระทำ (start, stop)
- **4 Pillars**:
  - **Encapsulation** ห่อหุ้ม/ซ่อนข้อมูล (private) เข้าถึงผ่านเมธอดเท่านั้น (เติมน้ำมันต้องผ่านฝาถัง)
  - **Inheritance** สืบทอดคุณสมบัติจากคลาสแม่ (`extends`)
  - **Polymorphism** คำสั่งเดียวกัน ตอบสนองต่างกัน (start() แบบกดปุ่ม vs บิดกุญแจ)
  - **Abstraction** แสดงเฉพาะส่วนจำเป็น ซ่อนรายละเอียดซับซ้อน

## 6. ภาษาสำคัญ (น.23–33)
- **C** (Bell Labs/AT&T, 2515) เร็ว ใกล้ฮาร์ดแวร์ ใช้เขียน OS (Unix, Windows) · **C++** = C + OOP
- **Swift** (Apple: iOS/macOS แทน Objective-C) · **Kotlin** (Android แทน Java, Static Type, โค้ดสั้นลง 40%)
- **Java** (Sun Microsystems, 2534) ทำงานได้ทุกแพลตฟอร์ม Android, ธนาคาร · **C#** (Microsoft .NET, Unity)
- **Visual Basic** (Microsoft) เขียนโปรแกรมเชิงจินตภาพบน GUI · **Delphi** = Visual + Pascal
- **Python** นิยมอันดับ 1 (2024) ง่าย AI/Data · **Go/Golang** (Google) Backend, Compiler, Static Type · **R** สถิติ/Data Science · **TypeScript** = JavaScript + Static Typing
- **PHP** ฝั่งเซิร์ฟเวอร์ คู่ MySQL (Laravel) · **Ruby** (Ruby on Rails) · **Perl** จัดการ Text · **Dart** (Google) + **Flutter**
- **Fortran** ภาษาระดับสูงภาษาแรก งานวิทยาศาสตร์ · **ALGOL** ต้นตระกูล Pascal · **COBOL** งานธุรกิจ · **Pascal** สอนโปรแกรมโครงสร้าง
- **LISP**, **Prolog** → งาน AI · **Logo** = "เต่า" สอนเด็ก · **Smalltalk** OOP เพื่อการศึกษา · **MATLAB** คณิตศาสตร์/เมทริกซ์
- **Static Type** ต้องประกาศชนิดตัวแปร (C, Java, Go, Kotlin) · **Dynamic Type** ไม่ต้องประกาศ (Python, PHP, Ruby, JavaScript)

## 7. Framework & IDE (น.34–37)
- Framework: ลดเวลาพัฒนา · คุณภาพโค้ด (Design Patterns) · **ความปลอดภัย (กัน XSS, SQL Injection)** · ทำงานเป็นทีม · ขยายง่าย
  - Front-end: **React** (Canva, Netflix) · **Vue** · **Angular** · jQuery · Mobile: **React Native**, **Flutter (Dart)**
  - Back-end: **Laravel (PHP)** · **Django, Flask (Python)** · **Ruby on Rails** (Airbnb, Shopify)
- **IDE** = Code Editor + Compiler/Interpreter + **Debugger** + Build Automation
  - Offline: VS Code · Visual Studio · IntelliJ IDEA · PyCharm · **Android Studio** · **Xcode (iOS)** · Eclipse
  - Online: Replit · GitHub Codespaces · Google Project IDX · CodePen/JSFiddle · Arduino Web Editor
