# บทที่ 2 อัลกอริทึมและการเขียนโปรแกรม (Python, Java, C, PHP, HTML)
> เล่ม 2 หน้า 45–92 · ตรงหลักสูตรกรมที่ดิน "เขียนชุดคำสั่ง" ⭐ ข้อสอบชอบให้ไล่โค้ด/คำนวณนิพจน์/ลูป

## 1. อัลกอริทึม (น.45–49)
- คุณสมบัติที่ดี: **ถูกต้อง (Correctness)** · ใช้เวลาน้อย (Efficiency) · ลำดับชัดเจน (Precedence) · ใช้หน่วยความจำน้อย · ยืดหยุ่น · อ่านง่าย
- รูปแบบ: **บรรยาย (Narrative)** · **ผังงาน (Flowchart)** มาตรฐาน **ANSI/ISO** · **รหัสจำลอง (Pseudocode)** (ภาษาอังกฤษง่ายๆ 1 บรรทัด = 1 คำสั่ง) · **IPO Chart** (Input–Process–Output)
- สัญลักษณ์ผังงาน: **Terminal** วงรี (เริ่ม/จบ) · **Process** สี่เหลี่ยมผืนผ้า (คำนวณ/กำหนดค่า เช่น i=i+1) · **Decision** ข้าวหลามตัด · **Input/Output** สี่เหลี่ยมด้านขนาน · **Manual Input** (คีย์บอร์ด) · **Document** (พิมพ์รายงาน) · **Display** (จอ) · Data File/Database · **On-page Connector** วงกลม · **Off-page Connector** (ต่างหน้า) · Flowline ลูกศร

## 2. ตัวแปร (Variable) (น.49–54) ⭐
- ชนิดข้อมูลสำคัญ: **Integer** (byte, short, int, long) · **Floating Point** (float, double) · **Character/String** (char = 1 อักขระ) · **Boolean** (True/False) · **Array/List** (Python List ใช้ index ติดลบได้)
- ขอบเขต: **Global** (นอกฟังก์ชัน ใช้ได้ทั้งโปรแกรม) · **Local** (ในฟังก์ชัน) · ชื่อซ้ำกัน → ใช้ **Local ก่อน**
- **กฎตั้งชื่อตัวแปร**: ขึ้นต้นด้วย**ตัวอักษร** (หรือ _) · ห้ามมีสัญลักษณ์ `! @ # $ % ^ & * ( ) - = + ~` · ใช้ **_** ได้ · **ห้ามเว้นวรรค** · ห้ามซ้ำ**คำสงวน** · ✅ `_name`, `num_1` ❌ `123com`, `cost 1`, `A&P`
- **Case Sensitive** (Python, Java, C, C++, C#, PHP, JavaScript) vs **Case Insensitive** (Fortran, BASIC, Pascal, SQL, HTML tags)
- ขนาด: Java `int` = 32 บิตเสมอ · C `int` = 16/32 บิต · C `char` 8 บิต (ASCII) vs Java `char` 16 บิต (Unicode)

## 3. Class, Method, Function, Argument, Parameter (น.55–58)
- **Class** มี Attribute + Method · Method ประกอบด้วยหลาย Function · **Instance/Object** = ของจริงจากคลาส
- ฟังก์ชันหลัก (main) ทำงานก่อน เรียกฟังก์ชันย่อย · จำนวน/ชนิดค่าที่ส่งต้องตรงกัน
- **Argument** = ค่าที่ **ส่งไป** (ฝั่งผู้เรียก) "อา-ไป" · **Parameter** = ค่าที่ **รับมา** (ในนิยามฟังก์ชัน) "พา-มา"
- **Statement** ใน C/Java จบด้วย `;` และใช้ `{ }` ครอบหลายบรรทัด · Python จบด้วยการขึ้นบรรทัดใหม่ (ใช้การย่อหน้า)

## 4. รับค่า/แสดงผล (น.58–62)
- รับค่า: Python `input()` · C `scanf("%f",&height)` · Java `Scanner input = new Scanner(System.in); input.nextInt()` · PHP `readline()`
- Format Code: **%d** จำนวนเต็ม · **%f** ทศนิยม (**%.2f** = 2 ตำแหน่ง ปัดเศษ) · **%c** อักขระ · **%s** ข้อความ
- Escape: **\n** ขึ้นบรรทัดใหม่ · \t แท็บ · \b ถอยหลัง · \r กลับต้นบรรทัด · \f หน้าใหม่
- แสดงผล: C `printf` · Java `System.out.println/printf` · Python `print("...%.2f" % x)` · PHP `echo`

## 5. ขั้นตอนเขียนโปรแกรม & ลำดับตัวดำเนินการ (น.59–60) ⭐
- วิเคราะห์ปัญหา → ออกแบบอัลกอริทึม → เขียนโปรแกรม → **ทดสอบและ Debug** → **ทำเอกสาร** (User Guide / Technical Reference) และบำรุงรักษา
- ลำดับ: **( )** → **^** (ยกกำลัง) → **\* / % (mod) // (div)** (ซ้าย→ขวา) → **+ −**
  - ตัวอย่าง 5+2\*0+5/1%2+5^2 = 5+0+1+25 = **31**
  - `%` หารเอาเศษ (10%3=1) · `//` หารปัดลง (10//4=2) · `/` หารปกติ (Python ได้ทศนิยม)
- `++a` เพิ่มก่อนใช้ · `a++` ใช้ก่อนแล้วเพิ่ม

## 6. เงื่อนไข (Decision) (น.62–68)
- `if` · `if-else` · `if-elif-else` (ขั้นบันได) · **Nested if** (ซ้อน)
- **Switch-case** (C/Java) เลือก case ที่ตรง · **ลืม `break` = ไหลไป case ถัดไป (Logic Error)** · `default` เมื่อไม่ตรง · Python ใช้ **match-case** (Python 3.10)

## 7. การวนซ้ำ (Loop) (น.69–73) ⭐
- **Definite Loop** (รอบแน่นอน) = `for` · **Indefinite** = `while`, `do-while`
- `for (init; condition; update)` → init → ตรวจ → ทำ → update → ตรวจ…
- `while` ตรวจเงื่อนไข**ก่อน**ทำ (อาจไม่ทำเลย, เสี่ยง Endless Loop)
- `do-while` **ทำก่อน 1 รอบ**แล้วค่อยตรวจ (Python ไม่มี)
- Python `range(0,10,1)` = 0..9 (10 รอบ) · `for (i=0; i<5; i++)` = 5 รอบ

## 8. Array (น.73–75)
- ข้อมูลชนิดเดียวกัน ต่อเนื่องในหน่วยความจำ · **index เริ่ม 0** · scores = [85,90,78,92,88] → scores[2] = 78
- Array 2 มิติ = ตาราง (แถว × คอลัมน์)

## 9. PHP & HTML (น.83–90)
- PHP: ตัวแปรขึ้นต้น **$** · Dynamic Type · แสดงผล **echo** · ต่อข้อความด้วย **จุด (.)** · ใส่ตัวแปรใน "..." ได้ · ขึ้นบรรทัดใหม่บนเว็บ `<br>` · ตรรกะ AND = `&&`
- HTML: `<!DOCTYPE html>` → `<html>` → `<head>` (meta, title, ลิงก์ CSS) + `<body>` (เนื้อหา)
  - `<h1>`–`<h6>` หัวข้อ · `<p>` ย่อหน้า · `<a href="">` ลิงก์ · `<img src="" alt="">` รูป · `<ul>` ไม่เรียงลำดับ / `<ol>` เรียงลำดับ / `<li>` · `<table><tr><th>/<td>` ตาราง

## 10. ข้อผิดพลาด (Error) (น.90–91) ⭐
- **Syntax Error** ผิดไวยากรณ์ (ลืมวงเล็บ/;) รันไม่ได้ · **Logic Error** รันได้แต่ผลผิด (สูตร BMI ผิด) · **Runtime Error** พังขณะรัน (หารด้วยศูนย์, index เกิน) · **Semantic Error** ใช้ผิดความหมาย (string × ตัวเลข) · Hardware Error · Human Error
