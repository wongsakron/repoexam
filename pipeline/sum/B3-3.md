# บทที่ 3 เครื่องแม่ข่ายและคอมพิวเตอร์ส่วนบุคคล
> ชุดแนวสอบกระทรวงการคลัง · หมวด 3 (สัดส่วนประมาณ 12–15%) · ออก: Hypervisor Type 1 vs 2, Docker vs VM, SAN vs NAS, ความจุ RAID, Backup, RPO/RTO, สิทธิ์ไฟล์ Linux/Windows

## 1. ประเภท Server
- **Tower** ตั้งพื้นคล้าย PC ราคาประหยัด · **Rack** ติดตู้ 19 นิ้ว สูงเป็นหน่วย U (**1U = 1.75 นิ้ว**) · **Blade** เสียบ Chassis ใช้ไฟ พัดลม สวิตช์ร่วมกัน

## 2. Virtualization และ Container ⭐⭐
- **Hypervisor Type 1 (Bare-Metal)** ลงบนฮาร์ดแวร์ตรง: VMware ESXi, Hyper-V, KVM — เร็วและปลอดภัย เหมาะองค์กร
- **Type 2 (Hosted)** ลงบน OS อีกชั้น: VirtualBox, VMware Workstation — เหมาะงานทดสอบ
- **Docker** แชร์ Kernel กับ Host → เล็ก เปิดในไม่กี่วินาที · ⚠️ ต้องการ OS คนละตระกูลกับ Host → ใช้ **VM**
- **Kubernetes** = Container Orchestration: Scheduling, **Auto-scaling**, Load Balancing, **Self-healing** · หน่วยเล็กสุด = **Pod**

## 3. Storage ⭐⭐
| ชนิด | เชื่อมต่อ | ระดับข้อมูล | โปรโตคอล |
|---|---|---|---|
| **DAS** | ต่อตรงกับเครื่อง | Block | SATA/SAS/NVMe |
| **NAS** | ผ่าน LAN | **File-level** | SMB/CIFS, NFS |
| **SAN** | เครือข่ายสตอเรจแยก | **Block-level** | Fibre Channel, iSCSI |

## 4. RAID ⭐⭐
| RAID | ขั้นต่ำ | ความจุสุทธิ | ทนดิสก์เสีย |
|---|---|---|---|
| 0 Striping | 2 | N | ไม่ทนเลย |
| 1 Mirroring | 2 | N/2 | 1 ลูกต่อคู่ |
| 5 Single Parity | 3 | **N − 1** | 1 ลูก |
| 6 Dual Parity | 4 | **N − 2** | 2 ลูกพร้อมกัน |
| 10 Mirror+Stripe | 4 | N/2 | อย่างน้อย 1 (ได้ 2 ถ้าคนละคู่ Mirror) |

- ตัวอย่าง: 4 × 2 TB RAID 5 = **6 TB** · 6 × 4 TB RAID 6 = **16 TB** · 8 × 1 TB RAID 10 = **4 TB**

## 5. Backup และ RPO/RTO ⭐⭐
- **Full** ทุกไฟล์ กู้คืนเร็วสุด · **Incremental** เฉพาะที่เปลี่ยนจาก Backup ครั้งล่าสุด (เร็วสุด เล็กสุด แต่กู้ต้องใช้ทุกชุด) · **Differential** เฉพาะที่เปลี่ยนจาก Full ล่าสุด (กู้ใช้ 2 ชุด แต่ขนาดสะสม)
- Full อาทิตย์ + Inc จันทร์–พุธ ล่มพฤหัส → ใช้ **4 ชุด** · ถ้าเป็น Diff → ใช้ **2 ชุด** (อาทิตย์ + พุธ)
- **กฎ 3-2-1**: 3 สำเนา · 2 สื่อ · 1 ชุดนอกสถานที่
- **RPO** (Point) = ข้อมูลหายได้แค่ไหน → กำหนดความถี่ Backup · **RTO** (Time) = ระบบล่มได้นานแค่ไหน

## 6. Windows Server / Linux ⭐
- **AD DS** + Domain Controller จัดการผู้ใช้รวมศูนย์ · **GPO** บังคับนโยบาย
- Share + NTFS ใช้ร่วมกัน → ได้สิทธิ์ที่ **เข้มงวดกว่า (Most Restrictive)**
- Linux `chmod`: r=4 w=2 x=1 · **755** = rwxr-xr-x · **640** = rw-r----- · **750** = rwxr-x---

## 7. แก้ปัญหาเครื่องลูกข่าย
- เปิดไม่ติด/มี Beep → RAM หรือการ์ดจอหลวม · BSOD หลังลงไดรเวอร์ → **Safe Mode** ถอนไดรเวอร์ + ดู **Event Viewer**
- เครือข่าย: `ipconfig` → `ping 127.0.0.1` → `ping Gateway` → `nslookup`
- ping 127.0.0.1 ไม่ผ่าน = ปัญหา TCP/IP ในเครื่อง · ได้ IP **169.254.x.x** = ขอ IP จาก DHCP ไม่สำเร็จ (APIPA)
