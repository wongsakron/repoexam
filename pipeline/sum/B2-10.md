# บทที่ 10 เบ็ดเตล็ด
> เล่ม 2 หน้า 366–385 · ออก: คำศัพท์คอมพิวเตอร์ คีย์ลัด Windows ลอจิกเกต พอร์ต/USB/HDMI

## 1. คำศัพท์ที่ควรรู้ (น.366–372) — เลือกที่ออกบ่อย
- **Algorithm** ขั้นตอนวิธี · **Bandwidth** ความกว้างช่องสัญญาณ · **Bit** หน่วยเล็กสุด (0/1) · **Byte** 8 บิต = 1 อักขระ
- **Bus** ทางส่งข้อมูล/คำสั่งระหว่างอุปกรณ์ · **Cache** หน่วยความจำพักข้อมูลที่ใช้บ่อย · **Clipboard** พื้นที่เก็บข้อมูลชั่วคราว (คัดลอก)
- **CAPTCHA** ตรวจว่าเป็นมนุษย์หรือไม่ · **Cookie** ข้อมูลที่เบราว์เซอร์เก็บ · **Debug** แก้จุดบกพร่อง · **Compile** แปลเป็นภาษาเครื่อง
- **Firmware** ซอฟต์แวร์ที่บรรจุในชิป (เช่น BIOS) · **Flash** หน่วยความจำ Non-volatile เขียน/ลบได้ · **Kernel** แกนกลางของ OS
- **Hyperthreading** จำลองแกน CPU ให้ทำงานเสมือนหลายแกน · **Macro** ชุดคำสั่งอัตโนมัติเลียนแบบการกดแป้น/เมาส์
- **Cyber Bully** การระรานทางไซเบอร์ · **Digital Disruption** การเปลี่ยนฉับพลันทางดิจิทัล · **Digital Literacy** การรู้ดิจิทัล
- **NFT** (Non-Fungible Token) สินทรัพย์ดิจิทัลที่ไม่สามารถทดแทนกันได้ · **Metaverse** จักรวาลนฤมิต · **Avatar** อวตาร
- **Frame** หน่วยข้อมูลใน Data Link Layer · **Freeware** ใช้ฟรี (มีลิขสิทธิ์) · **ZIP** ไฟล์บีบอัด (WinZip, 7z, WinRAR)

## 3. ลอจิกเกต (Logic Gate) (น.377–380) ⭐
- **NOT** กลับค่า · **AND** = คูณ (1 เมื่อทุกอินพุตเป็น 1) · **OR** = บวก (1 เมื่อมีอินพุตใดเป็น 1)
- **NAND** = ตรงข้าม AND · **NOR** = ตรงข้าม OR
- **XOR**: อินพุต **เหมือนกัน = 0, ต่างกัน = 1** · **XNOR**: **เหมือนกัน = 1, ต่างกัน = 0**
- เขียนสมการ: จุด (.) = AND, บวก (+) = OR เช่น X = A + (B.C)
- วิธีหาคำตอบ: ถอดวงจรเป็นสมการ → แทนค่า → ทำในวงเล็บก่อน
  - ตัวอย่าง (A.B) + ((B+C).(C.B)) เมื่อ A=0, B=1, C=1 → 0 + (1.1) = **1**

## 4. พอร์ตและตัวต่อ (น.381–385)
- **Serial (COM)** ~0.1 Mbps รุ่นเก่า · **Parallel** = Printer Port รุ่นเก่า · **PS/2** เมาส์ (เขียว) / คีย์บอร์ด (ม่วง)
- **Ethernet/LAN (RJ-45)** ต่อเครือข่าย · **DVI** ภาพดิจิทัล · **VGA** ภาพ**แอนะล็อก** (ไม่มีเสียง ตั้งแต่ 1987)
- **HDMI** ภาพ + เสียงดิจิทัลในสายเดียว (ขนาด A–E; HDMI 2.1 รองรับ 4K@120, 8K)
- **USB** = Universal Serial Bus (อนุกรม จ่ายไฟได้ เปิดตัว 1996)
  - 1.0 = 1.5 Mbps · 1.1 = 12 Mbps · **2.0 = 480 Mbps (2001)** · **3.0 = 5 Gbps (สีน้ำเงิน)** · 3.2 = 10/20 Gbps · **USB4 = 40 Gbps (2019, Type-C เท่านั้น)** · **USB4 v2 = 80 Gbps**
  - สีพอร์ต: ขาว 1.x · ดำ 2.0 · **น้ำเงิน 3.x Gen1** · เขียวหัวเป็ด 3.2 Gen2 · เหลือง/แดง = Sleep-and-Charge · ส้ม = ชาร์จอย่างเดียว
- **Thunderbolt** (Apple + Intel, 2011) · Thunderbolt 4 = **40 Gbps** ต่อจอหลายจอแบบ Daisy Chain · USB4 สร้างบนโปรโตคอล Thunderbolt 3
