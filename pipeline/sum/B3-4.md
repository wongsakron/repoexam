# บทที่ 4 ระบบสารสนเทศและการจัดการฐานข้อมูล
> ชุดแนวสอบกระทรวงการคลัง · หมวด 4 (สัดส่วนประมาณ 15–18%) · ออก: แยก TPS/MIS/DSS/EIS/ERP, Normalization 1NF–3NF, กลุ่มคำสั่ง SQL, JOIN, ACID, บทบาท Data Governance

## 1. SDLC และเครื่องมือออกแบบ
- SDLC 7 ขั้น: **Planning & Feasibility** (เทคนิค เศรษฐศาสตร์ ปฏิบัติการ) → Analysis → Design → Development → Testing → **Implementation** (ติดตั้ง + โอนย้ายข้อมูล) → Maintenance
- **DFD** 4 สัญลักษณ์: Process (วงกลม/สี่เหลี่ยมมุมมน) · Data Flow (ลูกศร) · **Data Store (เส้นขนาน/กล่องเปิดข้าง)** · External Entity (สี่เหลี่ยมผืนผ้า) · ระดับบนสุด = **Context Diagram (Level 0)**
- **UML**: Structural เช่น Class Diagram · Behavioral เช่น Use Case, Sequence, Activity

## 2. ประเภทระบบสารสนเทศ ⭐⭐
| ระบบ | ผู้ใช้ | จุดเด่น |
|---|---|---|
| **TPS** | ระดับปฏิบัติการ | บันทึกธุรกรรมประจำวัน |
| **MIS** | ผู้บริหารระดับกลาง | รายงานสรุปตามรอบเวลา |
| **DSS** | ผู้ตัดสินใจ | ปัญหากึ่งมีโครงสร้าง **What-if Analysis** |
| **EIS** | ผู้บริหารระดับสูง | **Dashboard / KPI** เชิงกลยุทธ์ |
| **ERP** | ทั้งองค์กร | บูรณาการทุกฝ่ายในฐานข้อมูลเดียว |

## 3. Data Governance (มาตรฐาน DGA) ⭐
- **Data Owner** ผู้บริหารเจ้าของข้อมูล ตัดสินนโยบาย/สิทธิ์ · **Data Steward** ดูแลคุณภาพและเมทาดาทา · **Data Custodian** ฝ่ายไอที ดูแลระบบ Backup ความปลอดภัย

## 4. RDBMS vs NoSQL
- **RDBMS** (PostgreSQL, MySQL, Oracle) ตาราง Schema คงที่ SQL ACID · Scale-up
- **NoSQL** Schema-less · Scale-out · 4 ประเภท: Key-Value (**Redis**) · Document (**MongoDB**) · Column-Family (**Cassandra**) · Graph (**Neo4j**)

## 5. Keys และ Normalization ⭐⭐
- **PK** ห้ามซ้ำ ห้ามว่าง · **FK** อ้างอิง PK ตารางอื่น (Referential Integrity) · **M:N** ต้องแตกตารางเชื่อม
- **1NF** = ค่า Atomic (ห้ามหลายค่าในช่องเดียว)
- **2NF** = 1NF + ตัด **Partial Dependency** (ขึ้นกับบางส่วนของ Composite Key)
- **3NF** = 2NF + ตัด **Transitive Dependency** (คอลัมน์ไม่ใช่คีย์ขึ้นต่อกันเอง)

## 6. SQL ⭐⭐
| กลุ่ม | คำสั่ง |
|---|---|
| **DDL** | CREATE, ALTER, DROP, **TRUNCATE** |
| **DML** | SELECT, INSERT, UPDATE, DELETE |
| **DCL** | GRANT, REVOKE |
| **TCL** | COMMIT, ROLLBACK, SAVEPOINT |

- ⚠️ **TRUNCATE เป็น DDL** ไม่ใช่ DML (ตัวหลอกยอดฮิต)
- **INNER JOIN** เฉพาะแถวที่จับคู่ได้ · **LEFT JOIN** ซ้ายทั้งหมด ขวาไม่มีคู่เป็น NULL
- **Index** ค้นเร็วขึ้นแต่เพิ่ม/แก้ช้าลง · **View** ตารางเสมือน ใช้ซ่อนคอลัมน์ลับ · **HAVING** กรองหลัง GROUP BY

## 7. ACID ⭐⭐
- **Atomicity** ทั้งหมดหรือไม่มีเลย · **Consistency** ถูกต้องตามกฎก่อนและหลัง · **Isolation** ไม่แทรกแซงกัน · **Durability** COMMIT แล้วถาวรแม้ไฟดับ
