# บทที่ 5 การพัฒนาโปรแกรมและสถาปัตยกรรมซอฟต์แวร์
> เล่ม 3 แนวสอบกระทรวงการคลัง · หมวด 5 (สัดส่วนประมาณ 12–15%) · ออก: บทบาทใน Scrum, ลำดับการทดสอบ, OOP 4 หลัก, Stack/Queue, HTTP Status Code, OWASP Top 10

## 1. Agile / Scrum ⭐⭐
- **Product Owner** กำหนดวิสัยทัศน์ จัดลำดับ Product Backlog · **Scrum Master** ดูแลกระบวนการ ขจัดอุปสรรค · **Development Team** บริหารตนเอง
- **Sprint** 1–4 สัปดาห์ · Sprint Planning · **Daily Scrum ≤ 15 นาที** · **Sprint Review** (สาธิตผลงาน) · **Sprint Retrospective** (ปรับปรุงวิธีทำงานของทีม)

## 2. DevOps / CI/CD / Git
- **CI** รวมโค้ดบ่อย + Build + Automated Test ทันที · **Continuous Delivery** พร้อมปล่อยเสมอ (มักรออนุมัติ) · **Continuous Deployment** ปล่อยขึ้น Production อัตโนมัติ
- Git: `clone` คัดลอก repo · `add` เข้า Staging · `commit` บันทึกในเครื่อง · `push`/`pull` ส่งขึ้น/ดึงจาก Remote · `branch`/`merge` แตกแขนงและรวม
- ลำดับปกติ: แก้ไฟล์ → add → commit → push

## 3. การทดสอบ ⭐⭐
- **Unit** (นักพัฒนา ทดสอบฟังก์ชัน) → **Integration** (การเชื่อมต่อระหว่างโมดูล) → **System** (ทั้งระบบ) → **UAT** (ผู้ใช้จริงตรวจรับ)
- **Load Test** ภาระตามที่คาดไว้ · **Stress Test** เกินขีดจำกัดเพื่อหาจุดล่มและดูการฟื้นตัว

## 4. OOP 4 เสาหลัก ⭐⭐
- **Encapsulation** private + Getter/Setter · **Inheritance** คลาสลูกสืบทอดคลาสแม่ · **Abstraction** Abstract Class / Interface
- **Polymorphism**: **Overloading** ชื่อเดียว พารามิเตอร์ต่าง ในคลาสเดียว · **Overriding** คลาสลูกเขียนทับเมธอดคลาสแม่

## 5. โครงสร้างข้อมูลและอัลกอริทึม
- Array เข้าถึงด้วย Index **O(1)** · Linked List แทรก/ลบง่าย · **Stack = LIFO** (Undo, Call Stack) · **Queue = FIFO** (คิวพิมพ์)
- **Binary Search** ต้องเรียงข้อมูลก่อน · **O(log n)** · 1,000,000 รายการ ≈ 20 ครั้ง

## 6. สถาปัตยกรรมและ REST API ⭐
- **Monolithic** ก้อนเดียว ฐานข้อมูลเดียว ต้อง Scale ทั้งก้อน · **Microservices** บริการเล็กอิสระ ฐานข้อมูลแยก Scale รายบริการ ล่มบางส่วนไม่กระทบทั้งระบบ
- REST = **Stateless** · GET อ่าน · POST สร้าง · PUT แก้ทั้งก้อน · **PATCH แก้บางส่วน** · DELETE ลบ · JSON เล็กกว่า XML (XML ตรวจโครงสร้างด้วย XSD ได้)

| Code | ความหมาย |
|---|---|
| 200 | OK |
| 201 | Created สร้างสำเร็จ |
| 400 | Bad Request คำขอผิดรูปแบบ |
| **401** | ยังไม่ยืนยันตัวตน (ไม่ได้ Login) |
| **403** | Login แล้วแต่ **ไม่มีสิทธิ์** |
| 404 | Not Found |
| 500 | Internal Server Error |

## 7. OWASP ⭐⭐
- **Broken Access Control** เช่น IDOR แก้เลข ID ใน URL แล้วเห็นข้อมูลคนอื่น
- **Cryptographic Failures** เก็บ/ส่งข้อมูลสำคัญไม่เข้ารหัส (เช่นรหัสผ่าน Plain Text)
- **SQL Injection** → **Parameterized Query / Prepared Statement**
- **XSS** → Input Validation + **Output Encoding** · **CSRF** → **Anti-CSRF Token**
