# บทที่ 4 ซอฟต์แวร์ (Software)
> เล่ม 1 หน้า 85–115 · ตรงหลักสูตรกรมที่ดิน (ความปลอดภัย/มัลแวร์ และงานติดตั้งระบบ) ⭐ ออก: OS, Kernel/Shell, ประเภท OS, Utility, License, Cloud SaaS/PaaS/IaaS, Malware, Virtualization

## 1. ความหมาย & UI/UX (น.85–87)
- **ซอฟต์แวร์** = ชุดคำสั่งสั่งให้ฮาร์ดแวร์ทำงาน และเป็นตัวกลางระหว่างฮาร์ดแวร์กับผู้ใช้
- โปรแกรม (อาจไม่มีหน้าจอ ทำงานเบื้องหลัง) vs **แอปพลิเคชัน** (ต้องมี UI)
- **UI**: **CLI** (พิมพ์คำสั่ง: MS-DOS, Unix, Linux) · **GUI** (ภาพ ไอคอน เมาส์/สัมผัส: Windows, Android, iOS, macOS) · **UX** = ประสบการณ์ผู้ใช้ (ใช้ง่าย/ยาก)

## 2. ซอฟต์แวร์ระบบ (System Software) (น.87–99) ⭐
### 2.1 ระบบปฏิบัติการ (OS)
- หน้าที่: **ติดต่อผู้ใช้** · **ควบคุมซอฟต์แวร์ประยุกต์** · **ควบคุมฮาร์ดแวร์** · **จัดสรรทรัพยากร** (CPU, Memory, I/O) ด้วย Queue, Time Slice, Priority
- ตัวอย่าง: Windows (PC นิยมสุด, ปัจจุบัน Windows 11) · **Android** (Google นิยมที่สุดในโลก ~70% Embedded OS, Android 16) · **iOS/iPadOS** (Apple ระบบปิด, iOS 26) · **macOS** (ระบบปิด ใช้เฉพาะเครื่อง Apple, macOS 26 Tahoe) · **Linux** (Unix-like **Open Source** ใช้ทำ Server) · **Chrome OS** (Chromebook, Cloud-First) · **HarmonyOS** (Huawei) · Unix: BSD, AIX, Solaris · Tizen, tvOS, webOS
- **Platform** = สภาพแวดล้อมฮาร์ดแวร์+ซอฟต์แวร์ที่ทำงานสัมพันธ์กัน
- **Kernel** = แกนกลาง OS ควบคุม CPU, RAM, I/O ตั้งแต่บูต · **Shell** = ตัวกลางรับคำสั่งผู้ใช้ส่งให้ Kernel
- **ประเภท OS**: **Stand-alone** (ผู้ใช้คนเดียว: Windows 11, macOS) · **Network OS** (Multi-user, Client/Server: Unix, Linux, **Windows Server**, Solaris) · **Embedded OS** (มือถือ อุปกรณ์: Android, iOS, Symbian) · **Cloud OS/Web OS** (ประมวลผลที่เซิร์ฟเวอร์ผู้ให้บริการ: Chrome OS, Azure)
- **คุณสมบัติ**: **Multi-user** (หลายผู้ใช้พร้อมกัน) · **Multiprocessing** (หลาย CPU) · **Multitasking** (ผู้ใช้เดียวรันหลายโปรแกรม) · **Multithreading** (หลาย Thread ในโปรแกรมเดียว) · **Real-time** (ตอบสนองในเวลาที่กำหนดแน่นอน)
- **สถานะ Process 5 สถานะ**: New → **Ready** → **Running** → Waiting → Terminate
- Copyleft (Richard Stallman, **GNU GPL**) vs Copyright

### 2.2 ตัวแปลภาษา (Translator) — เร็วสุดไปช้าสุด
- **Assembler** (Assembly → ภาษาเครื่อง เร็วสุด) · **Compiler** (แปลทั้งโปรแกรม → .obj → **.exe** ใช้ซ้ำได้: C, C++, Java, C#, VB, Swift) · **Interpreter** (ทีละบรรทัด ต้องแปลใหม่ทุกครั้ง: Python, PHP, JavaScript, Perl)

### 2.3 ซอฟต์แวร์อรรถประโยชน์ (Utility) 4 ประเภท
1. **Device Driver** = ตัวกลางให้ OS รู้จักและใช้ฮาร์ดแวร์เต็มความสามารถ (เช่น ไดรเวอร์การ์ดจอ)
2. **System Utilities**: Firewall · Antivirus · Clipboard Manager · Memory Tester · **Registry Cleaner (CCleaner)** · **Screensaver** (รักษาความลับ+ยืดอายุจอ) · Network Utilities · **System Profiler (CPU-Z)** · Uninstaller
3. **Storage Utilities**: **Disk Checker** (Bad Sector) · **Disk Defragmenter** (จัดเรียงไฟล์ HDD) · Disk Formatter · **Partition Editor**
4. **File Management**: Archiver · **Backup** · Cryptographic (เข้ารหัส) · Data Compression · **Data Sync** (Google Drive, Dropbox, OneDrive)

## 3. ซอฟต์แวร์ประยุกต์ (Application Software) (น.99–105)
- **ทั่วไป/สำเร็จรูป (General Purpose)** 6 กลุ่ม: DBMS (Access, MySQL, Oracle, MongoDB) · ประมวลผลคำ (Word, Google Docs, InDesign) · ตารางคำนวณ (Excel, Sheets, Calc) · นำเสนอ (PowerPoint, Canva, Prezi) · กราฟิก/มัลติมีเดีย (Photoshop, CapCut, Blender, DaVinci Resolve, Midjourney) · สื่อสาร/ทำงานร่วมกัน (Chrome, LINE, Teams, Zoom)
- **เฉพาะงาน (Specific Purpose)** จ้างพัฒนาเฉพาะองค์กร ต้นทุนสูงแต่ตรงความต้องการ (ระบบธนาคาร, ทะเบียนราษฎร์, โปรแกรมแผนที่ภาษี)
- แพลตฟอร์มแอป: **Desktop App** · **Mobile App** · **Web App** (ใช้ผ่านเบราว์เซอร์: Gmail, Canva, Google Docs)

## 4. สัญญาอนุญาต (License) (น.101–104) ⭐
- **Commercial** ต้องซื้อ License (EULA/TOS) · **Shareware** ใช้ได้เรื่อยๆ แต่ปิดฟังก์ชันขั้นสูง/มีโฆษณา/ลายน้ำ จ่ายเพื่อปลดล็อก · **Trial** เต็มความสามารถแต่**จำกัดเวลา** (7/15/30 วัน) · **Demo** **จำกัดความสามารถ** ไม่จำกัดเวลา · **Beta** ให้ทดลองหาบั๊ก · **Freeware** ใช้ฟรี (บางตัว Non-Commercial) · **Open Source** ใช้ฟรี + **แก้ซอร์สโค้ดได้** (Linux, GIMP, 7-Zip, VLC, FileZilla, Notepad++)
- Open Source License: **GPL** (ขายได้แต่ต้องเปิด Source) · **LGPL** (ส่วนที่พัฒนาเองไม่ต้องเปิด) · **BSD/MIT** (ขายต่อได้ ไม่ต้องเปิด Source แต่ต้องระบุ License)
- **Creative Commons**: **BY** แสดงที่มา · **NC** ห้ามใช้เชิงการค้า · **ND** ห้ามดัดแปลง · **SA** ดัดแปลงแล้วต้องใช้สัญญาเดียวกัน · ผสมได้ 6 แบบ (BY, BY-SA, BY-ND, BY-NC, BY-NC-SA, BY-NC-ND)

## 5. Cloud Computing (น.105–108) ⭐
- เช่าใช้ทรัพยากรผ่านอินเทอร์เน็ต **จ่ายตามใช้ (Pay-as-you-go)** · ไม่ต้องลงทุนฮาร์ดแวร์ ไม่ต้องดูแลระบบ เข้าถึงจากทุกที่ ขยายได้ทันที
- **SaaS** ใช้ซอฟต์แวร์สำเร็จรูป (Google Apps, Office 365, Canva, Dropbox) ผู้ใช้ควบคุมน้อยสุด
- **PaaS** แพลตฟอร์มสำหรับนักพัฒนา (Google App Engine, AWS Lambda, Azure App Service, Heroku) ผู้ใช้ปรับได้ Data + App
- **IaaS** โครงสร้างพื้นฐาน CPU/RAM/Disk/Network/OS (Amazon EC2, Google Compute Engine, Azure VMs) ผู้ใช้ควบคุมได้มากสุด (Data, App, Runtime, OS)
- **Public Cloud** (ผู้ให้บริการภายนอก Multi-tenant ถูก ยืดหยุ่น) · **Private Cloud** (องค์กรเดียว Single-tenant ปลอดภัยสูง) · **Hybrid Cloud** (ผสม นิยมสุดในองค์กร)

## 6. มัลแวร์ (Malware) (น.108–111) ⭐
- **Virus** แนบไปกับไฟล์/โปรแกรม ทำงานเมื่อเปิดไฟล์ · **Worm** สำเนาตัวเองแพร่ผ่านเครือข่ายเองได้ (Stuxnet, Conficker) · **Trojan** หลอกว่าเป็นโปรแกรมดี เปิดทางให้ควบคุมเครื่อง (Emotet) ไม่แพร่ตัวเอง
  - **Backdoor** เปิดช่องลับ · **Rootkit** ได้สิทธิ์ Root ซ่อนตัวระดับ Kernel · **Spyware** แอบดู/ขโมยข้อมูล (Pegasus) · **Ransomware** เข้ารหัสไฟล์เรียกค่าไถ่ (WannaCry, Ryuk)
- **Cryptojacking** แอบใช้ CPU/GPU ขุดคริปโต · **Adware** โฆษณา · **Banking Spy** (Zeus) · **Keylogger** บันทึกการกดแป้น
- กลอน: ไวรัส เปิดไฟล์ กระจายตัว · เวิร์มหนอนชั่ว แพร่ผ่านเครือข่าย · โทรจัน หลอกฉันให้ตายใจ · สปาย แอบดูพฤติกรรม
- ป้องกัน: **อัปเดต Patch** · Antivirus + Firewall · รหัสผ่านยาก + **2FA** · **สำรองข้อมูลแยก** (กัน Ransomware) · ตรวจลิงก์/ไฟล์แนบ (Phishing) · ไม่ใช้บัญชี Admin ประจำวัน · Wi-Fi สาธารณะใช้ **VPN** · โหลดแอปจาก Store ทางการ

## 7. Virtualization / Virtual Machine (น.111–115) ⭐
- **VM** = คอมพิวเตอร์จำลอง มี **Guest OS** + CPU/RAM/Disk ของตัวเอง บนฮาร์ดแวร์จริงเครื่องเดียว
- **Hypervisor** = ซอฟต์แวร์จัดสรรทรัพยากรให้ VM
  - **Type 1 (Bare Metal)** ติดตั้งบนฮาร์ดแวร์โดยตรง เร็ว เสถียร ใช้ใน Data Center: **VMware ESXi, Hyper-V, KVM**
  - **Type 2 (Hosted)** ติดตั้งบน Host OS ใช้ง่าย เหมาะทดสอบ: **VirtualBox, VMware Workstation**
- **Server Virtualization** (Server Consolidation ลดฮาร์ดแวร์/พลังงาน) · **Desktop Virtualization (VDI)** เดสก์ท็อปอยู่ที่ศูนย์ข้อมูล เข้าจาก Thin Client ข้อมูลปลอดภัย Work From Anywhere · **Storage Virtualization** รวม HDD/SAN/NAS เป็นก้อนเดียว · **Network Virtualization (SDN)** แยกเครือข่ายเสมือน (Segmentation) บนสายเดียวกัน
