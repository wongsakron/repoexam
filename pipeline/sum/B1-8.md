# บทที่ 8 การสื่อสารข้อมูล (Data Communications)
> เล่ม 1 หน้า 239–298 · ตรงหลักสูตรกรมที่ดิน (ความปลอดภัยเครือข่าย) ⭐ ออกหนักที่สุดในเล่ม 1: PAN/LAN/MAN/WAN, Topology, คำสั่ง DOS, สาย UTP/Fiber, อุปกรณ์ Hub/Switch/Router, 1G–5G, IPv4/IPv6, Class/Private IP, Subnet, Unicast/Broadcast/Multicast, Symmetric/Asymmetric, DNS, Firewall, DMZ

## 1. ประเภทเครือข่ายตามพื้นที่ (น.239–242) ⭐
| ประเภท | ขอบเขต | ตัวอย่าง/เทคโนโลยี |
|---|---|---|
| **PAN** | ใกล้ตัว | AirDrop, Bluetooth, Hotspot มือถือ, USB-C, **OTG** |
| **LAN** | บ้าน/อาคาร | Ethernet **IEEE 802.3** (Star) · Token Ring **802.5** (Ring 16 Mbps เลิกใช้) · Wi-Fi **802.11** (WLAN) |
| **MAN** | **5–100 กม.** ระดับเมือง | เชื่อม LAN ข้ามอาคาร/คณะ · **WiMAX 802.16** (ถูกแทนด้วย 4G/5G แล้ว) |
| **WAN** | ทั่วโลก | **อินเทอร์เน็ต**, เคเบิลใต้น้ำ, MPLS/Leased Line, Cellular 5G, ดาวเทียม Starlink |

- Wi-Fi 6 = **802.11ax** (9.6 Gbps ใช้แพร่หลายในไทย) · **Wi-Fi 7 = 802.11be** (~30 Gbps) · Wi-Fi 8 = 802.11bn (ปลายปี 2028)

## 2. แบ่งตามความปลอดภัย & หน้าที่ (น.242–245)
- **Intranet** = เครือข่ายภายในองค์กร ใช้ IP/เว็บ เฉพาะผู้มีสิทธิ์ (ระบบสลิปเงินเดือนครู, e-office)
- **Extranet** = Intranet ที่**เปิดบางส่วนให้คนนอกที่ได้รับอนุญาต** (คู่ค้า/ลูกค้า เช่น ระบบ **e-GP** ยื่นประมูล)
- **Internet** = เครือข่ายสาธารณะ ไม่มีเจ้าของ เชื่อมผ่าน **ISP** · Internetwork เชื่อมหลายเครือข่ายด้วย Router (ปลอดภัยต่ำ)
- **Client-Server** (มีเครื่องแม่ข่ายให้บริการ: เว็บ ฐานข้อมูล Cloud) vs **Peer-to-Peer (P2P)** (ทุกเครื่องเป็นทั้งผู้ให้และผู้รับ เช่น **BitTorrent**)

## 3. Topology (น.245–247) ⭐
| แบบ | ลักษณะ | ข้อดี | ข้อเสีย |
|---|---|---|---|
| **Bus** | สายแกนหลักเส้นเดียว (Backbone) เหมือนราวแขวนผ้า | ติดตั้งง่าย ประหยัดสาย | **สายหลักขาด = ล่มทั้งระบบ** หาจุดเสียยาก |
| **Star** | ทุกเครื่องต่อเข้า **Switch/Hub ศูนย์กลาง** (นิยมสุด) | สายเส้นใดขาดเสียแค่เครื่องนั้น ดูแลง่าย | เปลืองสาย · **ศูนย์กลางเสีย = ล่มหมด** |
| **Ring** | ต่อเป็นวงปิด | ทุกโหนดส่งได้เท่าเทียม ประหยัดสาย | วงขาดล่มทั้งหมด ตรวจสอบยาก |
| **Mesh** | ทุกโหนดเชื่อมกันตรง (อินเทอร์เน็ต) | **Fault-Tolerant** ใช้แบนด์วิดท์เต็มที่ ปลอดภัย | **เปลืองสายมากที่สุด** |

## 4. คำสั่ง Network ใน DOS (น.247–250) ⭐
- **ipconfig** ดู IP / Subnet Mask / Gateway (IPv4+IPv6, LAN และ Wi-Fi)
- **netstat** ดูสถานะการเชื่อมต่อ (Proto TCP/UDP, Local Address:Port, Foreign Address, State)
- **ping** ทดสอบว่าเชื่อมถึงปลายทางไหม (`ping 192.168.0.3`, `-t` = ต่อเนื่อง)
- **tracert** แสดง**เส้นทาง**ทุกจุดที่ผ่าน (`*` = จุดขัดข้อง จบด้วย trace complete)
- **nslookup** ถาม DNS: ชื่อเว็บ ↔ IP

## 5. Physical Layer: สัญญาณ & สื่อกลาง (น.250–261) ⭐
- **Modulation** = Digital → Analog · **Demodulation** = Analog → Digital · **MODEM** ทำทั้งสองอย่าง
- Fiber: แปลงไฟฟ้าเป็น**พัลส์แสง** (ไดโอด/เลเซอร์) ปลายทางใช้ **Photo Diode** · เร็ว ~70% ของแสงในอากาศ · ใช้งาน 10–40 Gbps ในระยะ 100 กม.
- **Noise 7 ชนิด**: Crosstalk (สายรบกวนกัน) · **Thermal/White** (ความร้อน) · **Impulse** (ฟ้าผ่า กระชากทันที) · **Echo** (สะท้อน แก้ด้วย **Terminator**) · **Jitter** (ผิดพลาดด้านเวลา) · **Delay Distortion** (แก้ด้วย **Equalizer**) · **Attenuation** (สัญญาณอ่อน แก้ด้วย **Amplifier/Repeater**)

### สื่อกลางแบบมีสาย
- **Coaxial** แกนทองแดง+ชีลด์ถัก · นิยม **RG6** (CCTV, เคเบิลทีวี) · หัว **BNC**
- **Twisted Pair** บิดเกลียวเพื่อลดสัญญาณรบกวน · **STP** (หุ้มเกราะ กันรบกวนดี) · **UTP** (ไม่หุ้ม ถูก นิยมสุด) · หัว **RJ-45** (4 คู่ 8 เส้น) ส่วนโทรศัพท์ใช้ **RJ-11**
- เข้าหัว: **T568A** เริ่ม ขาวเขียว-เขียว · **T568B** เริ่ม ขาวส้ม-ส้ม (สลับคู่เขียว↔ส้ม)

| CAT | ความเร็ว | Bandwidth | หมายเหตุ |
|---|---|---|---|
| **5e** | 1 Gbps | 100 MHz | นิยมสุด e = Enhanced |
| **6** | 10 Gbps (≤55 ม.) | 250 MHz | ยาวสุด 100 ม. |
| **6a** | 10 Gbps @100 ม. | 500 MHz | มีฉนวนกันรบกวน |
| 6e | — | — | **ไม่ได้รับรองจาก TIA** |
| 7/7a | 10 Gbps | 600 MHz | รับรองโดย **ISO/IEC** ไม่นิยม |
| **8** | **40 Gbps** | **2,000 MHz** | ได้แค่ 30–36 ม. เหมาะ Data Center |

- ทุก CAT ใช้ร่วมกันได้ (Backward compatible) แต่ความเร็ววิ่งตามตัวที่ต่ำสุด (คอขวด)
- **Fiber Optic**: **Core** (ดัชนีหักเหสูง) + **Cladding** (ดัชนีหักเหต่ำกว่า → สะท้อนกลับหมด) + Coating/Buffer · ไม่ถูกรบกวนจากคลื่นไฟฟ้า
  - **Multimode** หลายลำแสง ถูกกว่า นิยมกว่า ระยะสั้น · **Singlemode** ลำแสงเดียว เร็ว **ไกลกว่า**

### สื่อกลางไร้สาย
- **คลื่นวิทยุ** กระจายรอบทิศ (Omni) ทะลุสิ่งกีดขวางได้ (Multicasting: วิทยุ ทีวี มือถือ)
- **ไมโครเวฟ** เดินทาง**เส้นตรง** ต้องมีสถานีทวนเป็นระยะบนที่สูง
- **อินฟราเรด** เส้นตรง ทะลุสิ่งกีดขวางไม่ได้ (รีโมททีวี)
- **ดาวเทียม** = สถานีไมโครเวฟลอยฟ้า · **Bluetooth** คลื่นวิทยุระยะสั้น ไม่ต้องเล็งเส้นตรง
- ยิ่ง**ความถี่สูง** ยิ่งทะลุวัตถุได้น้อยและพุ่งเป็นทิศทางมากขึ้น (คล้ายแสง)

## 6. อุปกรณ์เครือข่าย (น.262–268) ⭐⭐
| อุปกรณ์ | ชั้น OSI | หน้าที่ |
|---|---|---|
| **Hub** | 1 | กระจายทุกพอร์ต (**Broadcast**) **Half-Duplex** ชนกันได้ |
| **Repeater** | 1 | ทวน/ขยายสัญญาณ (UTP ต้องทวนทุก ~100 ม.) |
| **Switch** | 2 | จำ **MAC Address** แต่ละพอร์ต ส่งตรงเป้าหมาย · Unicast/Multicast/Broadcast · **Full-Duplex** ชนกันน้อยมาก |
| **Bridge** | 2 | เชื่อม LAN ที่ใช้**โพรโตคอลเดียวกัน** กรองข้อมูลตามปลายทาง |
| **NIC/LAN Card** | 1–2 | การ์ดแลน มี MAC · พอร์ต RJ-45 |
| **Router** | 3 | เชื่อม**ต่างเครือข่าย** (LAN↔WAN) เลือกเส้นทางด้วย **Routing Table** · มี Firewall, VPN, QoS ในตัว |
| **Gateway** | 4–7 | เชื่อมเครือข่าย**ต่างชนิดกัน**ให้คุยกันได้ + คัดกรอง (ปัจจุบันรวมใน Router) |
| **Modem** | 1 | แปลง Digital↔Analog · **ADSL** (Asymmetric อัป/ดาวน์ไม่เท่ากัน 24/3.3 Mbps) · **VDSL** (300/100 Mbps) |
| **ONU/ONT** | 1 | "Fiber Modem" แปลงแสง → Ethernet ในระบบ **FTTH** |
| **Access Point** | 2 | ให้อุปกรณ์ไร้สายเข้าเครือข่ายสาย (ปัจจุบันรวมใน Router) |

- Router แบ่งประเภท: Wireless (SOHO) · Gaming (Low Latency + QoS) · VPN Router · **Edge** (ขอบเครือข่ายองค์กร↔อินเทอร์เน็ต) / **Core** (ใจกลางเครือข่าย ISP Throughput สูง)
- **PoE (Power over Ethernet)** จ่ายไฟผ่านสาย LAN ให้กล้อง CCTV / Access Point · **MiFi/Pocket Wi-Fi** รับ 4G/5G แปลงเป็น Wi-Fi

## 7. เทคโนโลยีการสื่อสาร (น.268–275) ⭐
- **Cellular**: พื้นที่บริการแบ่งเป็น **Cell** (เมืองใช้เซลล์เล็กหลายเซลล์) · **Handoff** = ย้ายเซลล์ไม่สะดุด · **Roaming** = ไปใช้เครือข่ายอื่น/ต่างประเทศ

| ยุค | ระบบ | บริการเด่น | เทคโนโลยี |
|---|---|---|---|
| **1G** | **แอนะล็อก** | เสียงอย่างเดียว | AMPS, TACS · FDMA · Circuit |
| **2G** | ดิจิทัล | เสียง + **SMS/MMS** + data | **GSM, GPRS, EDGE** · TDMA/CDMA |
| **3G** | ดิจิทัล | + **Video Call** | WCDMA, HSPA, UMTS · CDMA |
| **4G** | ดิจิทัล | อินเทอร์เน็ตเร็วสูง | **LTE**, WiMAX, VoLTE · OFDMA · Packet |
| **5G** | ดิจิทัล | **IoT**, Low Latency (~1 ms) | NR · **MIMO 64–256 เสา** · 10–50 Gbps · เร็วกว่า 4G 20 เท่า รองรับผู้ใช้ 10 เท่า |

- 6G (กำลังพัฒนา) ผสาน AI เข้ากับเครือข่าย
- **Ethernet**: Xerox+DEC+Intel ยุค 1970 · มาตรฐาน **IEEE 802.3** · ชื่อ **[ความเร็ว]BASE-[สื่อ]** (BASE = Baseband · **T = Twisted pair**, F/FX/SX/LX = Fiber)
  - 10BASE-T (10 Mbps) · **Fast Ethernet 100BASE-TX** (100 Mbps) · **Gigabit 1000BASE-T** · 10GBASE-T (Cat 6a) · 40/100/400 GbE (Fiber, Data Center) · UTP จำกัด **100 เมตร**
- **Wi-Fi** (Wireless Fidelity) IEEE 802.11 · พื้นที่ครอบคลุม AP = **Hotspot** รัศมี ~100 ม. · Wi-Fi 5 = 802.11ac (2.4 **หรือ** 5 GHz) · Wi-Fi 6/7 ใช้ได้ทั้ง 2.4–6 GHz
- **WiMAX** (Worldwide Interoperability for Microwave Access) **802.16** · 802.16a เสาห่างได้ถึง 48 กม. · 802.16e ฝั่งลูกข่าย · แพ้ LTE

## 8. IP Address (น.275–284) ⭐⭐
- **IPv4** = **32 บิต** 4 ชุด ชุดละ 8 บิต (0–255) คั่นด้วย **จุด** · ~4,294,967,296 (≈4 พันล้าน) · หมดแล้วปี 2019
- **IPv6** = **128 บิต** คั่นด้วย **โคลอน (:)** เลขฐาน 16 เช่น 2001:0db8:85a3::8a2e:0370:7334 · ≈ 3.4 × 10³⁸ หมายเลข · IPv4 กับ IPv6 คุยกันตรงไม่ได้
- **IPv5** ใช้ทดลองส่งภาพ/เสียง (ST) ไม่เคยใช้สาธารณะ

| Class | ช่วงไบต์แรก | Default Mask | Private IP |
|---|---|---|---|
| **A** | 1–126 (127 = Loopback ทดสอบ) | 255.0.0.0 (/8) | **10.0.0.0 – 10.255.255.255** |
| **B** | 128–191 | 255.255.0.0 (/16) | **172.16.0.0 – 172.31.255.255** |
| **C** | 192–223 | 255.255.255.0 (/24) | **192.168.0.0 – 192.168.255.255** |
| **D** | 224–239 | — | **Multicast** |
| **E** | 240–255 | — | สำรอง (ทดลอง) |

- **Private IP** ใช้ภายในองค์กร ออกอินเทอร์เน็ตไม่ได้ ต้องผ่าน **NAT** (Router แปลง Private ↔ Public) · เปรียบ Public IP = เบอร์สำนักงาน, Private IP = เบอร์ต่อภายใน, Router = ตู้ PABX
- **Subnet Mask** แบ่งส่วน **Network** กับ **Host** · Prefix /n = มีบิต 1 n ตัว
- **สูตร**: จำนวน IP ต่อวง = 2^(32−n) · **Host ใช้ได้ = 2^(32−n) − 2** (ตัด Network Address ตัวแรก + Broadcast ตัวสุดท้าย)
  - /24 → 256 − 2 = **254** · /25 → 126 · /26 → **62** · /27 → 30 · /28 → **14** · /29 → 6 · /30 → **2**
- ตารางจำ Mask ไบต์สุดท้าย: /25=128 · /26=192 · /27=224 · /28=240 · /29=248 · /30=252 · /31=254 · /32=255
- **วิธีหา Network/Broadcast**: ขนาดบล็อก = 256 − ค่า Mask · Network = (เลขชุดสุดท้าย ÷ ขนาดบล็อก ปัดลง) × ขนาดบล็อก · Broadcast = Network + บล็อก − 1
  - 192.168.1.50/30 → บล็อก 4 → Network **.48** · Broadcast **.51** · Host .49–.50
  - 192.168.1.164/28 → บล็อก 16 → Network **.160** · Broadcast **.175** · Host .161–.174 (14 Host)
  - 192.168.1.164/26 → บล็อก 64 → Network **.128** · Broadcast **.191** · Host .129–.190 (62 Host)
  - วิธีบิต: Network = IP **AND** Mask · Broadcast = Network **OR** (Mask กลับบิต)

## 9. รูปแบบการสื่อสาร (น.285) ⭐
- **Unicast** 1:1 (โทรคุย 2 คน, ดู Netflix)
- **Broadcast** 1:ทั้งหมด (ทีวี วิทยุ, **ARP, Hub**) ใช้เฉพาะใน LAN เสี่ยง **Broadcast Storm**
- **Multicast** 1:กลุ่มเฉพาะ (Video Conference, อีเมลถึงหลายคน, เรียนออนไลน์) · IP Class D

## 10. Presentation Layer: เข้ารหัส & รหัสอักขระ (น.286–288) ⭐
- **Encryption** (Plaintext → Ciphertext) · **Decryption** (กลับเป็นข้อความเดิม)
- **Symmetric (Secret Key)** **กุญแจเดียวกัน** ทั้งเข้า-ถอด: **DES, 3DES, AES, Blowfish, RC4/5/6** · จุดอ่อน = แจกจ่ายกุญแจยาก
- **Asymmetric (Public Key)** **คู่กุญแจ** Public (แจกได้) + Private (เก็บลับ) เข้ารหัสด้วยดอกหนึ่งต้องถอดด้วยอีกดอก: **RSA, Diffie-Hellman, ECC, DSA** · **ECC** ปลอดภัยเท่า RSA แต่ **Key เล็กกว่ามาก**
- **ASCII** 7 บิต 128 ตัว (Extended 8 บิต 256) อังกฤษเท่านั้น · **EBCDIC** 8 บิต ของ **IBM Mainframe** (พัฒนาต่อจาก BCD) · **Unicode/UTF-8** 1–4 ไบต์ ทุกภาษา (อังกฤษ 1 ไบต์ **ไทย 3 ไบต์**) มาตรฐาน ISO/IEC 10646

## 11. Application Layer (น.288–293) ⭐
- **DNS** แปลง**ชื่อโดเมน → IP** (เหมือนสมุดโทรศัพท์)
  - โดเมน 2 ระดับ: .com (การค้า) .org (ไม่แสวงกำไร) .net (เครือข่าย) .edu (การศึกษา) .gov (รัฐบาล) .info .biz
  - โดเมน 3 ระดับ (ไทย): **.co** (บริษัท) · **.ac** (การศึกษา) · **.go** (รัฐบาล) · .or (ไม่แสวงกำไร) · .net (ISP) · .in (บุคคล) + **.th**
  - ขวาสุด = **TLD**: **gTLD** (.com .net .org) / **ccTLD** (.th .jp .uk) ดูแลโดย **ICANN** · ถัดมา = Second-Level, Third-Level Domain
- **FTP** (Port 21 คำสั่ง/20 ข้อมูล) Client-Server ไม่เข้ารหัส → ใช้ **SFTP** (ผ่าน SSH **Port 22**) แทน
- **HTTP** ส่ง Clear text (80) · **HTTPS** เข้ารหัสด้วย SSL/TLS (443) ต้องมี **SSL Certificate** ข้อดี: ปลอดภัย น่าเชื่อถือ **SEO ดีขึ้น**
- **WWW** = ห้องสมุดเอกสาร Hypertext · **HTTP** = ภาษาที่คุยกับบรรณารักษ์ · **URL** (Uniform Resource Locator) 5 ส่วน: โปรโตคอล · ชื่อโดเมน · นามสกุลโดเมน · ไดเรกทอรี/พาธ · ชื่อไฟล์ · Domain เป็นส่วนย่อยของ URL

## 12. Firewall (น.294–295) ⭐
- ซอฟต์แวร์/ฮาร์ดแวร์ตรวจข้อมูลเข้า-ออกตาม**กฎ (Rule)** ไม่ผ่านกฎข้อเดียวก็ไม่ให้ผ่าน
- หน้าที่: **Packet Filtering** (IP/Port) · **Stateful Inspection** (ดูสถานะการเชื่อมต่อ) · **NAT** · **Content Filtering** (บล็อกเว็บ) · **IDS/IPS** (ตรวจจับ/ป้องกันการบุกรุก)
- ประเภท: Hardware · Software · Cloud · **NGFW** (ตรวจมัลแวร์ ป้องกัน **Zero-Day**)

## 13. ออกแบบเครือข่ายองค์กร (Network Diagram) (น.296–298)
- ผู้ใช้ภายนอก → **VPN Client** (เข้ารหัสผ่าน ISP) → **Firewall + IDS** → **DMZ** (โซนกึ่งกลางวาง **Web/Mail/VPN Server** ที่เปิดให้คนนอกใช้) → Router → **Core Switch** → Switch/Access Point แต่ละอาคาร
- เส้นทางออกเน็ต: **AP → Switch → Core Switch → Router → Firewall → Internet**
