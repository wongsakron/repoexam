# บทที่ 1 ความรู้เบื้องต้นเกี่ยวกับคอมพิวเตอร์
> เล่ม 1 หน้า 11–40 · ออก: บุคคลสำคัญ ยุคคอมพิวเตอร์ ประเภทคอมพิวเตอร์ หน่วยวัด กฎของมัวร์ AI/ML/Gen AI การแก้ปัญหาเบื้องต้น

## 1. ความหมาย (น.11)
- **คอมพิวเตอร์** = เครื่องคำนวณอิเล็กทรอนิกส์ (ฮาร์ดแวร์+ซอฟต์แวร์) ทำงานตามชุดคำสั่ง เร็ว ต่อเนื่อง อัตโนมัติ
- **เทคโนโลยี** = สิ่งที่มนุษย์สร้างขึ้นเพื่อตอบสนองความต้องการของตัวเอง

## 2. บุคคลสำคัญ (น.11–17) ⭐
- **ลูกคิด (Abacus)** จีน ~700 ปีก่อน = เครื่องคำนวณยุคแรก
- **Blaise Pascal** → **Pascaline** (เครื่องคำนวณแบบเฟือง บวก–ลบ) · **Leibniz** → คูณ–หารได้
- **Joseph Marie Jacquard** → เครื่องทอผ้าใช้**บัตรเจาะรู** (ต้นแบบการป้อนข้อมูล)
- **Charles Babbage** → Difference Engine, **Analytical Engine** (5 ส่วน: Input, Arithmetic, Control, Memory, Output) = **บิดาแห่งคอมพิวเตอร์**
- **Lady Ada Augusta Byron (Lovelace)** = **โปรแกรมเมอร์คนแรกของโลก**
- **Herman Hollerith** → เครื่องจัดเรียงบัตรเจาะรู (1886) → บริษัทที่กลายเป็น **IBM** (1924)
- **Howard Aiken** (Harvard + IBM) → **Mark I** (1944) เครื่องคำนวณอัตโนมัติเครื่องแรก (ใช้ relay)
- **Eckert & Mauchly** → **ENIAC** (1946, หลอดสุญญากาศ หนัก 30 ตัน) → **UNIVAC** = คอมพิวเตอร์**เพื่อการค้า**เครื่องแรก
- **John von Neumann** → แนวคิด**เก็บโปรแกรมและข้อมูลในหน่วยความจำ (Stored Program)** + ใช้เลขฐานสอง → **EDVAC** = **บิดาคอมพิวเตอร์คนที่ 2**
- **Maurice Wilkes** (Cambridge) → **EDSAC** สร้างเสร็จก่อน EDVAC (ใช้เทปแม่เหล็ก)

## 3. ยุคของคอมพิวเตอร์ 5 ยุค (น.17–19) ⭐
| ยุค | เทคโนโลยี | จุดเด่น |
|---|---|---|
| 1 (2497–2501) | **หลอดสุญญากาศ** | ใหญ่ ร้อน กินไฟ · ENIAC, EDVAC, UNIVAC |
| 2 (2502–2507) | **ทรานซิสเตอร์** | วงแหวนแม่เหล็กเป็นหน่วยความจำ · ไทยใช้ครั้งแรก **IBM 1620, IBM 1401** |
| 3 (2508–2513) | **IC (วงจรรวม)** บนชิปซิลิกอน | เล็กลง ถูกลง |
| 4 (2514–2523) | **LSI/VLSI → ไมโครโปรเซสเซอร์** | CPU บนชิปเดียว ยุค PC เฟื่องฟู |
| 5 (ปัจจุบัน) | **ปัญญาประดิษฐ์ (AI)** | สั่งด้วยเสียง Affective Computing |

## 4. ประเภทคอมพิวเตอร์ (น.19–23) ⭐
- **Supercomputer** เร็วที่สุด แพงสุด (NASA, พยากรณ์อากาศ, จำลองนิวเคลียร์) · หน่วยวัด **FLOPS** · อันดับ 1 ปี 2025 = **El Capitan (1.742 ExaFLOPS)**, Frontier, Aurora
  - kilo 10³ → mega 10⁶ → giga 10⁹ → tera 10¹² → peta 10¹⁵ → **exa 10¹⁸** (ปัจจุบัน)
- **Mainframe** เน้นธุรกรรมจำนวนมาก เชื่อถือได้ 24/7 (ธนาคาร สายการบิน) · หน่วยวัดเดิม **MIPS** ปัจจุบัน **TPM** (Transactions Per Minute)
- **Minicomputer/Midrange** = เครื่อง **Server** (องค์กรขนาดกลาง หน่วยงานระดับกรม)
- **Microcomputer/PC**: Desktop (All-in-one) · Portable (Notebook/Laptop, Tablet, Palmtop, Smartphone, Wearable)
- **Embedded Computer** = Microcontroller ฝังในอุปกรณ์ (เบรก ABS, โดรน, เครื่องใช้ไฟฟ้า) → พัฒนาเป็น **IoT**

## 5. หน่วยวัด (น.23–24)
- 8 bit = 1 Byte · มาตราเดิม KB = 1,000 B (ใช้กับความจุดิสก์ขาย) · มาตราใหม่ **KiB = 1,024 B** (RAM/SSD)
- เรียง KB → MB → GB → TB → **PB → EB → ZB → YB** (จำ "PEZY")
- ความเร็ว: **Hz** (รอบ/วินาที, CPU ระดับ GHz) · **MIPS** (ล้านคำสั่ง/วินาที) · **TPM** · **FLOPS** (ซูเปอร์คอม)
- อัตราส่งข้อมูล/บิตเรต: **bps** (Kbps, Mbps, Gbps)

## 6. กฎของมัวร์ (น.24–25)
- **Gordon Moore** (ผู้ร่วมก่อตั้ง Intel, 1965): จำนวนทรานซิสเตอร์บนวงจรรวม**เพิ่มเป็นเท่าตัวทุก ~2 ปี**

## 7. ปัญญาประดิษฐ์ (AI) (น.25–32) ⭐
- นิยาม 4 แบบ (Russell & Norvig): **คิดเหมือนมนุษย์** · **คิดอย่างมีเหตุผล** (Expert System) · **กระทำเหมือนมนุษย์** (Text↔Speech, หุ่นยนต์) · **กระทำอย่างมีเหตุผล** (ขับรถอัตโนมัติ)
- ตัวอย่าง: Da Vinci (ผ่าตัด), Inspection Robot, AGV คลังสินค้า, Disaster Robot, Siri/Google Assistant, Robo-advisor
- **AI ⊃ Machine Learning ⊃ Deep Learning**
- **Machine Learning** เรียนรู้จากข้อมูลเอง · องค์ประกอบ: **Data + Data Model** · Training Set / Test Set
  - **Supervised** (มีผู้สอน มีเฉลย บอกว่าหมา/แมว) · **Unsupervised** (ไม่มีเฉลย หาโครงสร้างเอง/Clustering) · **Reinforcement** (รางวัล–บทลงโทษ เช่น Algorithmic Trading)
- **Deep Learning** ใช้ **ANN (โครงข่ายประสาทเทียม)** ประมวลผลแบบขนาน
- **Generative AI** สร้างข้อมูลใหม่ (ข้อความ ภาพ เสียง วิดีโอ) ด้วย **LLM**
  - **ChatGPT** (OpenAI, พ.ย. 2565) · **Meta Llama** · **Microsoft Copilot** (ฝังใน Microsoft 365, เปิดตัว 16 มี.ค. 2023) · **Google Gemini** (Native **Multimodal**)

## 9. ปัญหาคอมพิวเตอร์และการแก้เบื้องต้น (น.35–40)
- ช้า → ลบไฟล์ขยะ/**Disk Cleanup** · ปิดโปรแกรมเบื้องหลังใน **Task Manager** · เพิ่ม RAM/เปลี่ยน **SSD**
- ค้าง → **Ctrl+Alt+Del**/Ctrl+Shift+Esc (Mac: Command+Option+Esc) · รีสตาร์ทเองบ่อย → ความร้อน/ไดรเวอร์/PSU
- บูตช้า → ปิดโปรแกรม Startup · บูตไม่ขึ้น → **Safe Mode**, **System Restore**, เช็กสาย SATA/M.2
- **จอฟ้า (BSOD)** → จดรหัส Error, อัปเดตไดรเวอร์, ถอนโปรแกรมที่เพิ่งลง
- เน็ตไม่ได้ → รีสตาร์ทเราเตอร์ เช็กสาย LAN/RJ-45 · เว็บช้า → ล้าง Cache/Cookies เปลี่ยน DNS **8.8.8.8 / 8.8.4.4**
- จอไม่ขึ้น → เช็กสายจอ ถอด–เสียบ RAM · เครื่องร้อน → ทำความสะอาดฝุ่น Thermal Paste
- เครื่องพิมพ์ไม่ออก → เช็กหมึก กระดาษติด ไดรเวอร์ **Print Spooler**
- ไฟล์หาย → Recycle Bin, Recuva/EaseUS · โดนไวรัส → สแกน Antivirus เปลี่ยนรหัสผ่าน
- **เวลาเพี้ยนทุกครั้งที่เปิดเครื่อง → ถ่าน CMOS (CR2032) หมด** ทำให้ SSL ไม่ตรง เข้าเว็บบางแห่งไม่ได้
