## 1. ระบบเลขฐาน (น.191–192)
- ฐานสอง (Binary) 0–1 · ฐานแปด (Octal) 0–7 · ฐานสิบ (Decimal) 0–9 · ฐานสิบหก (Hexadecimal) 0–9, **A=10 B=11 C=12 D=13 E=14 F=15**
- ฐานสองเข้ากับฮาร์ดแวร์โดยตรง (ไฟฟ้า 2 สถานะ) · 1 หลัก = **Bit** (Binary Digit)
- **ฐานแปด 1 หลัก = ฐานสอง 3 บิต** · **ฐานสิบหก 1 หลัก = ฐานสอง 4 บิต**

## 2. แปลงระหว่างฐาน 2 / 8 / 16 (น.193–195) ⭐
- **2 → 8**: ตัดทีละ **3 บิตจากขวา** แทนค่า เช่น 1010010101₂ → 1|010|010|101 = **1225₈**
- **2 → 16**: ตัดทีละ **4 บิตจากขวา** เช่น 1010010101₂ → 10|1001|0101 = **295₁₆**
- **8 ↔ 16**: แปลงเป็นฐานสองก่อน แล้วตัดใหม่ เช่น 2467₈ → 010 100 110 111 → 0101 0011 0111 = **537₁₆** · AEC₁₆ → 101 011 101 100 = **5354₈**
- ทศนิยม: ส่วนเต็มตัดจาก**ขวาไปซ้าย** · ส่วนทศนิยมตัดจาก**ซ้ายไปขวา** (เติม 0 ท้ายให้ครบ) เช่น AEC.CD₁₆ = **5354.632₈**

## 3. ฐานใดๆ ↔ ฐานสิบ (น.195–212) ⭐
- **ฐานใดๆ → 10**: คูณค่าประจำหลัก (ฐาน^ตำแหน่ง) แล้วรวม
  - ฐาน 2 ค่าประจำหลัก: …256 128 64 32 16 8 4 2 1 . 0.5 0.25 0.125 0.0625
  - 100100101₂ = 256+32+4+1 = **293** · 0.101₂ = 0.5+0.125 = **0.625** · 1111001.11₂ = **121.75**
  - ฐาน 8: …512 64 8 1 (232₈ = 128+24+2 = **154**) · ฐาน 16: …4096 256 16 1 (8E₁₆ = 128+14 = **142**, 3AB₁₆ = **939**)
- **10 → ฐานใดๆ**: **หารสั้นด้วยฐาน เก็บเศษ อ่านจากล่างขึ้นบน** (55 → 67₈, 35 → 100011₂, 2594 → A22₁₆)
- ทศนิยมฐาน 10 → ฐานใดๆ: **คูณด้วยฐาน** เก็บเลขหน้าจุดเรียงจากบนลงล่าง (0.375 × 8 = **3.0** → .3₈)
- ทริก: ฐาน 2 จำกำลังสอง 1, 2, 4, 8, 16, 32, 64, 128, 256, 512, 1024

## 4. การคำนวณเลขฐาน (น.205–208)
- **บวก**: บวกปกติ ถ้าผลรวม ≥ ฐาน ให้ลบฐานออกแล้วทด 1 (ฐาน2: 1+1 = 10, 1+1+1 = 11)
  - 11011₂ + 10111₂ = 110010₂ · 10110₂ + 1011₂ = **100001₂** · 99₁₆ + 11₁₆ = **AA₁₆**
- **ลบ**: ถ้าตัวตั้งน้อยกว่าให้**ยืม** โดยค่าที่ยืมมา = ค่าฐาน (ฐาน2 ยืมได้ 2, ฐาน8 ได้ 8, ฐาน16 ได้ 16)
  - 1000₂ − 111₂ = 1₂ · 1110₂ − 111₂ = **111₂**
- **คูณ**: คูณแบบฐานสิบแล้วบวกแบบฐานนั้น หรือแปลงเป็นฐานสิบคูณแล้วแปลงกลับ (1011₂ × 1101₂ = 11×13 = 143 = **10001111₂**)

## 5. 1's Complement และ 2's Complement (น.209–211) ⭐
- ทำกับฐานสองเท่านั้น (แปลงเป็นฐาน 2 ก่อน)
- **1's Complement** = **กลับบิต** 0↔1 (11111000 → 00000111)
- **2's Complement** = **1's Complement + 1** (00111 → 11000 → **11001**) · ใช้แทนเลขลบในคอมพิวเตอร์
- ตัวอย่าง: 2's ของ 11111100 = 00000011 + 1 = 00000100 (= 4 → แปลว่า 11111100 คือ −4)

## 6. รหัสแทนข้อมูล (เสริมจากข้อสอบ)
- **ASCII** 7 บิต (128 ตัว) / Extended ASCII 8 บิต (256 ตัว) · **Unicode** รองรับทุกภาษา (UTF-8, UTF-16)
- 8 บิต = 1 ไบต์ = 1 ตัวอักษร · 4 บิต = 1 Nibble
- (เสริม) เลขโรมัน I=1 V=5 X=10 L=50 C=100 D=500 M=1000 · ตัวเล็กอยู่หน้า = ลบ (IX=9, XL=40) → 249 = **CCXLIX**
