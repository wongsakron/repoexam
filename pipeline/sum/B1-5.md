# บทที่ 5 ฮาร์ดแวร์ (Hardware)
> เล่ม 1 หน้า 131–181 · ตรงหลักสูตรกรมที่ดิน (ติดตั้ง/กำหนดสเปคเครื่อง) ⭐ ออก: 5 หน่วย, CPU (Core/Thread/Cache, CISC/RISC, Machine Cycle), หน่วยความจำ, ROM/BIOS/UEFI, RAM DDR, HDD/SSD, ระบบไฟล์, จอ/เครื่องพิมพ์, การอ่านสเปค

## 1. ฮาร์ดแวร์ 5 หน่วย (น.131)
**Input · CPU · Main Memory · Secondary Storage · Output** (ทำงานไม่ได้ถ้าไม่มีซอฟต์แวร์สั่ง)

## 2. หน่วยรับข้อมูล (Input) (น.131–134)
- แบบกด (Keyboard) · ชี้ตำแหน่ง (Mouse, Touchpad, Joystick, Wiimote) · ปากกา (Stylus) · Touch Screen · รับภาพ (Barcode/QR, Scanner, กล้อง, Webcam, **Kinect**, Fingerprint, Eye Tracker, **OMR ตรวจข้อสอบ**) · เสียง (Microphone, Speech Recognition)
- หน่วยวัด: เมาส์/เครื่องพิมพ์ = **DPI** · สแกนเนอร์ = **PPM/IPM** · กล้อง = **Pixel**
- จอสัมผัส: **Resistive** (ใช้อะไรกดก็ได้) · **Capacitive** (นิ้ว/Stylus ดีกว่า ใช้ในมือถือ)

## 3. CPU (น.134–149) ⭐
- วงรอบ **Machine Cycle**: **Fetch → Decode → Execute → Store**
- ค่าสำคัญ: **Core** (สมองจริง) · **Thread** (จำลองคอร์ Hyper-Threading/SMT เช่น 12C/24T) · **Clock Speed** (GHz) · **Cache**
- Intel ไฮบริด (Gen 12+): **P-Core** (แรง) + **E-Core** (ประหยัดไฟ งานเบื้องหลัง) · AMD Zen + **3D V-Cache** · **NPU** = หน่วยประมวลผล AI (Core Ultra, Ryzen AI)
- สถาปัตยกรรม: **CISC** ชุดคำสั่งซับซ้อน หลาย Cycle กินไฟ (**Intel/AMD x86-64**) · **RISC** ชุดคำสั่งง่าย **1 Cycle/คำสั่ง** ประหยัดไฟ (**ARM**: Apple M, Snapdragon, MediaTek, Kirin) · ARM = Advanced RISC Machine (ขาย License ไม่ผลิตเอง)
- หน่วยย่อย: **CU** (ควบคุม) · **ALU** (คำนวณ + เปรียบเทียบ มากกว่า/น้อยกว่า/เท่ากับ) · **Register** (เร็วที่สุด เล็กที่สุด: Accumulator, Storage, Instruction, Address Register) · **Cache**
- Cache: **L1** (ในแต่ละคอร์ เร็วสุดรองจาก Register ~100× RAM) · **L2** (ใหญ่กว่า) · **L3** (ใช้ร่วมทุกคอร์ Shared ใหญ่สุด ช้าสุดในกลุ่ม)
- เร็ว→ช้า: **Register > Cache > RAM > Disk Cache > Disk**
- CPU/GPU/**APU** (CPU+GPU ชิปเดียว)/ECU (รถยนต์)/NPU · **Pipeline** อ่านคำสั่งถัดไประหว่างทำคำสั่งเดิม
- เทียบรุ่น: Ryzen 3/5/7/9 ≈ Core i3/i5/i7/i9 (ชื่อใหม่ Core 3/5/7, Core Ultra) · Intel ก่อตั้งปี 1968 โดย Gordon Moore & Robert Noyce
- **x86 = 32 บิต รองรับ RAM 4 GB** · **x64 = 64 บิต** รองรับ RAM มากกว่ามาก
- **Bus**: **Data Bus** (ส่งข้อมูล) · **Address Bus** (ส่งตำแหน่ง) · **Control Bus** (ส่งคำสั่ง/สถานะ) · ปัจจุบัน Memory Controller อยู่ใน CPU (ไม่มี FSB/North Bridge)

## 4. หน่วยความจำ (น.151–159) ⭐
- **Non-Volatile** (ไฟดับไม่หาย): ROM, Flash, SSD, HDD, DVD · **Volatile** (ไฟดับหาย): **DRAM** (RAM ถูก ต้อง Refresh) · **SRAM** (เร็ว แพง ไม่ต้อง Refresh ใช้ทำ **Cache**)
- **ROM** เก็บเฟิร์มแวร์บูต: ROM (โรงงานเขียน) → **PROM** (เขียนได้ครั้งเดียว) → **EPROM** (ลบด้วย**แสง UV**) → **EEPROM** (ลบด้วย**ไฟฟ้า**) → **Flash** (SSD, Flash Drive, Memory Card)
- **BIOS** ตรวจอุปกรณ์ (POST) แล้วส่งต่อให้ OS · **UEFI** แทน BIOS: ใช้ **GPT** (BIOS ใช้ MBR จำกัด 2.2 TB) · บูตเร็ว · **Secure Boot** (กันมัลแวร์) · GUI ใช้เมาส์ได้
- **RAM**: หน่วยวัด **MT/s** · DDR (Double Data Rate) · DDR3 1.5V · **DDR4 1.2V (1600–3200 MT/s)** · **DDR5 1.1V (4800–8400 MT/s)** · GDDR6 ของการ์ดจอคนละมาตรฐาน
  - ใส่ต่างบัสได้แต่จะวิ่งที่ความเร็ว**ตัวที่ช้ากว่า** · ต้อง DDR รุ่นเดียวกัน · ใส่คู่ความจุเท่ากัน = **Dual-Channel** เพิ่มแบนด์วิดท์
  - ความจุมากไม่ได้ทำให้ RAM เร็วขึ้น แต่ทำให้ระบบรวมเร็วขึ้น · **DIMM 288 พิน** (PC) · **SO-DIMM** (โน้ตบุ๊ก)
- (เสริม) **Virtual Memory** = ใช้พื้นที่ดิสก์เสริม RAM

## 5. หน่วยเก็บข้อมูลสำรอง (น.159–164)
- **HDD** จานแม่เหล็ก (Platter) วัดความเร็ว **RPM** (โน้ตบุ๊ก 5,400 / PC 7,200–10,000) ขนาด 2.5"/3.5" · เชื่อม **SATA** (Rev 3.0 = 6 Gbit/s ≈ 600 MB/s)
- **Flash**: SD/MicroSD (แบ่ง Class ความเร็ว) · Flash Drive (USB) · **SSD** เร็ว ทนแรงกระแทก กินไฟน้อย
  - Form factor: **2.5" SATA** (~550 MB/s) · **M.2 SATA** · **M.2 NVMe** (ผ่าน **PCIe** ตรงถึง CPU, Gen4/5 ≥ 7,000 MB/s) · **AIC** (การ์ด PCIe เซิร์ฟเวอร์) · อายุดูค่า **TBW**
- **Cloud Storage** เข้าถึงด้วย Username/Password จากทุกที่
- การเข้าถึงข้อมูล: **Sequential** (เทปแม่เหล็ก) · **Direct** (HDD, CD/DVD) · **Random** (RAM/ROM เวลาเท่ากันทุกตำแหน่ง) · **Associative** (Cache เร็วสุด)
- **ระบบไฟล์**: **NTFS** (Windows ปลอดภัย ไฟล์ใหญ่ได้) · **FAT32** (เข้ากันได้ทุกระบบ **จำกัดไฟล์ละ 4 GB**) · **exFAT** (Flash Drive ไม่จำกัด 4 GB) · **APFS** (Apple) · Ext4/Btrfs (Linux)

## 6. หน่วยแสดงผล (Output) (น.165–173)
- **Soft Copy** (จอ ไม่ถาวร) vs **Hard Copy** (กระดาษ/3D ถาวร)
- จอ: **CRT** (หลอดรังสีแคโทด เลิกผลิต) · **LCD** (ผลึกเหลว; LED TV = LCD ที่ใช้ไฟ LED ส่องหลัง) · **Plasma** (เลิกผลิต) · **OLED** (แต่ละพิกเซลเปล่งแสงเอง **ดำสนิท** มุมมองกว้าง เสี่ยง Burn-in) · **QLED** (LCD + Quantum Dot สว่างกว่าแต่ดำไม่สนิท)
- **Refresh Rate** (Hz: 60/120/144/240) · ความละเอียด: HD 1280×720 · **Full HD 1920×1080 (~2 ล้านพิกเซล)** · 2K QHD 2560×1440 · **4K UHD 3840×2160 (~8 ล้านพิกเซล)** · 8K 7680×4320
- เครื่องพิมพ์: **Inkjet** (พ่นหมึก ละเอียดสุดสำหรับภาพถ่ายตามหนังสือ หัวอุดตันได้) · **Laser** (ผงหมึก ประจุไฟฟ้า เร็ว ต้นทุนต่อแผ่นถูก) · **Dot Matrix** (หัวเข็มกระแทกผ้าหมึก เสียงดัง **พิมพ์สำเนาหลายชั้น** กระดาษต่อเนื่อง) · **Thermal** (ความร้อน ใบเสร็จ ATM บัตรคิว) · **3D Printer** (ต้นแบบ) · **Plotter** (ป้าย/แปลนขนาดใหญ่ A0–A2)
- Projector: **Lamp** (สว่าง ร้อน อายุ 1,000–5,000 ชม.) · **LED** (อายุ 20,000–30,000 ชม. ไม่สว่างมาก พกพา) · **Laser** (สว่าง อายุยาว ราคาแพง)
- ลำโพงอัจฉริยะ (IoT) · หูฟัง **TWS** (True Wireless Stereo) · **ANC** ตัดเสียงรบกวน
- **Microcontroller** (CPU+RAM+ROM+I/O ในชิปเดียว ประหยัดไฟ งานฝังตัว) vs **Microprocessor** (CPU อย่างเดียว ต้องต่อหน่วยความจำ/I/O แยก)

## 7. การเลือกซื้อ/อ่านสเปค (น.175–181)
- ขั้นตอน: งบ+การใช้งาน → **CPU & GPU** → Mainboard (Socket ตรง CPU) & RAM (≥ 8 GB) → **SSD NVMe M.2** เป็นไดรฟ์หลัก → **PSU** (มี Wattage เผื่อ, **80 PLUS Gold** ขึ้นไป)
- ตัวอักษรท้าย CPU: โน้ตบุ๊ก **H** (แรง) / P (สมดุล) / **U** (ประหยัดไฟ) · เดสก์ท็อป **K** (โอเวอร์คล็อกได้) / **F** (ไม่มีกราฟิกในตัว ต้องมีการ์ดจอแยก)
- RAM: 8 GB ขั้นต่ำ · 16 GB มาตรฐาน · 32 GB+ งานหนัก · SSD ≥ 256–512 GB
- GPU: Integrated (ในตัว CPU) vs Dedicated (มี VRAM) · NVIDIA GT < GTX < RTX (ท้าย: – < SUPER < Ti) · AMD Radeon < RX (ท้าย: – < XT < XTX) · VRAM ≥ 6–8 GB สำหรับเกม
- Mainboard: Socket (Intel LGA 1700, AMD AM5) · Chipset (Z790/B760, X670/B650) · ขนาด ATX > Micro-ATX > Mini-ITX
- PSU แปลงไฟ **AC → DC** · จองาน/กราฟิก: IPS/OLED 4K · เกม: 144 Hz+, < 5 ms, HDMI 2.1/DisplayPort
