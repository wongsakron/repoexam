B1-4-2-11|ChromeOS ติดตั้งแอปจาก Google Play Store ได้ และเน้นเก็บข้อมูลบนคลาวด์ (Google Drive) ตัวเครื่องจึงมีพื้นที่เก็บข้อมูลน้อย
B1-4-2-12|Standalone OS คือ OS สำหรับเครื่องส่วนบุคคลที่มีผู้ใช้หลักคนเดียว ได้แก่ Windows 11, macOS และ Android ส่วน Windows Server, UNIX และ Solaris เป็น OS เครื่องแม่ข่าย
B1-4-2-13|iPadOS, HarmonyOS และ Tizen เป็น OS ที่ฝังในอุปกรณ์เฉพาะ เช่น แท็บเล็ต สมาร์ทวอทช์ และสมาร์ททีวี (ตามการจัดกลุ่มของเล่ม) ส่วนข้ออื่นมี OS ของ PC หรือเซิร์ฟเวอร์ปนอยู่
B1-4-2-14|PC และสมาร์ทโฟนออกแบบให้ใช้งานครั้งละหนึ่งคน จึงไม่ใช่ระบบ Multiuser แต่รองรับ Multitask, Multithread และ Multiprocessing (CPU หลายคอร์)
B1-4-2-15|สถานะ Running คือโปรเซสที่กำลังครอง CPU ส่วน Ready คือพร้อมรอคิว CPU และ Waiting คือรอ I/O หรือเหตุการณ์
B1-4-2-16|Interrupt คือการขัดจังหวะโปรเซสชั่วคราวเพื่อให้ CPU ไปจัดการงานที่สำคัญกว่าก่อน แล้วค่อยกลับมาทำต่อ
B1-4-2-17|Driver เป็นตัวกลางที่ทำให้ OS รู้จัก ติดต่อ และควบคุมฮาร์ดแวร์แต่ละชิ้นได้ถูกต้อง
B1-4-2-18|Clipboard เป็นยูทิลิตี้ (Utility) ช่วยเก็บข้อมูลชั่วคราวสำหรับ Copy-Paste
B1-4-2-19|Gmail, Teams, Zoom, LINE และ Discord เป็นซอฟต์แวร์สื่อสารทั้งหมด ข้ออื่นมี Photoshop, Word, Excel หรือ Canva ปนอยู่
B1-4-2-20|Beta Software คือรุ่นทดสอบที่ปล่อยให้ผู้ใช้กลุ่มหนึ่งลองใช้และรายงานบั๊กก่อนวางจำหน่ายจริง
B1-4-2-21|Creative Commons ให้เจ้าของผลงานกำหนดเงื่อนไขการใช้ได้อย่างยืดหยุ่น (BY, NC, ND, SA) โดยยังคงเป็นเจ้าของลิขสิทธิ์อยู่
B1-4-2-22|Worm แพร่กระจายผ่านเครือข่ายได้เองโดยไม่ต้องให้ผู้ใช้รันไฟล์ ต่างจาก Virus ที่ต้องอาศัยการเปิดไฟล์ที่ติดเชื้อ
B1-4-2-23|Adware แสดงโฆษณาไม่พึงประสงค์และมักเปลี่ยนหน้าแรกของเบราว์เซอร์ (Browser Hijack)
B1-4-2-24|Rootkit ซ่อนตัวในระดับลึก (Kernel) เพื่อปกปิดร่องรอยของมัลแวร์อื่นหรือของแฮกเกอร์ จึงตรวจจับได้ยาก
B1-4-2-25|DDoS คือการใช้เครื่องจำนวนมาก (Botnet) ส่งทราฟฟิกท่วมเป้าหมายจนให้บริการไม่ได้ ข้อ ข คือ Ransomware ส่วนข้อ ค และ ง คือการดักขโมยข้อมูล
B1-4-2-26|การอัปเดต Patch ของ OS และแอปคือการปิดช่องโหว่ (Vulnerability) โดยตรง ส่วนข้ออื่นป้องกันภัยด้านอื่น
B1-4-2-27|การสำรองข้อมูล (Backup) แยกเก็บไว้ทำให้กู้คืนไฟล์ได้แม้ถูก Ransomware เข้ารหัส จึงป้องกันข้อมูลสูญหายได้ตรงที่สุด
B1-4-3-1|Virtual Computer (Virtual Machine) คือเครื่องเสมือนที่ซอฟต์แวร์จำลองขึ้น ให้ทำงานได้เหมือนคอมพิวเตอร์จริงเครื่องหนึ่ง
B1-4-3-2|Hypervisor (Virtual Machine Monitor) จัดสรรและแบ่ง CPU, RAM และ Storage ของเครื่อง Host ให้เครื่อง Guest แต่ละเครื่อง
B1-4-3-3|Hypervisor Type 1 (Bare Metal) ติดตั้งลงบนฮาร์ดแวร์โดยตรงโดยไม่มี OS คั่น เช่น VMware ESXi และ Hyper-V
B1-4-3-4|การรวมเซิร์ฟเวอร์ (Server Consolidation) ลดจำนวนเครื่องจริง จึงประหยัดไฟ พื้นที่ และค่าบำรุงรักษา
B1-4-3-5|Guest OS ทำงานในเครื่องเสมือนที่ Hypervisor สร้างและจัดการให้ และไม่จำเป็นต้องเป็น OS ชนิดเดียวกับ Host
B1-4-3-6|Hypervisor แบ่งทรัพยากรจริงที่มีให้ VM แต่ละเครื่องตามที่ตั้งค่าไว้ เช่น 2 vCPU และ RAM 4 GB
B1-4-3-7|Hypervisor Type 2 เรียกว่า Hosted ติดตั้งบน OS หลักเหมือนโปรแกรมทั่วไป เช่น VirtualBox และ VMware Workstation
B1-4-3-8|VM เหมาะกับการทดสอบซอฟต์แวร์บนหลาย OS เพราะสร้าง ลบ และย้อนสถานะ (Snapshot) ได้ง่าย แต่ไม่เหมาะกับเกมที่ต้องใช้ฮาร์ดแวร์เต็มกำลัง
B1-4-3-9|Linux เป็นระบบปฏิบัติการ ไม่ใช่ Hypervisor (แม้ Linux จะมี KVM อยู่ในตัว) ส่วน Hyper-V, KVM และ VirtualBox เป็น Hypervisor
B1-4-3-10|Server Virtualization รวมเซิร์ฟเวอร์หลายเครื่องให้ทำงานบนเครื่องจริงน้อยลง เพื่อประหยัดค่าใช้จ่ายและใช้ทรัพยากรคุ้มค่าขึ้น
B1-4-3-11|Network Virtualization ใช้ซอฟต์แวร์สร้างเครือข่ายเสมือน (Logical Network) หลายวงบนโครงสร้างเครือข่ายจริงชุดเดียว เช่น VLAN และ SDN
B1-4-3-12|ศูนย์ข้อมูลนิยมใช้ Type 1 (Bare Metal) เพราะไม่มี OS คั่นกลาง จึงเร็วและเสถียรกว่า
B1-4-3-13|VDI เก็บเดสก์ท็อปและข้อมูลไว้ที่เซิร์ฟเวอร์กลาง ทำให้ควบคุมความปลอดภัยและสำรองข้อมูลได้ง่าย แต่ต้องออนไลน์ และผู้ใช้ติดตั้งโปรแกรมเองไม่ได้
