B2-5-1-1|ระบบ (System) คือองค์ประกอบตั้งแต่สองสิ่งขึ้นไปทำงานร่วมกันเพื่อเป้าหมายเดียวกัน

B2-5-1-3|DFD (Data Flow Diagram) คือแผนภาพการไหลของข้อมูลในระบบ
B2-5-1-4|สัญลักษณ์ DFD มี 4 อย่าง คือ Process (วงกลม/สี่เหลี่ยมมุมมน), External Entity (สี่เหลี่ยม), Data Store (สี่เหลี่ยมเปิดด้านข้าง) และ Data Flow (ลูกศร) ข้อที่ไม่ใช่ให้ดูจากภาพตัวเลือก
B2-5-1-5|ชื่อ Process ต้องเป็นคำกริยา (เช่น ตรวจสอบ หรือคำนวณ) ไม่ใช่คำนาม ข้อ ก จึงกล่าวผิด
B2-5-1-6|กฎของ DFD: ข้อมูลระหว่าง Entity กับ Data Store ต้องผ่าน Process เสมอ Process จึงเป็นศูนย์กลาง และ Process ต้องมีทั้งข้อมูลเข้าและออก
B2-5-1-7|ข้อความกำกับ Data Flow ต้องเป็นคำนามที่บอกชื่อข้อมูล เช่น "ข้อมูลพนักงาน"
B2-5-1-8|Context Diagram (DFD Level 0) แสดงภาพรวมของระบบเป็น Process เดียว พร้อม External Entity ที่เกี่ยวข้อง
B2-5-1-9|ดูลูกศรที่ชี้ไปหาผู้บริหารในแผนภาพ ข้อมูลที่ผู้บริหารได้รับคือ "รายงานประจำวัน"
B2-5-1-10|ข้อความกำกับ Data Flow ต้องเป็นชื่อข้อมูล (คำนาม) ส่วน "แจ้งเตือนสินค้าใกล้หมด" เป็นการกระทำ จึงไม่ตรงกฎ (ดูแผนภาพ)
