B1-8-1-1|การต่อจอ LCD 2 จอเข้ากับคอมพิวเตอร์เป็นการต่ออุปกรณ์แสดงผล ไม่ใช่เครือข่าย เพราะเครือข่ายคือการเชื่อมอุปกรณ์ตั้งแต่ 2 เครื่องขึ้นไปเพื่อสื่อสารและแบ่งปันทรัพยากร
B1-8-1-2|PAN คือเครือข่ายส่วนบุคคลระยะใกล้มาก เช่น Bluetooth และ AirDrop ส่วน Wi-Fi ในบ้านเป็น LAN และ Cellular เป็น WAN
B1-8-1-3|LAN ครอบคลุมพื้นที่จำกัด เช่น อาคารหรือสำนักงาน ระยะไม่เกินประมาณ 1 กม. ถ้าห่างกันเกินนั้นจะเป็น MAN/WAN
B1-8-1-4|Ethernet = IEEE 802.3, Wi-Fi = 802.11, WiMAX = 802.16 และ Token Ring = 802.5
B1-8-1-5|MAN เชื่อมเครือข่ายระดับเมือง/จังหวัด นิยมใช้สายใยแก้วนำแสงเป็นแกนหลัก
B1-8-1-6|ตามแนวของเล่ม เครือข่ายโทรศัพท์มือถือ 5G เป็น WAN แบบไร้สายที่ครอบคลุมทั้งประเทศ ส่วน WiMAX และเคเบิลทีวีเป็นระดับ MAN
B1-8-1-7|สายเคเบิลใต้น้ำเชื่อมระหว่างประเทศหรือทวีป จึงเป็น WAN
B1-8-1-8|Wireless WAN คือเครือข่ายไร้สายครอบคลุมพื้นที่กว้าง เช่น เครือข่ายโทรศัพท์มือถือ (Cellular) ส่วน WiMAX เป็น Wireless MAN และ Wi-Fi เป็น Wireless LAN
B1-8-1-9|Intranet และ Extranet แบ่งตามการควบคุมการเข้าถึง เน้นความปลอดภัยและจำกัดผู้ใช้ ไม่ได้แบ่งตามขนาดพื้นที่
B1-8-1-10|Extranet ขยายจาก Intranet ให้คนภายนอกที่ได้รับอนุญาต เช่น คู่ค้า เข้าถึงข้อมูลได้เท่าที่จำเป็น
B1-8-1-11|ISP (Internet Service Provider) คือผู้ให้บริการอินเทอร์เน็ต เช่น True, AIS และ 3BB
B1-8-1-12|E-Commerce ขายสินค้าให้บุคคลทั่วไป จึงใช้เครือข่ายอินเทอร์เน็ต
B1-8-1-13|Client คือเครื่องผู้ใช้บริการ ส่วน Server คือเครื่องผู้ให้บริการ
B1-8-1-14|เครือข่ายไร้สายถูกรบกวนได้ง่ายกว่า จึงมีโอกาสผิดพลาดในการส่งข้อมูลมากกว่าแบบมีสาย ข้อ ง จึงกล่าวผิด
B1-8-1-15|P2P (Peer-to-Peer) ทุกเครื่องมีฐานะเท่ากัน เป็นได้ทั้งผู้ให้และผู้รับบริการ
B1-8-1-16|Topology คือรูปแบบการเชื่อมต่อทางกายภาพของเครือข่าย เช่น Bus, Star, Ring และ Mesh
B1-8-1-17|Backbone คือสายแกนหลักใน Topology แบบ Bus ที่ทุกเครื่องต่อพ่วงเข้ามา (ตามแนวของเล่ม)
B1-8-1-18|Star นิยมที่สุด เพราะทุกเครื่องต่อเข้ากับศูนย์กลาง (Switch/AP) ติดตั้งและหาจุดเสียง่าย และเครื่องหนึ่งเสียไม่กระทบเครื่องอื่น
B1-8-1-19|Ethernet ปัจจุบันใช้ Switch เป็นศูนย์กลาง จึงเป็น Topology แบบ Star
B1-8-1-20|Wi-Fi AP, Switch และ Repeater เป็นศูนย์กลางของเครือข่ายแบบ Star ส่วน Microwave เป็นสื่อสัญญาณแบบจุดต่อจุด
B1-8-1-21|ipconfig แสดงค่า IP Address, Subnet Mask และ Gateway ของเครื่อง ส่วน tracert ตรวจเส้นทาง และ ping ตรวจว่าปลายทางยังติดต่อได้
B1-8-1-22|สัญญาณอนาล็อกเป็นคลื่นต่อเนื่อง สัญญาณรบกวนจึงบิดเบือนคลื่นได้ง่ายที่สุด ส่วนดิจิทัลมีแค่ 0/1 จึงทนกว่า
B1-8-1-23|Demodulation คือการแปลงอนาล็อกเป็นดิจิทัล ส่วน Modulation คือดิจิทัลเป็นอนาล็อก (โมเด็ม = Modulator + Demodulator)
B1-8-1-24|สายใยแก้วนำแสงส่งข้อมูลด้วยสัญญาณแสง (Optical)
B1-8-1-25|สายขาดทำให้ส่งสัญญาณไม่ได้เลย ไม่ได้ทำให้เกิดสัญญาณรบกวน ส่วนฟ้าผ่า พายุสุริยะ และความร้อนเป็นแหล่งของสัญญาณรบกวน
B1-8-1-26|Crosstalk คือสัญญาณรบกวนข้ามสายจากสายที่อยู่ใกล้กัน จึงต้องบิดเกลียวสาย
B1-8-1-27|ใยแก้วนำแสงเร็วที่สุด ส่วน RG6 คือสายโคแอกเชียลชนิดหนึ่ง
B1-8-1-28|หัว RJ45 ใช้กับสาย Twisted Pair (สาย LAN UTP/STP)
B1-8-1-29|STP (Shielded Twisted Pair) มีชีลด์ฟอยล์หุ้มป้องกันสัญญาณรบกวน จึงเหมาะกับพื้นที่ที่มีสัญญาณรบกวนมาก
B1-8-1-30|สาย Twisted Pair มี 4 คู่สี คือ ส้ม เขียว น้ำเงิน และน้ำตาล (และสีขาวคู่) ไม่มีสีม่วง
B1-8-1-31|CAT8 เร็วที่สุด (25-40 Gbps) รองลงมาคือ CAT7, CAT6 และ CAT5e
B1-8-1-32|แสงเดินทางในแกนกลาง (Core) โดยมี Cladding หุ้มให้แสงสะท้อนกลับเข้าแกน
B1-8-1-33|Multimode มีแกนใหญ่ แสงเดินได้หลายแนว (หลายโหมด) จึงไปได้ใกล้กว่าและถูกกว่า Single Mode
B1-8-1-34|ดาวเทียมสื่อสารใช้คลื่นไมโครเวฟ (ช่วงความถี่ GHz) รับส่งข้อมูล
B1-8-1-35|Wi-Fi ใช้คลื่นวิทยุย่าน 2.4/5/6 GHz ส่วนรีโมททีวีใช้อินฟราเรด และ PoE เป็นการจ่ายไฟผ่านสาย LAN
B1-8-1-36|รีโมททีวีส่งสัญญาณด้วยคลื่นอินฟราเรด
B1-8-1-37|ONU (Optical Network Unit) ใช้กับอินเทอร์เน็ตไฟเบอร์ (FTTH) จึงเร็วที่สุด ส่วน VDSL, ADSL และ 56K ใช้สายทองแดง
B1-8-1-38|Router หาเส้นทาง (Routing) และเชื่อมต่อระหว่างเครือข่าย
B1-8-1-39|HUB เป็นศูนย์กลางเชื่อมต่อแบบมีสายเหมือน Switch แต่ส่งข้อมูลไปทุกพอร์ต (Broadcast) ส่วน Switch ส่งตรงไปพอร์ตปลายทาง
B1-8-1-40|PoE (Power over Ethernet) จ่ายไฟฟ้าผ่านสาย LAN ไปยังอุปกรณ์ เช่น กล้อง IP หรือ AP
B1-8-1-41|Ethernet Port คือช่องเสียบสาย LAN หัว RJ45 (ดูภาพประกอบตัวเลือก)
B1-8-1-42|Cell คือพื้นที่ครอบคลุมการให้บริการของสถานีฐานแต่ละแห่ง
B1-8-1-43|1G เป็นยุคอนาล็อกที่ใช้โทรด้วยเสียงอย่างเดียว ส่วน 2G เริ่มเป็นดิจิทัล
B1-8-1-44|3G ทำให้มือถือเชื่อมต่ออินเทอร์เน็ตแบบ Always On ได้
B1-8-1-45|ตามแนวของเล่ม 5G ใช้คลื่นมิลลิเมตร (mmWave) ช่วงประมาณ 30-300 GHz
B1-8-1-46|5G เร็วมาก หน่วงต่ำ (Latency ต่ำ) และรองรับอุปกรณ์จำนวนมหาศาล
B1-8-1-47|Cellular เป็นมาตรฐานของ 3GPP/ITU ส่วน Wi-Fi (802.11), WiMAX (802.16) และ Ethernet (802.3) เป็นมาตรฐาน IEEE
B1-8-1-48|6G ต้องมี Latency ต่ำมาก ไม่ใช่สูงมาก
B1-8-1-49|Ethernet เป็นเทคโนโลยีหลักของเครือข่าย LAN ส่วน IEEE เป็นชื่อองค์กร และ WiMAX/LTE เป็นเครือข่ายพื้นที่กว้าง
B1-8-1-50|Wi-Fi ใช้คลื่นวิทยุย่าน 2.4, 5 และ 6 GHz (ตามแนวของเล่ม) ความเร็วสูงสุดไม่ถึง 200 Gbps และไม่ได้ถูก WiMAX แทนที่
B1-8-2-1|IP Address คือหมายเลขที่ระบุอุปกรณ์ที่เชื่อมต่อเครือข่าย ส่วนหมายเลขจากโรงงานคือ MAC Address
B1-8-2-2|Public IP คือ IP จริงที่ใช้บนเครือข่ายอินเทอร์เน็ตสาธารณะ และต้องไม่ซ้ำกันทั่วโลก
B1-8-2-3|NAT (Network Address Translation) แปลงระหว่าง Public IP กับ Private IP ที่ Router
B1-8-2-4|IPv6 ยาว 128 บิต ส่วน IPv4 ยาว 32 บิต
B1-8-2-5|10.x.x.x เป็น Private IP ของ Class A (10.0.0.0 – 10.255.255.255)
B1-8-2-6|Broadcast คือส่งจากโหนดเดียวไปทุกโหนดในเครือข่าย
B1-8-2-7|Unicast คือการสื่อสารแบบหนึ่งต่อหนึ่ง เช่น โทรศัพท์หาเพื่อนคนเดียว
B1-8-2-8|Multicast คือส่งจากผู้ส่งหนึ่งไปยังกลุ่มผู้รับที่เลือกไว้ เช่น เรียนออนไลน์เป็นกลุ่ม (ส่วนเสียงตามสายเป็น Broadcast)
B1-8-2-9|Encryption คือการเข้ารหัส ส่วน Decryption คือการถอดรหัส
B1-8-2-10|Public Key (Asymmetric) ใช้กุญแจสองดอก (Public/Private) จึงปลอดภัยกว่าแบบ Secret/Symmetric Key ที่ใช้กุญแจดอกเดียว
