B1-7-1-3|สื่อกลาง (Medium) คือช่องทางที่ข้อมูลเดินทางผ่าน ในที่นี้คือสัญญาณอินเทอร์เน็ต ส่วนอุปกรณ์เคลื่อนที่เป็นอุปกรณ์ของผู้ส่งและผู้รับ
B1-7-1-4|ตามแนวของเล่ม Live Streaming ส่งข้อมูลจากผู้ไลฟ์ไปยังผู้ชมทางเดียว จึงเป็นแบบ Simplex (การพิมพ์คอมเมนต์เป็นช่องทางแยกต่างหาก)
B1-7-1-5|สัญญาณอนาล็อกเป็นคลื่นต่อเนื่องแบบ Sine Wave (ดูภาพประกอบ) ส่วนสัญญาณดิจิทัลเป็นคลื่นสี่เหลี่ยมแบบ 0/1
B1-7-1-6|สัญญาณดิจิทัลมีสองสถานะคือ 0 (ปิด) และ 1 (เปิด)
B1-7-1-7|ตามแนวของเล่ม OSI Model คือแบบจำลองมาตรฐานของ ISO ที่อธิบายรูปแบบการส่งข้อมูลระหว่างอุปกรณ์ในเครือข่าย แบ่งเป็น 7 ชั้น
B1-7-1-8|แต่ละชั้นใน OSI ทำงานร่วมกับชั้นที่อยู่ติดกันเท่านั้น คือรับบริการจากชั้นล่างและให้บริการชั้นบน
B1-7-1-9|เว็บเบราว์เซอร์เป็นแอปที่ผู้ใช้ใช้งานโดยตรง จึงอยู่ในชั้น Application (ชั้นที่ 7) ร่วมกับโปรโตคอล HTTP/HTTPS
B1-7-1-10|Application Layer เป็นประตูให้ผู้ใช้หรือโปรแกรมเข้าสู่บริการเครือข่าย
B1-7-1-11|Presentation Layer (ชั้นที่ 6) จัดรูปแบบข้อมูล เข้ารหัส/ถอดรหัส และบีบอัดข้อมูล
B1-7-1-12|Session Layer (ชั้นที่ 5) ควบคุมการเปิด-ปิดเซสชัน การซิงโครไนซ์ และจังหวะการสื่อสาร
B1-7-1-13|ตามแนวของเล่ม แอปเชื่อมต่อได้และแจ้งว่าทำรายการไม่ได้ แสดงว่าการสร้างเซสชันกับเซิร์ฟเวอร์ไม่สำเร็จ จึงทำงานถึง Session Layer
B1-7-1-14|Transport Layer (ชั้นที่ 4) ส่งข้อมูลแบบ Process-to-Process จากแอปต้นทางถึงแอปปลายทาง โดยใช้หมายเลข Port
B1-7-1-15|ฝั่งผู้ส่ง ข้อมูลไหลจากชั้นบนลงล่าง Transport (ชั้น 4) จึงรับข้อมูลจาก Session Layer (ชั้น 5)
B1-7-1-16|Segment ของชั้น Transport มี Header ที่ระบุหมายเลข Port ต้นทางและปลายทาง (IP อยู่ใน Packet และ MAC อยู่ใน Frame)
B1-7-1-17|Transport Layer แบ่งข้อมูลออกเป็น Segment
B1-7-1-18|UDP ไม่ต้องสร้างการเชื่อมต่อและไม่ตรวจสอบ/ส่งซ้ำ จึงเร็วกว่า TCP เหมาะกับงาน Real-time ที่ข้อมูลหายได้บ้าง
B1-7-1-19|สายใยแก้วนำแสง (Fiber Optic) ส่งข้อมูลได้ไกลที่สุด (หลายสิบกิโลเมตร) ส่วน Microwave เป็นสื่อไร้สาย
B1-7-1-20|MAC Address เป็นหมายเลขประจำการ์ดเครือข่ายที่ไม่ซ้ำกันทั่วโลก เปรียบเหมือนเลขประจำตัวประชาชน ส่วน IP Address เปรียบเหมือนที่อยู่บ้าน
B1-7-1-21|Network Layer นำ Segment มาใส่ Header ที่มี IP Address กลายเป็น Packet
B1-7-1-22|ตามแนวของเล่ม Packet Sniffer ดักจับข้อมูลที่วิ่งในเครือข่ายระดับ Frame จึงทำงานที่ Data Link Layer
B1-7-1-23|Best Effort Delivery คือ Network Layer พยายามส่งให้ดีที่สุดโดยพิจารณาหลายปัจจัยรวมกัน ทั้งความเร็ว ระยะทาง และความคับคั่งของทราฟฟิก (แต่ไม่รับประกันว่าจะถึง)
B1-7-1-24|Fiber Optic เป็นสื่อกลางในชั้น Physical ส่วน L3 Switch, Router และ Gateway ทำงานครอบคลุมชั้น Data Link ด้วย
B1-7-1-25|Data Link Layer นำ Packet มาใส่ Header/Trailer ที่มี MAC Address กลายเป็น Frame
B1-7-1-26|Ethernet ส่งข้อมูลเป็นสัญญาณดิจิทัล
B1-7-1-27|ARP (Address Resolution Protocol) ใช้หา MAC Address จาก IP Address ในเครือข่ายเดียวกัน
B1-7-1-28|Telnet ใช้ควบคุมเครื่องระยะไกล ส่วน SMTP (ส่ง), POP3 และ IMAP (รับ) เป็นโปรโตคอลอีเมล
B1-7-1-29|DNS แปลงชื่อโดเมนกับ IP Address ให้ตรงกัน คือผูกชื่อที่จำง่ายเข้ากับ IP เช่น 164.115.31.64

B1-7-1-31|Ethernet เป็นโปรโตคอลแบบมีสายในชั้น Link/Data Link ส่วน Wi-Fi เป็นแบบไร้สาย
B1-7-1-32|การดาวน์โหลดจากเว็บใช้ HTTP/HTTPS ซึ่งทำงานบน TCP/IP แต่ไม่ได้ใช้ UDP
B1-7-1-33|ดาวน์โหลดผ่าน HTTP ส่วนใหญ่ไม่ต้องใช้รหัสผ่าน ส่วน FTP ต้องล็อกอินด้วยชื่อผู้ใช้และรหัสผ่าน (ยกเว้นแบบ Anonymous)
