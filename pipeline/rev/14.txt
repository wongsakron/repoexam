B1-11-1-1|องค์ประกอบหลักของระบบสารสนเทศคือ Input → Process → Output ส่วน Feedback (ผลป้อนกลับ) เป็นส่วนเสริมสำหรับปรับปรุงระบบ จึงไม่ใช่องค์ประกอบหลัก (ตามแนวของเล่ม)
B1-11-1-2|ระบบสารสนเทศประมวลผลด้วยคนหรือด้วยคอมพิวเตอร์ก็ได้ ไม่จำเป็นต้องใช้คอมพิวเตอร์เสมอ
B1-11-1-3|ระดับของระบบสารสนเทศจากล่างขึ้นบน: Operational → Knowledge → Management → Strategic (สูงสุด เป็นระดับผู้บริหารระดับสูง)
B1-11-1-4|TPS (Transaction Processing System) บันทึกและประมวลผลธุรกรรมประจำวัน เช่น การขาย และการฝาก-ถอนเงิน
B1-11-1-5|OAS (Office Automation System) สนับสนุนงานธุรการในสำนักงาน เช่น เอกสาร อีเมล และนัดหมาย
B1-11-1-6|KWS (Knowledge Work System) สนับสนุนผู้ทำงานความรู้ เช่น วิศวกรและนักออกแบบ ให้สร้างผลิตภัณฑ์หรือองค์ความรู้ใหม่
B1-11-1-7|MIS = Management Information System
B1-11-1-8|MIS สรุปข้อมูลเป็นรายงานเพื่อการวางแผนและบริหารจัดการของผู้บริหารระดับกลาง
B1-11-1-9|DSS (Decision Support System) ช่วยสนับสนุนการตัดสินใจโดยวิเคราะห์ทางเลือกต่างๆ
B1-11-1-10|ระบบเปิดปิดไฟอัตโนมัติเป็นระบบควบคุมอัตโนมัติ ไม่ได้ช่วยผู้บริหารตัดสินใจ ส่วนการคาดการณ์จราจร การปลูกพืช และพยากรณ์อากาศเป็นการวิเคราะห์เพื่อช่วยตัดสินใจ
B1-11-1-11|EIS (Executive Information System) คือระบบสารสนเทศสำหรับผู้บริหารระดับสูงเพื่อวางแผนเชิงกลยุทธ์ (หมายเหตุ: ชื่อที่ถูกต้องคือ Executive ไม่ใช่ Exclusive)
B1-11-1-12|EIS ออกแบบให้ใช้งานง่ายที่สุด แสดงเป็นกราฟหรือแดชบอร์ด ผู้บริหารไม่ต้องมีความรู้คอมพิวเตอร์ระดับสูงก็ใช้ได้
B1-11-1-13|ระบบผู้เชี่ยวชาญ (ES) ใช้ฐานความรู้และกลไกอนุมานแบบ AI ตัดสินใจแทนผู้เชี่ยวชาญ ไม่ได้ต้องให้มนุษย์คอยควบคุมการตัดสินใจ (ตามแนวของเล่ม)
B1-11-1-14|ES อาศัยฐานความรู้ที่ผู้เชี่ยวชาญป้อนไว้ จึงอัปเดตความรู้แบบเรียลไทม์ได้ยาก
B1-11-1-15|จุดเด่นของ ES คือมีฐานความรู้ (Knowledge Base) และกฎเกณฑ์ (Rules) สำหรับใช้อนุมานและตัดสินใจ
B1-11-1-16|DSS ช่วยผู้บริหารด้วยการเสนอทางเลือก จำลองสถานการณ์ (What-if) และประเมินผลของแต่ละทางเลือก
X1-11-2-1|GIS = Geographic Information System รวบรวม จัดเก็บ วิเคราะห์ และแสดงผลข้อมูลเชิงพื้นที่ (แผนที่)
X1-11-2-2|GIS เชื่อมข้อมูลเชิงพื้นที่ (ตำแหน่งพิกัด) กับข้อมูลเชิงบรรยาย (Attribute) ที่อธิบายสิ่งนั้น
X1-11-2-3|องค์ประกอบของ GIS คือ ฮาร์ดแวร์ ซอฟต์แวร์ ข้อมูล บุคลากร และวิธีการ ไม่มี AI เป็นองค์ประกอบ
X1-11-2-4|GIS เพิ่มมิติ "ที่ไหน (Where)" ให้ระบบสารสนเทศเพื่อการบริหาร
X1-11-2-5|Overlay Analysis คือการซ้อนชั้นข้อมูลแผนที่หลายชั้นเพื่อวิเคราะห์ เป็นเทคนิคของ GIS
X1-11-2-6|การหาทำเลสร้างโรงพยาบาลต้องวิเคราะห์ข้อมูลเชิงพื้นที่ จึงเป็นงานของ GIS (กรมที่ดินก็ใช้ GIS กับงานแผนที่และรูปแปลงที่ดิน)
X1-11-2-7|GIS แปลงข้อมูลที่กระจัดกระจายให้เป็นแผนที่เชิงวิเคราะห์
X1-11-2-8|การประมวลผลด้วยมือเหมาะกับข้อมูลน้อยและไม่เร่งด่วน
X1-11-2-9|Batch Processing รวบรวมข้อมูลไว้ก่อน แล้วประมวลผลพร้อมกันตามรอบเวลาที่กำหนด
X1-11-2-10|การปันผลหุ้นทุก 3 เดือนคำนวณเป็นรอบ จึงเป็น Batch ส่วน ATM, Google และ GPS ต้องตอบสนองทันที
X1-11-2-11|Interactive (Online/Real-time) Processing ประมวลผลและให้ผลทันทีที่ได้รับข้อมูล
X1-11-2-12|การสมัครบัตรเครดิตผ่านแอปโต้ตอบกับผู้ใช้ทันที ส่วนการคิดค่าน้ำ ค่าไฟ และดอกเบี้ยตามรอบเป็น Batch
X1-11-2-13|EDP (Electronic Data Processing) คือการประมวลผลข้อมูลด้วยคอมพิวเตอร์
X1-11-2-14|ตามแนวของเล่ม Batch ประมวลผลงานจำนวนมากรวดเดียวโดยไม่ต้องรอผู้ใช้โต้ตอบทีละรายการ จึงลดเวลาโดยรวม แต่ไม่ได้ผลทันที
X1-11-2-15|CIA Triad = Confidentiality (ความลับ), Integrity (ความถูกต้องครบถ้วน) และ Availability (ความพร้อมใช้)
X1-11-2-16|Confidentiality คือให้เข้าถึงข้อมูลได้เฉพาะผู้มีสิทธิ์
X1-11-2-17|ลายมือชื่อดิจิทัลยืนยันว่าข้อมูลไม่ถูกแก้ไขระหว่างทาง (Integrity) และยืนยันตัวผู้ส่ง (Non-repudiation)
X1-11-2-18|DDoS ทำให้ระบบใช้งานไม่ได้ การป้องกัน DDoS จึงรักษา Availability
X1-11-2-19|ทั้งสามคำมีขอบเขตต่างกัน: Information Security กว้างสุด (ข้อมูลทุกรูปแบบ) → IT Security (ระบบไอที) → Cybersecurity (ภัยบนไซเบอร์)
X1-11-2-20|IT Security เน้นปกป้องข้อมูลดิจิทัลและระบบไอที
X1-11-2-21|Information Security ปกป้องข้อมูลทุกรูปแบบ ทั้งกระดาษและดิจิทัล
X1-11-2-22|Firewall และ Anti-malware เป็นมาตรการทางเทคนิคของ IT Security ส่วนการล็อกประตูเป็น Physical และการอบรมเป็น Administrative
X1-11-2-23|Cybersecurity รับมือภัยทางไซเบอร์ เช่น การแฮก และมัลแวร์ ส่วนไฟไหม้และน้ำท่วมเป็นภัยทางกายภาพ
X1-11-2-24|Ransomware เข้ารหัสไฟล์แล้วเรียกค่าไถ่
X1-11-2-25|Worm แพร่ผ่านเครือข่ายได้เอง ส่วน Virus ต้องอาศัยการเปิดไฟล์ที่ติดเชื้อ
X1-11-2-26|Phishing คือการหลอกขโมยข้อมูลด้วยเว็บหรืออีเมลปลอมที่ดูน่าเชื่อถือ
X1-11-2-27|Zero-day คือการโจมตีช่องโหว่ที่ผู้พัฒนายังไม่รู้ จึงยังไม่มีแพตช์ป้องกัน
X1-11-2-28|Insider Threat คือภัยจากคนในองค์กร เช่น พนักงานหรืออดีตพนักงาน
X1-11-2-29|Vulnerability คือช่องโหว่หรือจุดอ่อนที่อาจถูกใช้โจมตี
X1-11-2-30|Risk = Threat × Vulnerability × Asset Value ถ้าปัจจัยใดเป็นศูนย์ ความเสี่ยงก็ลดลงเป็นศูนย์
X1-11-2-31|มีทั้งภัยคุกคาม (แฮกเกอร์) ช่องโหว่ (รหัสผ่านเริ่มต้น) และทรัพย์สินมีค่า (ข้อมูลส่วนบุคคล) ความเสี่ยงจึงสูงมาก
X1-11-2-32|การอบรมพนักงานลดจุดอ่อนด้านคน คือลด Vulnerability ส่วนภัยคุกคามจากภายนอกยังมีอยู่เท่าเดิม
X1-11-2-33|MFA เป็นมาตรการเพิ่มความปลอดภัย ไม่ใช่สาเหตุของช่องโหว่
X1-11-2-34|การทำประกันภัยไซเบอร์คือการโอนความเสี่ยง (Risk Transfer) ไปให้บริษัทประกัน
X1-11-2-35|Firewall และการอบรมช่วยลดความเสี่ยง (Risk Mitigation)
X1-11-2-36|การยกเลิกบริการที่เสี่ยงเกินไปคือการหลีกเลี่ยงความเสี่ยง (Risk Avoidance)
X1-11-2-37|Administrative Controls คือมาตรการเชิงบริหาร เช่น นโยบาย ระเบียบ และการอบรม
X1-11-2-38|Technical Controls คือมาตรการทางเทคนิค เช่น Firewall, Antivirus และการเข้ารหัส
X1-11-2-39|Physical Controls คือมาตรการทางกายภาพ เช่น CCTV และการควบคุมการเข้าออก
X1-11-2-40|การเข้ารหัส SSL เป็นมาตรการทางเทคนิค ไม่ใช่ความปลอดภัยทางกายภาพ
X1-11-2-41|Defense in Depth คือการป้องกันหลายชั้นซ้อนกัน ถ้าชั้นหนึ่งถูกเจาะยังมีชั้นอื่นป้องกันอยู่
X1-11-2-42|MFA ใช้ปัจจัยยืนยันตัวตนมากกว่า 1 ประเภท
X1-11-2-43|Something you are คือสิ่งที่เป็นตัวเรา เช่น ลายนิ้วมือ ใบหน้า และม่านตา (Biometric)
X1-11-2-44|Something you know คือสิ่งที่รู้ เช่น รหัสผ่าน และ PIN
X1-11-2-45|OTP ส่งมาที่โทรศัพท์หรือ Token ที่เรามีอยู่ จึงเป็น Something you have
X1-11-2-46|Biometric ปลอมแปลงได้ยาก แต่ถ้าข้อมูลรั่วจะเปลี่ยนไม่ได้
X1-11-2-47|Least Privilege คือให้สิทธิ์เฉพาะเท่าที่จำเป็นต่อการปฏิบัติงาน
X1-11-2-48|chmod: r = 4, w = 2, x = 1 ดังนั้น 755 = เจ้าของ rwx (7), กลุ่ม r-x (5), คนอื่น r-x (5)
X1-11-2-49|644 = เจ้าของ rw- (6), กลุ่ม r-- (4), คนอื่น r-- (4)
X1-11-2-50|777 = rwx ทุกกลุ่ม คือทุกคนอ่าน เขียน และรันได้ (ไม่ปลอดภัย)
X1-11-2-51|5 = 4 + 1 = อ่าน (r) + ประมวลผล (x) ไม่มีเขียน
X1-11-2-52|6 = 4 + 2 = อ่าน (r) + เขียน (w) ไม่มีประมวลผล
X1-11-2-53|NTFS Modify อ่าน เขียน และลบได้ แต่เปลี่ยนสิทธิ์ (Permission) หรือเปลี่ยนเจ้าของไม่ได้ ซึ่งต้องใช้ Full Control
X1-11-2-54|การเข้ารหัสทำให้ผู้ไม่มีสิทธิ์อ่านไม่ออก จึงรักษา Confidentiality
X1-11-2-55|Plaintext คือข้อความที่อ่านได้ ส่วน Ciphertext คือข้อความที่ถูกเข้ารหัสแล้ว
X1-11-2-56|IDS ตรวจจับและแจ้งเตือน ส่วน IPS ตรวจจับและบล็อกได้ทันที
X1-11-2-57|VPN สร้างอุโมงค์เข้ารหัสเป็นเครือข่ายส่วนตัวเสมือนบนเครือข่ายสาธารณะ
X1-11-2-58|ข้อมูลลับที่สุดต้องเข้ารหัส จำกัดสิทธิ์เข้มงวดที่สุด และแยกเก็บในระบบเฉพาะ
X1-11-2-59|3-2-1 คือสำรองข้อมูล 3 ชุด บนสื่อ 2 ประเภท และเก็บนอกสถานที่ 1 ชุด
X1-11-2-60|DRP คือแผนกู้คืนระบบหลังเกิดภัยพิบัติ ให้กลับมาดำเนินงานได้อย่างต่อเนื่อง
