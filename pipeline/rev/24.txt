B2-6-1-1|วิทยาการข้อมูล (Data Science) ครอบคลุมทั้งกระบวนการ ตั้งแต่เก็บ จัดการ วิเคราะห์ ไปจนถึงนำข้อมูลไปช่วยตัดสินใจ
B2-6-1-2|วิทยาการข้อมูล = Data Science
B2-6-1-3|BI (Business Intelligence) คือการนำข้อมูลและการวิเคราะห์มาใช้สนับสนุนการตัดสินใจทางธุรกิจ
B2-6-1-4|Database เป็นแหล่งข้อมูลส่วนหนึ่งของ Big Data ข้อที่บอกว่าไม่ใช่จึงผิด
B2-6-1-5|5V ของ Big Data: Volume (ปริมาณ), Velocity (ความเร็ว), Variety (ความหลากหลาย), Veracity (ความถูกต้อง) และ Value (คุณค่า)
B2-6-1-6|Data Analysis คือกระบวนการวิเคราะห์ ไม่ใช่แหล่งเก็บข้อมูล ส่วน Database, Data Lake และ Data Warehouse เป็นแหล่งเก็บข้อมูล
B2-6-1-7|Data Lake เก็บข้อมูลดิบทุกรูปแบบจำนวนมหาศาล จึงใหญ่ที่สุด
B2-6-1-8|Data Lake เก็บได้ทั้งข้อมูลที่มีโครงสร้าง กึ่งโครงสร้าง และไม่มีโครงสร้าง
B2-6-1-9|Oracle Database ได้รับความนิยมอันดับ 1 ในการจัดอันดับ (DB-Engines) ปี 2024
B2-6-1-10|ข้อมูลไม่มีโครงสร้าง เช่น ภาพ วิดีโอ และเสียง เก็บใน Data Lake
B2-6-1-11|ข้อมูลตัวเลขและตัวอักษรเป็นข้อมูลมีโครงสร้าง เก็บได้ทุกแหล่ง
B2-6-1-12|Data Science ใช้ข้อมูลจาก Big Data มาวิเคราะห์ ไม่ได้เป็นแหล่งข้อมูลให้ Big Data ข้อ ก จึงผิด
B2-6-1-13|Data Mining คือการใช้คอมพิวเตอร์วิเคราะห์ข้อมูลขนาดใหญ่เพื่อค้นหารูปแบบหรือความสัมพันธ์ที่ซ่อนอยู่ ส่วนข้อ ค คือ Data Cleansing
B2-6-1-14|การหาสินค้าที่มักขายคู่กัน (Market Basket Analysis) ใช้ข้อมูลจาก Big Data/Data Warehouse มาทำ Data Mining จึงเกี่ยวข้องทุกข้อ
B2-6-1-15|Database ใช้ประมวลผลรายการประจำวัน (OLTP)
B2-6-1-16|Data Warehouse รวบรวมข้อมูลมีโครงสร้างจากหลายแหล่ง เพื่อเตรียมไว้วิเคราะห์ (OLAP)
B2-6-1-17|Data Visualization คือการนำเสนอข้อมูลเป็นภาพ เช่น กราฟ แผนภูมิ และแดชบอร์ด
B2-6-1-18|ตามแนวของเล่ม Infographic เป็นสื่อกราฟิกที่เล่าเรื่องด้วยภาพและข้อความ แยกจาก Data Visualization ที่แสดงข้อมูลโดยตรงอย่างกราฟ แผนภูมิ และตาราง
B2-6-1-19|Dashboard แสดงข้อมูลสรุปหลายตัวชี้วัดแบบเรียลไทม์ผ่านซอฟต์แวร์
B2-6-1-20|Canva เป็นเครื่องมือออกแบบกราฟิกทั่วไป ส่วน Power BI, Tableau และ Google Data Studio (Looker Studio) สร้าง Data Visualization โดยเฉพาะ
