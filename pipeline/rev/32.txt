M2-2|1-1|ยุคที่ 2 เปลี่ยนจากหลอดสุญญากาศเป็นทรานซิสเตอร์ ทำให้เล็กลง ร้อนน้อยลง และเชื่อถือได้มากขึ้น
M2-3|1-1|งานพยากรณ์อากาศและจำลองนิวเคลียร์ต้องคำนวณมหาศาล จึงใช้ซูเปอร์คอมพิวเตอร์
M2-4|1-1|Embedded Computer ฝังอยู่ในอุปกรณ์หรือเครื่องจักรเพื่อควบคุมงานเฉพาะอย่าง
M2-5|1-1|เรียงจากเล็กไปใหญ่: Bit < Byte < KB < MB < GB < TB (โจทย์ใช้เครื่องหมาย > แทนลำดับ)
M2-6|1-1|1 TB = 1,024 GB ดังนั้น 2 TB = 2,048 GB
M2-7|1-5|RAM เป็นหน่วยความจำแบบลบเลือน (Volatile) ข้อมูลหายเมื่อไม่มีไฟ ส่วน ROM เก็บถาวร
M2-8|1-5|Mouse, Scanner, Microphone และ Touch screen เป็นอุปกรณ์รับเข้าทั้งหมด ข้ออื่นปนอุปกรณ์แสดงผล เช่น Plotter, Printer, Monitor และ Projector
M2-9|1-4|ระบบปฏิบัติการเป็นตัวกลางระหว่างผู้ใช้กับฮาร์ดแวร์
M2-10|1-4|Malware คือโปรแกรมที่สร้างขึ้นเพื่อขัดขวางหรือทำลายระบบและข้อมูล
M2-11|2-8|นักวิเคราะห์ระบบ (System Analyst) วิเคราะห์ความต้องการและออกแบบระบบสารสนเทศทั้งหมด
M2-12|1-4|Compiler แปลทั้งโปรแกรมก่อน ได้ไฟล์ที่พร้อมรัน ส่วน Interpreter แปลและรันทีละบรรทัด
M2-13|1-5|Plotter ใช้พิมพ์แบบแปลนทางวิศวกรรมและสถาปัตยกรรมขนาดใหญ่
M2-14|1-5|Register เป็นหน่วยความจำเร็วที่สุดภายใน CPU ใช้พักข้อมูลขณะประมวลผล
M2-15|1-4|ถ้า OS เสีย ฮาร์ดแวร์ยังทำงานได้ (เปิดเครื่องและเข้า BIOS ได้) แต่จะรันโปรแกรมประยุกต์ไม่ได้ และข้อมูลบนดิสก์ไม่ได้ถูกลบ
M2-16|1-2|Raster เก็บเป็นพิกเซล ส่วน Vector เก็บเป็นสมการคณิตศาสตร์
M2-17|1-2|JPEG บีบอัดแบบ Lossy เหมาะกับภาพถ่ายบนเว็บ
M2-18|1-2|PNG รองรับพื้นโปร่งใสและสี 24 บิต (16.7 ล้านสี) ส่วน GIF มีแค่ 256 สี
M2-19|1-2|TIFF เก็บรายละเอียดภาพครบถ้วนโดยไม่สูญเสีย เหมาะกับงานพิมพ์คุณภาพสูง
M2-20|1-2|.PSD เป็นไฟล์งาน Photoshop ที่เก็บ Layer ไว้แก้ไขภายหลังได้
M2-21|1-2|Lossy ตัดรายละเอียดเสียงที่หูมนุษย์แทบไม่ได้ยินออก เพื่อลดขนาดไฟล์
M2-22|1-2|FLAC เป็นแบบ Lossless รองรับเสียง High-Resolution จึงเป็นที่นิยมของกลุ่ม Audiophile
M2-23|1-2|WAV ไม่บีบอัด ไฟล์ใหญ่และคุณภาพเท่าต้นฉบับ ส่วน MP3 บีบอัดแบบ Lossy
M2-24|1-2|H.265 ใช้พื้นที่ประมาณครึ่งหนึ่งของ H.264 ที่ความชัดเท่ากัน (แต่ต้องใช้พลังประมวลผลมากกว่า)
M2-25|1-2|MP4 (H.264) เป็นมาตรฐานสากล เปิดได้แทบทุกอุปกรณ์และระบบ
M2-26|1-3|จำนวนพิกเซลยิ่งมาก ความละเอียดของภาพยิ่งสูง
M2-27|1-2|SVG = Scalable Vector Graphics
M2-28|1-2|.MP3 เป็นไฟล์เสียง ส่วน BMP, WebP และ RAW เป็นไฟล์ภาพ
M2-29|1-3|RGB ที่ (255,255,255) คือแสงทุกสีเต็มที่ จึงได้สีขาว
M2-30|1-3|CMYK = Cyan (ฟ้า), Magenta (ม่วงแดง/บานเย็น), Yellow (เหลือง) และ Key (ดำ)
M2-31|1-3|งานพิมพ์ใช้การผสมหมึก ซึ่งเป็นระบบสีแบบลบ จึงต้องใช้ CMYK
M2-32|1-3|หมึกดูดซับแสงไว้บางส่วน ยิ่งผสมยิ่งดูดซับมาก สีจึงยิ่งมืดลง (Subtractive)
M2-33|1-3|Saturation คือความสด ลดค่าแล้วภาพจะซีด เพิ่มค่าแล้วภาพจะสดขึ้น
M2-34|1-3|LAB เป็นมาตรฐานกลางในการวัดสีที่ไม่ขึ้นกับอุปกรณ์
M2-35|1-3|L = Lightness (ความสว่าง), a = แกนเขียว-แดง และ b = แกนน้ำเงิน-เหลือง
M2-36|1-3|Grayscale ไล่ระดับความเข้มจากขาวถึงดำ 256 ระดับ (8 บิต)
M2-37|1-3|ตามแนวของเล่ม งานลายเส้นสีเดียวใช้โหมด Grayscale (โหมดขาวดำล้วนแบบ 1 บิตไม่มีในตัวเลือก) ไม่ต้องใช้ระบบสีเต็มรูปแบบ
M2-38|1-3|ภาพ 3 มิติเพิ่มแกนความลึก (Z) ทำให้ดูมีปริมาตร
M2-39|1-3|หมึก CMY ผสมกันจริงได้สีน้ำตาลเข้ม ไม่ดำสนิท จึงต้องเพิ่มหมึกดำ (K) ซึ่งช่วยประหยัดหมึกสีด้วย แต่เหตุผลหลักตามเฉลยคือข้อ ก
M2-40|1-3|กล้องดิจิทัลและมือถือบันทึกภาพในระบบสี RGB
M2-41|1-3|UI แสดงผลบนจอ จึงใช้ระบบสี RGB
M2-42|1-3|ค่า a ใน LAB คือแกนเขียว (−) ถึงแดง (+)
M2-43|1-3|อินโฟกราฟิกเน้นภาพลายเส้น ไอคอน และสัญลักษณ์ที่สื่อความเข้าใจง่าย
M2-44|1-5|Hard Copy คือชิ้นงานที่พิมพ์ออกมาจับต้องได้ ส่วน Soft Copy คือข้อมูลบนจอหรือไฟล์
M2-45|1-4|UX (User Experience) เน้นความรู้สึกและความพึงพอใจของผู้ใช้เมื่อใช้งานระบบ
M2-46|1-4|ตามแนวของเล่ม ปุ่มเล็กจนกดยากเป็นปัญหาด้านประสบการณ์การใช้งาน (UX) ที่ทำให้ใช้งานลำบาก
M2-47|1-4|OS เป็นตัวกลางระหว่างผู้ใช้กับฮาร์ดแวร์ ระหว่างโปรแกรมกับฮาร์ดแวร์ และจัดสรรทรัพยากร จึงถูกทุกข้อ
M2-48|1-4|Utility ช่วยบำรุงรักษาและเพิ่มประสิทธิภาพระบบ
M2-49|1-4|ภาษาระดับต่ำใกล้เคียงภาษาเครื่อง ทำงานเร็ว แต่เขียนยากและขึ้นกับสถาปัตยกรรมของ CPU
M2-50|1-4|Virtualization จำลองทรัพยากรฮาร์ดแวร์ ให้เครื่องเดียวรันได้หลายระบบปฏิบัติการ
M2-51|1-4|Type 1 ติดตั้งบนฮาร์ดแวร์โดยตรง ไม่ต้องผ่าน OS หลัก จึงเร็วกว่าและนิยมใช้ใน Data Center
M2-52|1-4|Network Virtualization (เช่น VLAN) ใช้ซอฟต์แวร์แบ่งเครือข่ายย่อยได้บนอุปกรณ์ชุดเดียว
M2-53|1-4|Assembler แปลภาษา Assembly เป็นภาษาเครื่อง
M2-54|1-4|C++ เป็นภาษาคอมไพล์ ต้องใช้ Compiler
M2-55|1-4|SaaS (Software as a Service) คือซอฟต์แวร์ที่ใช้ผ่านอินเทอร์เน็ตโดยไม่ต้องติดตั้ง เช่น Google Docs
M2-56|1-4|Shareware ให้ทดลองใช้ก่อน อาจจำกัดฟังก์ชันหรือหมดอายุถ้าไม่จ่ายเงิน
M2-57|1-5|หน่วยรับข้อมูลรับข้อมูลจากภายนอกเหมือนประสาทสัมผัส ส่วน CPU เปรียบเหมือนสมอง
M2-58|1-5|Control Unit ดึงคำสั่ง ตีความ และประสานงานไปยังหน่วยต่างๆ
M2-59|1-5|Laser/BlueTrack Mouse ใช้งานบนพื้นผิวเงาหรือกระจกได้ดีกว่า Optical (แสงแดง)
M2-60|1-5|Refresh Rate ยิ่งสูง ภาพเคลื่อนไหวยิ่งราบรื่น (ความคมชัดขึ้นอยู่กับความละเอียด ไม่ใช่ Hz)
