B1-5-1-1|ฮาร์ดแวร์คือส่วนประกอบที่จับต้องได้ ทั้งอุปกรณ์ภายในเครื่องและอุปกรณ์ต่อพ่วงทุกชนิด ข้อ ข คือซอฟต์แวร์ และข้อ ค คือกระบวนการทำงาน (Procedure)
B1-5-1-2|ฮาร์ดแวร์แบ่งเป็นหน่วยรับเข้า หน่วยประมวลผลกลาง หน่วยความจำ และหน่วยส่งออก ไม่มี "หน่วยตรวจสอบข้อผิดพลาด"
B1-5-1-3|ฮาร์ดแวร์ทำงานเองไม่ได้ ต้องมีซอฟต์แวร์ (OS/โปรแกรม) สั่งงาน และศูนย์กลางการควบคุมคือ CPU ไม่ใช่ GPU
B1-5-1-4|3D Printer เป็นอุปกรณ์ส่งออก (Output) ที่พิมพ์ชิ้นงานสามมิติ ส่วนเมาส์ Touchpad และ Smart Speaker (รับคำสั่งเสียง) เป็นอุปกรณ์รับเข้า
B1-5-1-5|QR Code Reader อ่านข้อมูลจากภาพรหัส จึงจัดเป็นอุปกรณ์รับภาพ (กลุ่มเดียวกับสแกนเนอร์และกล้อง)
B1-5-1-6|Eye Tracker ติดตามการเคลื่อนไหวของดวงตาเพื่อใช้ควบคุม ไม่ได้ใช้ระบุตัวบุคคล ส่วนลายนิ้วมือ เสียง และใบหน้าเป็น Biometric (ตามแนวของเล่ม)
B1-5-1-7|DPI = Dots Per Inch คือจำนวนจุดต่อนิ้ว
B1-5-1-8|DPI ของเมาส์บอกความไว คือเลื่อนเมาส์ 1 นิ้วแล้วตัวชี้บนจอเคลื่อนไปกี่จุด (Printer ก็ใช้ DPI แต่ Printer เป็นอุปกรณ์ส่งออก)
B1-5-1-9|วงจรการทำงานของ CPU คือ Fetch → Decode → Execute → Store ส่วน Compile เป็นงานของตัวแปลภาษา
B1-5-1-10|CPU 4 Core คือมีหน่วยประมวลผลจริง 4 แกน ทำงานขนานได้มากที่สุด ส่วน Thread เป็นการแบ่งงานเสมือน และ Cache เป็นแค่ส่วนช่วย
B1-5-1-11|RISC (Reduced Instruction Set Computer) ใช้ชุดคำสั่งง่าย ออกแบบให้ทำ 1 คำสั่งต่อ 1 รอบสัญญาณนาฬิกา
B1-5-1-12|ตามแนวของเล่ม Intel Pentium เป็นตัวอย่างคลาสสิกของ CISC (Complex Instruction Set) ซึ่ง CPU x86 ของ Intel/AMD ใช้สถาปัตยกรรมนี้
B1-5-1-13|ชิปตระกูล ARM (เช่น Snapdragon และ Apple M-series) ใช้สถาปัตยกรรม RISC ส่วน Celeron, Athlon และ Pentium เป็น x86 (CISC)
B1-5-1-14|CPU อุปกรณ์พกพาเน้นชุดคำสั่งแบบง่าย (RISC) ประหยัดพลังงาน และราคาถูก ชุดคำสั่งซับซ้อน (CISC) เป็นลักษณะของ CPU เดสก์ท็อป
B1-5-1-15|Ryzen 9 เป็น CPU สำหรับคอมพิวเตอร์ ส่วน MediaTek และ Snapdragon ใช้ในมือถือ และ Apple M3 ใช้ใน Mac/iPad (สถาปัตยกรรม ARM เดียวกับมือถือ)
B1-5-1-16|Store คือการเก็บผลลัพธ์ลงหน่วยความจำ
B1-5-1-17|Fetch คือการดึงคำสั่งหรือข้อมูลจากหน่วยความจำมาที่ CPU
B1-5-1-18|CU (Control Unit) ถอดรหัสคำสั่ง (Decode) และควบคุมการทำงานของส่วนต่างๆ
B1-5-1-19|ALU (Arithmetic Logic Unit) ประมวลผลการคำนวณและตรรกะ (Execute)
B1-5-1-20|Register, L1 และ L2 อยู่ในแต่ละคอร์ ส่วน Cache L3 เป็นหน่วยความจำที่ทุกคอร์ใช้ร่วมกัน (Shared)
B1-5-1-21|SSD เป็นหน่วยเก็บข้อมูลถาวร (Non-volatile/หน่วยความจำสำรอง) ส่วน Register, Cache และ RAM เป็นหน่วยความจำแบบลบเลือนที่ทำงานกับ CPU โดยตรง
B1-5-1-22|ความเร็วเรียงจากมากไปน้อย: Register > Cache > RAM > SSD
B1-5-1-23|Cache L1 อยู่ใกล้คอร์ที่สุด จึงเร็วที่สุด (แต่เล็กที่สุด)
B1-5-1-24|Cache เป็นหน่วยความจำความเร็วสูงที่พักข้อมูลที่ CPU ใช้บ่อย ทั้งก่อน ระหว่าง และหลังประมวลผล เพื่อลดเวลารอ RAM
B1-5-1-25|APU ของ AMD รวม CPU และ GPU ไว้ในชิปเดียว จึงประมวลผลได้ทั้งงานทั่วไปและงานภาพ
B1-5-1-26|Mbps เป็นหน่วยอัตราการส่งข้อมูล ไม่ใช่หน่วยวัดประสิทธิภาพ CPU (CPU วัดด้วยจำนวนคอร์ เธรด และความเร็วสัญญาณนาฬิกา)
B1-5-1-27|ตามแนวของเล่ม ค่า Hz ของ CPU บอกว่าใน 1 วินาทีทำงาน (Decode/Execute คำสั่ง) ได้กี่รอบ เช่น 3 GHz ≈ 3 พันล้านรอบต่อวินาที
B1-5-1-28|Pipeline คือการซ้อนขั้นตอน รับคำสั่งถัดไปมาทำขณะที่คำสั่งก่อนหน้ายังไม่เสร็จ เหมือนสายพานการผลิต
B1-5-1-29|Ryzen 9 เป็น CPU ระดับสูง มีคอร์มากและความเร็วสูง เหมาะกับเกมและงานหนัก ส่วน Pentium และ Athlon เป็นรุ่นประหยัด
B1-5-1-30|x86 (32 บิต) อ้างอิงหน่วยความจำได้ 2^32 = 4 GB จึงใช้แรมได้สูงสุด 4 GB
B1-5-1-31|x64 คือ CPU 64 บิต ประมวลผลข้อมูลได้ครั้งละ 64 บิตต่อรอบ
B1-5-1-32|BUS คือเส้นทางรับส่งข้อมูลระหว่างอุปกรณ์ เปรียบเหมือนถนน ส่วนข้อมูลเปรียบเหมือนผู้โดยสาร
B1-5-1-33|ROM เก็บโปรแกรมเริ่มต้นระบบ (เช่น BIOS) และแทบไม่มีผลต่อความเร็วขณะทำงาน ต่างจาก BUS, CPU และ Cache
B1-5-1-34|หน่วยความจำหลัก (RAM) รับส่งข้อมูลและชุดคำสั่งกับ CPU ขณะประมวลผล
B1-5-1-35|หน่วยความจำแบบลบเลือนต้องมีไฟเลี้ยง ข้อมูลจะหายเมื่อปิดเครื่อง จึงเก็บข้อมูลถาวรไม่ได้
B1-5-1-36|RAM DDR5 และ Cache L2 เป็นแบบลบเลือนทั้งคู่ ข้ออื่นมี ROM, DVD, SSD หรือ Flash ซึ่งไม่ลบเลือนปนอยู่
B1-5-1-37|DRAM เก็บข้อมูลด้วยตัวเก็บประจุซึ่งรั่วได้ จึงต้อง Refresh ตลอดเวลา ส่วน SRAM (ใช้ทำ Cache) ไม่ต้อง Refresh
B1-5-1-38|Flash Memory เป็นแบบไม่ลบเลือน จึงเก็บข้อมูลถาวรแม้ไม่มีไฟเลี้ยง
B1-5-1-39|ROM = Read Only Memory
B1-5-1-40|FEPROM (Flash EEPROM) คือ ROM ที่ลบ/เขียนด้วยไฟฟ้าได้ทีละบล็อก ซึ่งก็คือ Flash Memory
B1-5-1-41|Flash Memory รวมข้อดีของ ROM (เก็บถาวร) และ RAM (เขียนได้เร็ว) ไว้ด้วยกัน จึงใช้เก็บข้อมูลแทนฮาร์ดดิสก์ได้
B1-5-1-42|SSD และ Flash Drive ใช้ชิป Flash ทั้งคู่ ส่วน Floppy, CD-ROM และ Hard Disk ไม่ใช่ Flash
B1-5-1-43|ตามแนวของเล่ม BIOS เป็นโปรแกรมที่บรรจุใน ROM บนเมนบอร์ด (ปัจจุบันใช้ Flash ROM เพื่อให้อัปเดตได้)
B1-5-1-44|BIOS ตรวจสอบและเตรียมฮาร์ดแวร์ (POST) แล้วส่งต่อการทำงานให้ระบบปฏิบัติการ (Boot)
B1-5-1-45|UEFI รองรับดิสก์แบบ GPT ซึ่งมี Partition ใหญ่กว่า 2 TB ได้ บูตเร็วกว่า และมีหน้าจอกราฟิก/เมาส์ ต่างจาก BIOS เดิมที่จำกัดด้วย MBR
B1-5-1-46|RAM = Random Access Memory หน่วยความจำที่เข้าถึงตำแหน่งใดก็ได้โดยตรง
B1-5-1-47|RAM เป็นหน่วยความจำหลักที่พักข้อมูลและคำสั่งเพื่อรับส่งกับ CPU ขณะทำงาน (ข้อมูลหายเมื่อปิดเครื่อง)
B1-5-1-48|ความจุของแรมวัดเป็น GB เช่น 8 GB และ 16 GB
B1-5-1-49|ความเร็วรับส่งข้อมูลของแรมวัดเป็น MT/s (Mega Transfers per second) เช่น DDR5-4800
B1-5-1-50|ตามแนวของเล่ม ขนาด BUS (ความถี่) ของแรมวัดเป็น MHz เช่น BUS 1600 MHz
B1-5-1-51|DDR5 เป็นรุ่นใหม่ล่าสุด จึงเร็วที่สุด (SDRAM → DDR2 → DDR3 → DDR4 → DDR5)
B1-5-1-52|การรับส่งระหว่าง RAM กับ CPU ใช้ FSB, Northbridge และ Memory BUS ส่วน Southbridge ดูแลอุปกรณ์ I/O ที่ช้ากว่า เช่น USB และ SATA
B1-5-1-53|แรมต่างบัสกันใช้ร่วมกันได้ โดยทุกตัวจะลดไปทำงานที่บัสต่ำสุด (1600) และความจุรวมเป็น 6 GB ข้อ ง จึงผิด เพราะแรมทั้งสองตัวทำงานร่วมกัน
B1-5-1-54|SO-DIMM (Small Outline DIMM) เป็นแรมขนาดเล็กสำหรับโน้ตบุ๊ก ส่วน DIMM ใช้กับ PC
B1-5-1-55|หน่วยความจำสำรอง เช่น HDD และ SSD เป็นแบบไม่ลบเลือน (Non-Volatile)
B1-5-1-56|ฮาร์ดดิสก์ (HDD) ใช้จานแม่เหล็กหมุนพร้อมหัวอ่าน ส่วน SSD, Flash Drive และ Micro SD เป็นชิปหน่วยความจำ
B1-5-1-57|RPM (Revolutions Per Minute) คือรอบต่อนาที เช่น 5400 หรือ 7200 RPM
B1-5-1-58|SATA ใช้ต่อฮาร์ดดิสก์/SSD 2.5 นิ้วเข้ากับเมนบอร์ด
B1-5-1-59|SSD ไม่มีชิ้นส่วนเคลื่อนไหว จึงเงียบ เร็ว ทนทาน และประหยัดไฟกว่า HDD
B1-5-1-60|DVD-R ชั้นเดียวจุ 4.7 GB และบันทึกได้ครั้งเดียว (R = Recordable) ลบไม่ได้ ส่วน 700 MB คือความจุของ CD
